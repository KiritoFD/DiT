# 三天双机实验计划：4090 主攻，48 负责高风险探索

按你的机器条件重新分配，不再按“4090 做短实验、48 做长实验”划分。两台卡计算性能基本相同，区别是显存和网络，因此应该按实验产物的价值分工。

| 机器         | 职责                            | Checkpoint 策略                |
| ---------- | ----------------------------- | ---------------------------- |
| 4090（24GB） | 主线训练、正式消融、多阶段实验、最终候选          | 保留所有重要 checkpoint、优化器状态和实验记录 |
| 48（48GB）   | 风格监督探索、梯度有效性、辅助模型、合成数据、失败机制分析 | 本机临时保存；结束只交结论、逐图指标和少量海报      |
| 两机共同       | 使用同一套语义 Writer ID、数据划分、评测协议   | 不依赖跨机器传输大权重                  |

总周期：约 72 小时，每台各 72 GPU 小时的资源窗口。

这次我建议同时覆盖五个研究问题：

1. 训练组织：P1 混合与 P2 配对，到底各贡献多少？
2. 数据分布：书家均衡、复杂字采样，能否改善泛化？
3. 风格学习：如何让 Writer 条件学到比粗细、墨量更丰富的局部笔法？
4. 内容监督：缺笔、错部件能否通过专门的训练信号改善？
5. 推理与蒸馏：CFG 的有效信息能否保留，而不放大风格伪影？

一个重要修正：已有实验中，strong/mild 各 5k 的配对比较没有支持 mild 胜出；D1 风格梯度也出现过自身分类分数提升、独立评估不动的情况。因此这两条不能再当作未经验证的成功假设。

## Day 1（0–24h）：确定最有效的训练配方，同时验证风格监督是否可信

### 4090：P1/P2 做一次完整的 2×2 因子实验

这是第一天最大的训练任务。

所有实验从同一个 P0\@75k EMA 开始，使用相同的总样本曝光量、学习率、Writer dropout、EMA 和阶段重置规则。

保持现有阶段结构：前 10k + 后 20k，每组 B512，总曝光 15.36M。

| 实验 | 前 10k                  | 后 20k          | 核心问题          |
| -- | ---------------------- | -------------- | ------------- |
| A0 | Top10 普通采样             | Top10 普通采样     | 直接 FT 对照      |
| A1 | 70% 通用 Null +30% Top10 | Top10 普通采样     | P1 混合本身有多少收益？ |
| A2 | Top10 普通采样             | Top10 30% 配对采样 | 配对采样有多少收益？    |
| A3 | 70% 通用 Null +30% Top10 | Top10 30% 配对采样 | 复现完整 P1/P2    |

A3 相当于重新进行一次条件统一的主线确认。

这套实验非常有价值，因为能够分辨：

- 如果 A1 优于 A0：通用数据回放和过渡训练有效。
- 如果 A2 优于 A0：配对采样有效。
- 如果 A3 明显优于 A1/A2：可能存在训练阶段之间的互补。
- 如果 A0 与 A3 接近：之前的收益可能主要来自预算、LR 等因素。

注意，四组总曝光相同，但 Top10 曝光不同，这是混合策略本身带来的差别，必须记录。

另外，配对采样只是改变 batch 组成，没有额外对比损失。若样本的边际采样概率没有改变，它的主要作用是改变梯度估计，而不是让 FM 自动获得新的反事实监督。

产物： 每组 P1\@10k、P2\@10k、P2\@20k 的 EMA checkpoint、配置、曝光统计和统一验证指标。

### 48：风格监督的可用性实验

48 第一阶段不做 U-Net 长训练，先确定哪些风格信号能够可靠地提供梯度。

| 实验 | 方法                                         | 需要回答的问题               |
| -- | ------------------------------------------ | --------------------- |
| F1 | DINO / Pixel D1 / D2 / D3，严格留字、尽可能跨作品评测    | 哪个编码器真正识别书家？          |
| F2 | 同一生成图分别优化不同 Style Loss，冻结生成器，只调整输出或 latent | 风格梯度是否能改善独立评价，而非欺骗自身？ |
| F3 | 墨量、笔宽归一化前后，重新做 Writer 检索                   | 编码器是否过度依赖黑白面积？        |
| F4 | GT→VAE 重建→完整生成，分析内容错误                      | 缺笔究竟主要来自 VAE 还是生成过程？  |

F2 是核心。

不要只优化 Style Encoder 的分数，而是对固定生成样本施加少量梯度后，同时检查：

- Teacher 分数有没有改善。
- 另一个独立风格评价器是否也认可。
- 汉字结构是否被破坏。
- 是否只是在增粗、增黑。
- 是否出现纹理或局部对抗伪影。

如果独立风格评价没有改善，那么该编码器只能当评价工具，不能给生成器提供 Style Loss。

这一天的 48 最终只需要交：

`style_teacher_audit.json`、`gradient_transfer.json`、风格梯度前后对照海报。

## Day 2（24–48h）：集中筛选能改善内容或真实书风的训练方法

### 4090：同一 P2 EMA，开展 5k 短程多臂消融

这一天不换骨干，不重新预训练。

所有实验从同一个原始 P2\@20k EMA 开始，保持相同训练配置与随机种子；只改变表中的目标变量。

| 编号 | 修改                   | 预算 | 目的                          |
| -- | -------------------- | -- | --------------------------- |
| B0 | 原始 FM + 原采样          | 5k | 对照，可复用完全同协议的 strong 5k 已有结果 |
| B1 | Writer×Script 组均衡采样  | 5k | 减轻训练分布不平衡                   |
| B2 | 复杂、稀疏但质量可靠字符的温和重采样   | 5k | 改善未见复杂字泛化                   |
| B3 | 高噪声区 Writer 条件样本适度加权 | 5k | 强化 Writer 在早期生成阶段的作用        |
| B4 | 轻量内容辅助监督             | 5k | 改善缺笔、错部件；先通过 48 的内容教师检查     |
| B5 | 全局 Style Loss        | 5k | 测试跨字共享风格监督                  |
| B6 | 局部 Patch Style Loss  | 5k | 测试局部笔法监督                    |

B5/B6 只有在第一天 F2 的梯度迁移实验通过后才启动。

若未通过，就把预算转给 B1/B2/B3 的进一步验证，而不是强行完成风格损失训练。

### B1：书家和书体采样

不是简单地把每个 Writer 的图重复到一样多，而是按真实存在的 Writer×Script 组合分层，防止少数高频组合主导训练。

不生成不存在的书家—书体组合。

### B2：困难字符采样

只使用训练集内的难度与质量信息，不能根据测试集失败字建立专门的训练名单。

可以利用 STD 结构复杂度、组件密度、已有训练样本覆盖量和训练图质量，给困难但可靠的样本较小的额外权重，例如上限 1.5 倍。

此前“屍、品、覆、荷”等测试失败例只能用于验收，不能直接作为训练样本选择依据。

### B3：时间相关 Writer 训练

已有 FM 审计显示，正确 Writer 在高噪声阶段具有比较明确的误差优势，但其余时间的条件收益不稳定。

因此试一个简单变化：

\\[ L=\mathbb E[\omega(t,w)L\_{\rm FM}] \\]

例如，对有效 Writer 条件且 \\(t>0.7\\) 的样本给予 1.5 倍权重，再归一化整体损失尺度，保持 Null-Writer 训练覆盖。

这只是在测试风格监督应该更多落在哪些 FM 时间段，不需要额外模型。

### B4：内容辅助监督

这里不建议重新引入 SkelNet。

优先测试在低到中噪声区间，从预测速度恢复 \\(\hat x_0\\)，以冻结的内容表征提供弱监督。

前提是 48 已确认该表征在 GT、VAE 重建和不同书家真迹上的字符识别可靠，且不强迫合法异体逐像素贴合 STD。

### B5/B6：风格监督

如果 48 验证了梯度可迁移，再做两条：

B5：全局风格。 让不同字符的生成图靠近同书家真实风格分布，但不要求其视觉特征逐点贴合另一张字。

B6：局部风格。 使用前景附近的 Patch 特征分布，重点学习局部粗细变化、边缘、转折及笔锋。

两者均采用小权重，在 FM 训练稳定的情况下逐步开启，不能把风格梯度压过主 FM 目标。

我更期待 B6，但它必须通过独立评价，不能因为模型写得更黑、Writer Probe 更高就判定成功。

### 48：做风格 Loss 的独立生成端预实验

48 利用更大的显存，在本机已有 Deep114 EMA 上测试：

| 实验 | 方法                       | 预算    |
| -- | ------------------------ | ----- |
| R0 | 普通 FM 续训                 | 3k–5k |
| R1 | FM + 全局 Style Loss       | 3k–5k |
| R2 | FM + 局部 Patch Style Loss | 3k–5k |
| R3 | FM + 弱内容监督               | 3k–5k |

这几组可以直接利用 48GB 显存尝试 VAE Decoder + Style Encoder 的反向传播。

但结论只限定为在 48 的 Deep114 起点上，该监督是否可用。即使 R2 成功，最终仍必须在 4090 的 P2 上重做，不能把两个不同初始化的结果当成同一条训练曲线。

48 不需要向 4090 传模型，只返回对照表、PNG 和失败分析。

## Day 3（48–72h）：确认最佳方案，形成正式候选

### 4090：只延长通过第二天验收的方案

从 Day 2 选择最多两个优胜方案。

| 实验 | 训练                  | 目的            |
| -- | ------------------- | ------------- |
| C0 | 原始 P2 最佳续训对照        | 确定延长训练本身带来的收益 |
| C1 | 最佳候选延长到额外 15k–20k   | 看早期收益能否维持     |
| C2 | 第二候选延长到额外 15k–20k   | 比较不同改进方向      |
| C3 | 最佳候选更换训练随机种子，复测关键阶段 | 初步验证不是单次优化偶然性 |

如果 Day 2 没有任何候选通过内容和风格双重验收，不需要硬选优胜者。将预算用于对照路线或最佳现有模型的继续训练，给出明确的阴性结论。

### 最终评测统一为四个层次

| 层次    | 主要指标                            | 必须保留的视觉检查           |
| ----- | ------------------------------- | ------------------- |
| 内容正确性 | 严重错字率、缺部件、错连接、Ink-IoU           | 固定困难字及随机正常字         |
| 笔画质量  | LPIPS、Frag、Width-W1、墨量          | 起收笔、转折、细笔、飞白        |
| 真实书风  | 同字 GT 相对方向、多字跨字检索、独立风格评价        | 同 STD 的 Writer-swap |
| 泛化    | 全局未见字符、未见 Writer×Char 组合、尽可能跨作品 | Seen/Unseen 分层海报    |

Writer Top-1 仍可以报告，但不用于单独决定模型优劣。特别是当前 GT 上表现较弱的探针，不能作为风格增强的唯一依据。

模型选择在 val100 完成，最终 test200 只用于冻结候选后的确认。 旧 eval200fix 作为历史兼容口径保留，不与 val100 直接混排。

### 48：补做不值得占用主线 checkpoint 的探索

第三天把 48 用在独立风险实验，而不是让它等待 4090 的结果。

| 实验             | 内容                                          | 最终只交什么             |
| -------------- | ------------------------------------------- | ------------------ |
| T1：合成数据价值      | 对 Qwen 样本先人工/OCR复核，再做一组小规模 Null-Writer 增广对照 | 是否有实际下游收益          |
| T2：Writer 时间响应 | 在本机 Deep114 上进行分时 CFG、墨量控制及独立风格检查           | 哪些时间区间增强有效         |
| T3：局部风格反事实     | 检查同字换书家后，局部 Patch 分布变化是否接近真实 GT             | 共享风格还是局部条件规律的生成端证据 |
| T4：蒸馏可行性       | 仅在独立风格与内容双验收通过后，做少量单前向学生试验                  | 蒸馏是否值得正式投入         |

T1 不把此前自动接受的 75 张视为“已人工验证的真迹”。该实验的目的只是判断经过真正复核的合成数据有无训练价值。

T4 只是 48 上的技术可行性试验，不替代未来在 4090 上保存的正式蒸馏模型。

## 四、三天资源与时间预算

根据历史日志，114M U-Net 在 4090、B256 时曾达到约 3.2 step/s。B512 的实际吞吐需要用新配置热身测量；这里暂按 1.5–2.5 step/s 估计，加入 DINO/VAE 风格损失后可能明显更慢。

| 时间段    | 4090 重点                            | 48 重点                   |
| ------ | ---------------------------------- | ----------------------- |
| 0–24h  | 4×30k 等曝光 P1/P2 消融；必要时溢出至 Day 2 前段 | 风格教师审计、梯度迁移、内容错误归因      |
| 24–48h | P2 的 B0–B6 多臂 5k 筛选与中期验收           | 风格/内容 Loss 的本机短训练对照     |
| 48–72h | 最优两组延长训练、随机种子复核、正式评测与归档            | 合成数据、分时风格、局部反事实和可选蒸馏预实验 |

其中：

- Day 1 四个完整 30k 实验，纯训练预计约 13–22 小时；加上加载与评测，可能占到约 18–27 小时。
- Day 2 普通 FM 5k 单臂预计约 0.6–1 小时，带辅助网络的损失必须单独测速。
- Day 3 留出不少于 6–8 小时弹性预算，用于处理实验失败、复核候选或补足前两天溢出的运行。

如果实际吞吐明显低于估计，优先完成 Day 1 的 A0/A3，再做 A1/A2；不要为了赶排期把未跑满的实验标作完成。

每条训练臂至少记录实际曝光、训练时间、最优验证点和最终点。 checkpoint 的步骤数不能代替预算。

## 五、开始前必须固定的实验契约

这是唯一需要先完成的工程工作，不重写训练框架。

1. Writer 映射必须由 checkpoint 确定。 旧 Deep114 和现代 P2 行号不同，不能再用 `0..9` 猜测身份。
2. 条件与评测固定。 保存原始字符与书家 ID、STD hash、σ、VAE 缩放、EMA、Heun 步数及 CFG。
3. 使用同一评价集合。 val100 用于选择，test200 用于最终确认；明确是否是全局留字还是仅 Writer×Char 留出。
4. 每个实验只改变声明的变量。 Stage 边界、优化器/EMA 重置、主干与 Writer LR、随机种子都要有完整记录。
5. 48 独立闭环。 使用它已经存在的 Deep114、数据和教师，不依赖从 4090 下载大权重；最后只同步小体积 JSON、表格、抽样海报和源码差异。

这些是为了避免重新出现 Writer 标签错位、EMA 加载错误、STD 域不一致而导致的假实验结果。已有审查明确记录了旧 Deep 评测十位书家全部错位的问题。

## 六、三天结束后，如何决定下一代模型？

这轮的价值不只是刷高 SSIM，而是把未来路线收敛到可以执行的判断。

| 结果           | 后续路线                             |
| ------------ | -------------------------------- |
| A1/A3 明显最好   | 保留 P1 混合预训练，继续优化数据混合与目标书家曝光      |
| A2/A3 最好     | 优先改采样，而不是增加风格网络                  |
| B1/B2 最好     | 数据均衡与复杂字覆盖是主要瓶颈                  |
| B3 最好        | 深入研究 Writer 条件在不同 FM 时间段的学习      |
| B5 最好        | 共享 Writer 风格监督有效，优先完善全局分布学习      |
| B6 最好        | 局部笔法监督有效，继续研究局部风格表征              |
| B4 最好        | 内容错误约束不足，优先改善内容监督                |
| 所有新增训练都无明显增益 | 保留现有模型，优先增加独立真实数据与改善条件表示；不继续强加损失 |
| CFG 真实风格验收通过 | 最后才启动 4090 上的正式 CFG 蒸馏           |

### 我的资源押注

从历史证据看，我会把三天的主要注意力按以下顺序分配：

第一：训练课程与采样。 已有小幅正向证据，且最容易得到可归因结论。

第二：局部风格监督。 潜在收益高，但梯度有效性没有得到证明，必须由 48 先排除奖励投机。

第三：内容监督与时间采样。 它们可能直接改善当前最明显的缺笔与错误结体问题。

第四：合成数据与 CFG 蒸馏。 作为独立探索，不占用重要 checkpoint 资源。

三天不启动新的 DiT、CalliFlow、完整 VAE 或参考图大模型训练，也不重复 strong/mild 实验。

预期三天结束时，4090 至少应保留一套完成等曝光归因的 P1/P2 训练记录、若干短程监督/采样实验的有效对照，以及最多两个经过延长训练和严格验收的最终候选；48 则交付风格梯度是否真正可用、内容失败来自哪里、以及几条高风险路线值不值得继续的明确结论。

这能让两台相同算力的机器真正并行推进不同研究问题，同时把所有有长期价值的模型资产留在网络条件更好的 4090 上。
