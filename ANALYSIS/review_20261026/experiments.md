# 实验家族总账与结论边界

截至 2026-10-26。此文按研究问题组织；逐个留存配置目录见 [run_inventory.jsonl](run_inventory.jsonl)，早期全部条目见 [499 行历史索引](../../docs/experiments/ledger/early_runs.md)。同名 run 的启动失败、smoke、profile 与重启不单独重复解释。没有产物不等于模型无效，计划步数不等于完成步数。

指标默认写作 `SSIM / LPIPS / Ink-IoU`，**LPIPS 网络和测试域变化时不能跨表比较**。旧汇总部分采用 Alex；本轮原生评测和现代主要表采用 VGG。Frag 的阈值、细小连通块处理和 GT 归一化不同，必须回到具体协议。这里保留有依据的结论，不用历史混杂数据重新制造排行榜。

## A. 骨架、联合目标与字表（早期—10/8）

|---|---|---|---|

| v18/v21、后续两阶段改进 | 标准骨架→预测书家骨架→渲染；latent/pixel、结构监督、注入与容量变体；10/3 封存 | 中间回归改善不保证最终细线连通；骨架 IoU 与 SSIM 可反向变化。裁图里不少字随步数几乎不再改善，局部笔画仍合并/变形 | [两阶段归档](../../docs/experiments/2026-10-03-twostage-archive.md)、`assets/results/v21_skelnet_200k/` |

## D. 风格表征：统计 → Pixel/Latent D1 → D2/D3

| 路线 | 量化/状态 | 生成指导意义 |
|---|---|---|
| Quill/Hinge/频域/VAE通道 | 全局跨字匹配弱，部分显著低于随机 | 先核对距离方向和字符混杂；不能反转距离后自称有效风格距离 |
| Allograph DINO token聚类、Patch-SWD | 未给出可靠单字跨来源距离 | 此实现失败不等于局部造型分布思想无效，更不等于真实风格不存在 |
| v89 早期编码器 | 约3k训练99.77%，字符留出30.07%、来源13.64% | 强记忆/捷径风险明显 |
| Pixel D0→D1 | 字符留出mAP .5186→.5354；匹配2AFC56.08→61.04%；来源56.12→60.71% | 对比目标有收益，但不复用来源的100组仅53%，泛化证据有限 |
| Latent D0→D1 | 字符留出2AFC57.50→60.45%，来源57.14%，mAP约.5033 | 提取了一部分跨字信息，不等于梯度可用 |
| 集合表征 | 来源留出16字集合 Pixel D1约98%、Latent约88% | 有限独立书家对，说明多字聚合强；不能当单字loss验收 |
| Latent D1 梯度审计 | 3%扰动自身Top1 31.25→93.75%，Pixel D1始终36.25%，独立CE约42–44% | 对自身敏感方向的优化没有可靠迁移；样本8字单seed不足以做大结论 |
| D2 Geometry+Brush | 10k，val mAP .55364、2AFC64.59% | 真迹表征提高；没有形成可接DiT的独立梯度验收 |
| D3 弱SDF辅助 | 实际停约8.38k；8k mAP .55502、2AFC65.44% | 非完整10k对照；几何重建更好不保证风格方向更好 |
| DINO 线性诊断 | 留字符Top1约43.6%，少数有效logit维度 | 只能描述该探针与该数据；不能推出真实书风线性或不需要条件交互 |

## G. 清洗、粗细工具与 Top2/5/10/20 梯度集

粗细统计/校准和海报工具已具备，但后处理只能改变局部墨迹边界，不能补回正确部件。全局 dilation/erosion 会同时改变连通性；校准后的分数不能充当原模型质量。

旧“青/靑”异常有实际脏训练图支持：生成与脏图 SSIM .97181；还发现异体标签下像素重复泄漏。因此这类图片不能证明网络独自产生了条纹、异体或错误结构。

## I. P2 诊断与收尾（4090，已结束）

- **训练配方**：P1主干LR1e-5、部分条件5e-5、Writer dropout .25；P2 dropout .10、batch512、约30%配对。主要是FM监督，不是新Critic强风格loss。每阶段严格迁移权重但重置优化器/EMA时钟。
- **FM反事实**：100字符中98全局见过，68组合未见；高噪声 .85/.95 正确Writer优于错误Writer，ΔMSE约+.0643/+.0863；null多数时间段反而更好。条件有效但不是所有时段都校准良好。
- **CFG三seed**：1→1.6，LPIPS .349015→.346177、IoU .280953→.289914、Frag2.556→2.051；100张×3seed不是300独立字符。DINO探针自身GT仅24%Top1，不能只看生成Top1升至39.7%宣布风格成功。
- **墨量控制**：匹配墨量后独立margin仍部分提升，三seed差值约+.0187/+.0201/+.0176，第三个CI跨零；分数变化不完全由墨量解释，也不意味着全是笔法。
- **时间窗CFG**：高噪声半程约17.17s、全程22.44s、base11.67s；单seed探索，没有稳定最优窗口结论。
- **GT方向**：120生成组合仅39有现成GT、10共享字符书体组；墨量87.3%、笔宽P50约70%排序一致，Writer9无GT。符合部分真实方向但证据覆盖有限。
- **strong/mild各5k**：同P2 EMA、同seed90、相同batch/LR/采样/时钟，B相对A各主要差值CI跨零；严重错字未系统修复，mild不胜出。
