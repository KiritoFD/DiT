# 双机实验总审查：进度、图像、指标与变量归因

审查日期：2026-10-26。范围：4090、48 两台机器实际留存的配置、日志、逐图指标、评测协议与生成 PNG，以及早期归档。**这是一份证据校正版综述，不是新的训练结果公告。** 本轮没有启动训练或修改模型源代码；只对一处确认的评测映射错误重做了三个已有 checkpoint 的推理评估。

## 目前可以相信的判断

1. **可用的生成主线仍是 STD 空间条件 + Script/Writer 条件的 CNN U-Net / FM。** 共享条件的 114M Deep-Sym4 是值得保留的强基线；尚不能称它是严格控制计算预算后的最优尺寸。72M U100Base@55k 的视觉表现依然值得作为选型锚点，不能被后来更高的均值分数自动淘汰。
2. **数据覆盖、内容正确性与书风评价，是目前比增加模块更明确的瓶颈。** 数据清洗排除了部分错误监督，但新数据上的训练集记忆仍远强于跨字泛化。Top20 未证明稳定优于 Top10，也没有证据说明简单缩小网络可以消除过拟合。
3. **Writer 条件有效，但不充分。** CFG、Writer-swap、FM 反事实误差都证明模型会使用书家信息；GT 审计也支持相当一部分粗细方向是真实的。不能将一切简化为“只学会墨量”，也不能将分类器分数提高解释为学会了完整笔法。
4. **尚未得到可信、可迁移的风格梯度。** Pixel/Latent D1 和 D2/D3 的真实图辨识比旧手工统计更好，但 D1 梯度能迅速抬高自身分数，独立评测几乎不动。没有证据支持立刻强训 Style Loss。
5. **预训练有可用迁移能力，但收益与充分收敛仍未被严格归因。** P0/P1/P2 是目前有价值的候选训练包；其 batch、曝光、LR、dropout、数据混合同时变化，不能宣称单靠配对采样或某阶段机制解决了泛化。
6. **不支持继续默认叠加复杂度。** Writer 硬分离、CalliFlow 组合改动、继续加深 DiT、SDE、Qwen 辅助 STD、mild 收尾，都没有形成可稳定复现的综合优势。

## 本轮最重要的新发现：旧 Deep 模型的评测书家标签全部错位

Deep-Sym4 的原始 Writer 行顺序与 P2 的现代顺序不同。Qwen→U-Net 评测沿用了现代 CSV 行号和 identity remap，**十个书家全部映射到错误行**。A/C 的训练配置仍保留原始映射，因此这里确认的是评测错误，不是这两组训练已经被该错误污染。

## 图像和数值联合看，问题怎样演变

### 1. SkelNet → 字表 → VAE：解决了部分接口问题，没有解决所有内容问题

- 两阶段 SkelNet 的中间 latent 骨架损失不能稳定约束下游拓扑；级联路线不如单阶段。封存的是这些具体接口，不是 STD 结构先验。
- Moyi 12ch 未展示优于 4ch 的稳定收益。V68 的表征/训练包把旧协议 SSIM 推到约 .615，是实质进步。
- 新 VAE 的重建更好；V80 又到 .617 左右，墨迹覆盖也提高。但数据、OT 等同时改变，不能把全部生成收益归到 VAE。
- V68 旧 SDE 视觉更平滑、部分细笔消失：SSIM 改善与 LPIPS、Ink-IoU 恶化可以同时发生。修正数学实现后，新模型上没有可靠的全面 free lunch。

[VAE 阶段报告](../../docs/experiments/2026-10-13-vae-and-related-changes-report.md) · [SDE 对照原图](../../docs/experiments/v68_v70_sde/poster_preview.jpg) · [SkelNet 可读裁图](visuals/skelnet_crop.png)。裁图只覆盖原海报部分列与早期步数，不能当作整套 Strict 结果的代表性估计。

### 2. DiT → U-Net：空间覆盖提升明显，宽度仍影响风格

等曝光量下，20×384 比 20×256 的 Val FM 更低、Writer Top-1 高约 10 个百分点；相近的复杂字拓扑代理指标不能说明 256 宽已经足够。32×256 的已核验阶段没有扭转问题，继续加深没有得到明确支持。

早期 U-Net 在相近曝光下更快取得较高 Ink-IoU 和 Writer 辨识，但当时 Frag 较差；修正 EMA 错误后，72M 基线逐步形成了很强的视觉质量。后续 Deep114 的成熟指标很好，然而原来的 Skip/Decoder/门控实验并没有全部保留等预算纯对照，不能分别给每个模块记功。

![Deep114 与 CalliFlow 的实际生成](visuals/deep_and_calliflow.png)

固定索引读图：Deep50k→85k 的“㩜”部分结构更清楚，“西”反而更残缺，“情”持续偏粗，“而”未恢复该 GT 的笔势。CalliFlow 的“情/德”较细，“出”更浓，但没有在这些字上统一超越 Deep。**训练更久不是所有字符单调改善；粗细更接近也不等于结体正确。**

### 3. Top2/5/10/20：模型擅长记训练真迹，缺少可靠的跨字迁移

清洗后的模型在各自训练集 SSIM 约 .78–.85，测试约 .57–.62。必须在相同测试子集比较：

| 测试域 | 模型与训练点 | SSIM | LPIPS-VGG | 判断 |
|---|---|---:|---:|---|
| Top10 test | M10@30k / M20@30k | .6022 / .6005 | .3373 / .3375 | 综合接近，配对 CI 未支持差异 |
| Top5 test | M5 / M10 / M20，均 30k | .6009 / .6053 / .6027 | .3499 / .3396 / .3397 | 不能宣称专训 Top5 必然更好 |
| 各自 train/test | M20@30k | .8302 / .5703 | .1247 / .3540 | 很强的拟合—泛化差距 |
| 各自 train/test | M10@30k | .8509 / .6022 | .1156 / .3373 | 更小集合也没有消除记忆 |

旧“青/靑”等坏字能追溯到脏 GT 与近重复泄漏，不能用它们诊断网络。清洗后仍有难字缺笔和过粗，所以也不能把后续所有错误都归到脏数据。

[完整跨集合评测](../cohort_generalization_20261022/README.md) · [训练/测试对照海报](../../assets/posters/cohort_20261022/poster.png)。这套海报中训练图接近复刻、测试图仍有缺笔与墨块，是最直接的过拟合证据。

### 4. 预训练与 P2：有效候选，但增益没有完全拆开

| 同口径新 Top10 test200，sigma0 | SSIM↑ | LPIPS-VGG↓ | Ink-IoU↑ |
|---|---:|---:|---:|
| 直接 FT50k | .5874 | .34886 | .28594 |
| P1 10k + P2 20k | .5895 | .34656 | .28744 |

P1/P2 小幅领先，值得保留。可是它有 15.36M 下游曝光，FT50k 是 12.8M；LR 分组、混合比例、Writer dropout 也不同。不能用“30k 超过 50k”宣告训练更高效。

同一新配方下，48M→114M 的 FT25k val100：SSIM .5703→.5817，LPIPS .3660→.3579，IoU .2548→.2653。这比跨时期拼榜更支持 114M 的质量优势，但同时改变宽度与块数，是架构包对比。

最早的无 Writer 48M、DINO 参考式、最新 shared Writer P0 是三条不同路线，不能混叫“无 Writer 预训练”。最新 P0 实际有通用组别 Writer 条件，Top10 行尚未在 P0 训练。

### 5. Writer CFG 与 mild 收尾：一个有数值收益，一个没有证明额外收益

P2 三 seed CFG1→1.6：LPIPS .34902→.34618，IoU .28095→.28991，Frag 2.556→2.051。GT 同字方向审计支持墨量排序约 87.3%、P50 笔宽约 70%；部分风格响应确实与真迹方向一致。

但风格探针对 GT 的 Top-1 只有约 24%，生成 CFG1.6 反而约 39.7%。这个评价器不足以担保真实书风。墨量匹配后部分 margin 收益保留，证据仍有限；不能将 CFG 等同于纯风格放大。

| 相同 P2 EMA、同 seed、5k 收尾、val100 sigma0 | SSIM↑ | LPIPS↓ | Ink-IoU↑ | Frag↓ |
|---|---:|---:|---:|---:|
| P2 起点，PNG 重算口径 | .594306 | .349082 | .280922 | 2.29815 |
| A strong | .596306 | .346238 | .284355 | 2.03663 |
| B mild | .595889 | .346172 | .283369 | 2.18676 |

B−A 的 LPIPS、IoU、Frag、宽度 W1 置信区间均跨零。“屍/品/覆/荷”等内容问题未被系统修好。**mild 没有赢，不能作为已经验证的新收尾阶段。** 起点表的 PNG 重算口径与旧 inline 数字有小差异，不混用其绝对值。

### 6. Qwen：获得了书法域外观，未证明书家保真或补数收益

![STD 条件 LoRA 的实际变化](visuals/qwen_std_progress.png)

0→2k→4k：“旬”等字的笔画覆盖明显恢复；“巫”等也更浓、更完整。但“荷/傳/儀”持续偏统一、规整，和 GT 的部件关系、起收笔差距没有消失；标注为“屍”的第三行更接近只生成了“尸”部，缺少目标内部结构，是内容问题。单个字的覆盖改善是真实的，不足以证明跨字风格迁移成功。

Top10 Turbo LoRA20k test200 为 .5821/.4365/IoU .2827；STD 条件 LoRA4k val100 为 .5858/.4485/.2687，未在相同 val100 上全面优于原 prompt LoRA 的 .5853/.4458/.2855。两者的测试集不同，不能直接跨这两行排名。

1000 张合成图的筛选结果是：物理筛选过 390，分类器接受 75，转 null 315，物理拒绝 610。**75 不是人工验证正确的真迹替代品；610 也不等于 610 张坏图。**

![筛选类别中的样例](visuals/qwen_synth_filter.png)

每列只取该类别前八张，不代表类别比例。右列“相/如/秋”等看起来也可能是可用字，证实筛选结果不能直接当质量标签。代码把封闭内白计入 hole，把 Ink-IoU 误称为 SkelIoU；还没有 OCR/人工盲验。后续 U-Net 合成增广训练没有做过，不能说已经证明“加合成数据必然有害”。

## 下一轮优先级

1. **先固定实验身份与评测契约。** checkpoint 自带 Writer/Script remap；不同映射拒绝 identity 猜测；记录样本哈希、STD hash、VAE scale、EMA、采样与指标实现。先修复本轮确认的旧入口错误，再复用它评新模型。
2. **建立一个明确的部署候选对照。** 保留 U100Base55k、Deep114 成熟点、P2/Astrong；统一到清洗后的同一集合、STD 与采样，既看均值，也看固定难字和正常字。当前不具备跨协议宣布唯一最佳 checkpoint 的依据。
3. **下一笔训练预算优先用于等曝光的训练配方对照。** 若继续 P1/P2，用相同起点、总曝光、LR、EMA 规则对比直接 FT；不要同时再改网络。现有结果支持保留候选，不支持机制已经验收。
4. **暂缓已无可靠增益的扩展。** 不默认继续 mild 收尾、强 Critic、加深 DiT、Writer 硬分离、SDE、Qwen 补数。参考式条件仍可研究，但当前全球向量/未训练参考注入的失败不能否定所有参考生成。
5. **内容正确性与真实风格分开验收。** 固定问题字、可靠 GT、未见 writer×script×char 组合；同时检查缺笔、错部件、墨块、笔宽分布与人工盲评。Frag 或 Writer 单指标不得单独决定模型替换。
