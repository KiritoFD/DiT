# 书家风格的表征与注入：证据、数学化与最小验证方案

日期：2026-10-26。依据：当前 U-Net 实现、F/A/B/C/R 系列测量、Style Disc 审计、T0/T1 补评，以及本次提供的方案。本文是研究设计文档；下述新增架构与验证实验均为建议，不代表已实施或已取得收益。

## 1. 我的判断

**保留 114M U-Net 和低维 Writer 表征，值得测试显式的 Writer×局部特征交互。但当前证据只能支持“小规模、可归因的结构消融”，还不能把它确定为下一代主线。**

方案最有价值的部分是把风格理解为条件生成规律：同一个书家参数，在不同字形、局部上下文和噪声阶段产生不同响应。需要进一步修正的部分有四点：

1. 当前 AdaGN 已经具有 Writer×局部特征交互。新增分支要证明的是更容易学到正确规律，而非填补一个原本不存在的表达能力。
2. 提议的乘性模块同时包含全局偏置和空间变化。只与原模型比较，无法判断收益来自哪一部分。
3. 有书家辨识信息、能提供生成梯度、能改善最终书风，是三个不同问题，不能互相替代。
4. VAE 尚未被证明是唯一瓶颈，也没有被证明完全无关。部分报告对新结果的解释又走得过远，需要保留归因边界。

我建议把核心研究问题收窄为：

> 在相同 Writer 表、相同数据、相同 FM 目标下，让 Writer 调制显式依赖空间上下文，能否比同参数量的全局调制更准确地复现未见字符上的书家差异？

### 两个必须纠正的解释

**全局余弦 .9919 与局部差异损失可以同时存在。** 全局编码器可能对细小连接、末端形状不敏感；局部差异又可能远小于整字共同信号。设重建特征误差为 \(e_i\)，则书家对比量的误差为 \(e_a-e_b\)。即使每个 \(\|e_i\|\) 很小，相对于很小的真实书家差异 \(\|f_a-f_b\|\)，误差比例仍可能很大。不同表征空间之间更没有直接矛盾关系。因此不能用高全局余弦直接否定全部局部损失。

**R3 是表达能力的正面证据，不是完整的瓶颈定位。** 优化后的 latent 使用了目标 GT，可能偏离训练 latent 分布；L1 下降也不等于笔法已经正确。还需要检查优化前后图片、latent 偏移、round-trip 稳定性，以及独立内容/风格指标。R1 的 L1 从 .0080 到第三轮 .0097，绝对增长小，但相对首轮约增加21%；三轮结果不足以证明映射长期稳定。

另外，A3 的近乎1.0交互残差余弦值得重视，也值得复核。当前本地 JSON 与报告对部分置乱项的命名、符号并不完全一致；B JSON 的 `R_stroke_beyond_capacity` 为负，报告展示的约 +2.3pp 则对应“真实交互收益减去置乱收益”。后续应直接给公式和原始误差，避免只引用字段名。现阶段以可复算的约0.8%–1.0%增量作为有限证据，不用极高聚合余弦替代未见字预测效果。

## 3. 风格的数学对象：条件分布与条件算子

记字符为 \(c\)、书体为 \(s\)、书家为 \(w\)，STD 为 \(g(c,s)\)。真实图像还受到作品、时期、材料、扫描和单次书写变化 \(u\) 的影响。目标更适合写成：

\[
p(x\mid g,w,s)=\int p(x\mid g,w,s,u)\,p(u\mid w,s)\,du.
\]

这意味着同一书家、同一字符也可以有多个合理答案。单张 GT 是一次观测，不是该条件分布唯一合法的输出。因此，逐图 SSIM/LPIPS 应用于内容和保真检查，不能单独定义“书风正确”。

固定向量 \(e_w\) 可以参数化这个分布：

\[
x=G_\theta(g,s,e_w,\epsilon),\qquad \epsilon\sim\mathcal N(0,I).
\]

随机性承担同一条件下的写法变化，\(e_w\) 决定这些变化的分布倾向。固定向量并不要求固定像素偏移，也不要求所有字符产生相同的笔宽变化。

对当前 FM：

\[
z_t=(1-t)z_0+t\epsilon,\qquad v^*=\epsilon-z_0,
\]

\[
v_\theta(z_t,t,g,s,e_w)\approx
\mathbb E[v^*\mid z_t,t,g,s,w].
\]

Writer 实际控制的是条件速度场；最终图像差异还经过整条积分轨迹与 VAE Decoder。某层 Writer 响应幅度更大，或某一时刻速度差方向更一致，都不自动意味着最终笔法更准确。

### 向量、MLP、权重属于不同层次

- **Writer 向量**：稳定的条件索引及可学习坐标。
- **条件 MLP**：把该坐标转换为各层的调制参数。
- **共享主干/动态权重**：根据局部输入执行具体变换。

对于固定 Top10，32D 没有明显的身份编码容量压力：10个点中心化后的矩阵秩最多9。这不证明32D能表达所有书风，只说明“区分十个 ID”本身不需要盲目扩维。应当测有效响应与泛化，而非用 embedding 维数推断风格容量。

Embedding 的坐标也不具有天然语义。对任意可逆矩阵 \(Q\)，把 \(e_w\) 换成 \(Qe_w\)，再相应修改投影，可以保持网络输出不变。因此跨实验直接比较表向量的范数、夹角或某一维，不足以判断模型学到了什么；更可靠的是比较固定输入下的输出响应。

固定 ID 与参考图也不是谁绝对更优。固定 ID 适合已知作者的总体分布；参考图还可能指定某件作品或某种局部写法。后者提供的信息不完全包含于 ID 中。当前 Top10 注入实验可以先使用已有表，将未知书家和作品级控制留作独立问题。

## 4. 当前 AdaGN 已经具备什么能力

当前 [ResBlock](../../src/unet/blocks.py) 的主要路径是：

\[
u_l=\operatorname{Conv}_1(\operatorname{SiLU}(\operatorname{GN}(h_l))),
\]

\[
\widetilde u_l(p)=
[1+\gamma_l(t,w,s)]\odot\operatorname{GN}(u_l)(p)+\beta_l(t,w,s),
\]

\[
h_{l+1}=\operatorname{Skip}(h_l)+\operatorname{Conv}_2(\operatorname{SiLU}(\widetilde u_l)).
\]

即使 \(\gamma,\beta\) 在空间上共享，\(u_l(p)\) 仍随位置变化。简化为 \(y(p)=\gamma(e)h(p)\) 时，混合导数 \(\partial^2 y/\partial e\partial h=\partial\gamma/\partial e\) 已经非零。再经过卷积、归一化和非线性，同一 Writer 对不同局部形状会产生不同响应。

**因此，新模块的合理动机是改善归纳偏置、优化路径和参数共享，而不是宣称原模型无法表达局部风格。**

已有 `writer_film_rank` 的实际实现，是把 Writer-only 的 scale/shift **加到原 scale/shift 上，再统一执行 AdaGN**；它不是在原调制后串联第二次仿射变换。两种实现会有不同的乘性交叉项，文档和消融必须按实际代码定义。

还要区分“新增独立输入支路”和“切断原 Writer 路由”。第一轮建议保留原共享 Writer 条件，只添加零初始化支路。若同时开启 `decouple_writer_condition`，就改变了已有条件路径，初始等价性也不能只靠新增头为零来保证。

## 5. 对低秩 Writer×Local 方案的细化

建议采用下面的候选形式，先每个目标尺度增加一个模块：

\[
a_l(w)=A_l(e_w)-A_l(e_{\varnothing})\in\mathbb R^r,
\]

\[
b_l(p)=\phi\!\left(B_l[\operatorname{Norm}(h_l(p)),
\operatorname{Norm}(F_l^{STD}(p))]\right)\in\mathbb R^r,
\]

\[
\Delta h_l(p)=W_l\,[a_l(w)\odot b_l(p)],\qquad
h'_l=h_l+\Delta h_l.
\]

其中 \(r=16\) 可作为首轮起点，\(\phi\) 可选 SiLU 或 tanh，\(W_l\) 零初始化。以 null Writer 为锚，使新增支路在 Writer-null 下为零，方便保持 CFG 两路语义。它仍不能保证训练后主干的 null 输出完全不变。

### 5.1 它更接近低秩条件算子

若暂时忽略非线性，并令 \(b=B_hh+B_gF\)，则：

\[
\Delta h=
\underbrace{W\operatorname{diag}(a_w)B_h}_{\Delta K_w}h
+W\operatorname{diag}(a_w)B_gF.
\]

这相当于书家控制一个由共享基底组成的低秩算子；若 \(B_h\) 是3×3卷积，其输入包含局部邻域。它与共享基底的动态权重有直接联系，不需要把每个隐含通道命名成“横画专家”或“转折专家”。

但 rank16 是对新增变换的约束，不代表“书家风格只有16维”。原主干仍承担大量条件交互。

### 5.2 它不保证学到空间变化

把门控分解为：

\[
b_l(p)=\bar b_l+\widetilde b_l(p),\qquad
\bar b_l=\frac1{|\Omega|}\sum_p b_l(p).
\]

则：

\[
\Delta h_l(p)=
\underbrace{W_l[a_l(w)\odot\bar b_l]}_{\text{空间共享项}}
+\underbrace{W_l[a_l(w)\odot\widetilde b_l(p)]}_{\text{空间变化项}}.
\]

当门控近似常量，新增模块主要产生空间共享偏置。Sigmoid 门控尤其不能仅凭“有乘法”就解释成局部规则；其常量分量可能很大。即使使用 tanh，也必须实测空间方差和最终响应。

建议记录两部分经过 \(W_l\) 后的能量、跨字变化，以及分别关闭时对生成结果的影响。**不要一开始强制去掉空间均值**：全局粗细、疏密本来也是合法风格，去均值应先作为诊断和对照。

### 5.3 局部特征并非天然与 Writer 解耦

现有 \(h_l\) 已经包含上游 Writer 信息，因此 \(b_l(h_l,F_l^{STD})\) 也可能识别 Writer。最终的乘积不一定是纯粹的“身份因子×内容因子”。对 \(h_l\) 使用 `detach` 只切断梯度，不会删除其中的书家信息。

第一版可以接受这一点，把模块称为条件局部适配器；不要宣称已经完成内容/风格解耦。若要研究机制，可离线固定来自同一基准 Writer/null 的 \(h_l\)，只切换 \(a_l(w)\)，测直接作用；再与自然运行时的总作用比较。无需为了这项诊断在日常训练中增加第二遍主干计算。

### 5.4 初始化与尺度

仅将输出投影 \(W_l\) 置零，\(A_l,B_l\) 正常初始化。第一个反向中主要由 \(W_l\) 获得梯度，随后上游才开始学习，这是正常过程。若再把外部乘法 gate 也置零，会造成双重零初始化的启动问题。

Decoder 16×16和32×32是合理的首轮位置，但“8×8负责结体、32×32负责笔锋”只是功能假设。多尺度传播和 Attention 使它们的感受野重叠；应通过干预测量，而非把分辨率直接当作功能标签。

按当前通道数，若32尺度用 \(C=192,D_{STD}=64\)，16尺度用 \(C=384,D_{STD}=128\)，每尺度一个3×3局部投影、32→16 Writer线性层、16→C输出投影，权重数约为：

\[
\sum_l r[32+9(C_l+D_l)+C_l]=120832.
\]

加上偏置约0.122M；这是特定简化实现的计算，不是已构建模型的实测参数量。每个ResBlock都加会扩大数量，首轮没有必要。

## 6. 为什么三臂“原模型 / Writer-FiLM / 局部模块”还不够归因

原建议能比较三个产品方案，但 Writer-FiLM 与局部模块的参数量、深度、输入信息都不同。局部模块胜出时，不能只归因于空间交互。

我更建议优先使用下面三个同起点方案：

| 臂 | 新增支路 | 回答的问题 |
|---|---|---|
| C0 | 无，原 P2 等预算续训 | 增加训练本身的收益 |
| Cg | 同一低秩模块，使用广播的 \(\bar b_l\) | 新容量与上下文相关的全局调制是否有效 |
| Cl | 完全相同模块，使用 \(b_l(p)\) | 保留空间变化是否有额外收益 |

Cg/Cl 保持相同参数、输入特征和注入位置，仅改变空间聚合。**Cl−Cg 比“局部模块−普通FiLM”更接近我们真正想测的变量。** 两者仍可能有优化难度差异，不能把一次差值解释为普遍的表达能力定理。

已有 Writer-only AdaGN 可以作为工程上便宜的附加对照，但无需为了齐全一次铺开很多分支。若 Cg 已有收益、Cl 没有额外收益，再比较更简单的 Writer-only AdaGN 是否足够。

共同约束：同一 P2 EMA、固定同一个 VAE、同数据顺序和曝光、同 STD 增强、同 LR/EMA/优化器重置方式；首轮仅普通 FM。新增模块零初始化，不改变原条件路由。

**书家表策略单独固定。** 你此前明确要求“独立对比学习训练表、生成训练冻结”；本次参考方案提出联合学习，不能默默把它并入结构实验。建议首轮三臂都冻结同一张已选定的表；它若来自 P2，只代表冻结 P2 当前表，不能冒称为独立对比学习表。是否换表或解冻，另做独立对照。

首轮预算建议每臂5k，保留1k/3k/5k观察点；实际 batch 先按一次显存预检确定，再三臂一致。5k无收益且新增支路基本没学动时，只能判定这轮优化失败，不能立即判定结构没有价值。

## 7. 最值得做的测量：按信息价值排序

### M0：先确认评价器会响应正确变化

选择固定图像，做可控变化：轻度模糊、亮度/背景变化、轻微位移，以及明确的局部增粗、连接/断开。报告指标随干预强度的曲线。

几何改变应能被内容/轮廓指标感知；背景变化不应主导书家判断；笔宽指标应随可控膨胀单调变化。不要要求风格指标对增粗完全不变，因为粗细本身可能是真实风格。对合法变形的稳定性与对错误笔画的敏感性，需要分别验收。

局部对照优先使用固定 STD 定义的区域及其邻域扩张，GT与生成图采用同一位置集合；同时报告多尺度结果，防止合法结体偏移被固定ROI漏掉。独立检测端点再比较两组均值，会混入“检测到的事件集合变了”这一效应。

### M1：R4式条件贡献审计——先看正确 Writer 是否真的有用

固定独立 GT latent、同一噪声、STD和Script，比较正确、同书体合法错误、null Writer。模型使用 eval，关闭随机 dropout；所有分支必须共享 \(z_t\)、目标 \(\epsilon-z_0\) 和模型时间 \(1000t\)。

\[
\Delta L_{wrong}(t)=L_{wrong}(t)-L_{true}(t),\qquad
\Delta L_{null}(t)=L_{null}(t)-L_{true}(t).
\]

建议先用已有留出集，覆盖 \(t=.15,.35,.55,.75,.90\)，3个噪声seed；按字符聚类估计配对置信区间，书体分别报告。这里是免训练审计，可以批量计算。

若 true 优于 wrong、却不优于 null，说明错误条件有害，但还没有证明正确条件带来额外收益。低噪声时 \(z_t\) 已包含大量目标书家信息，null 与 true 接近也不等于 Writer 无用。各时间桶必须结合信息量解释。

旧 T2 已出现 clean/noisy latent 与时间尺度不一致的问题，因此这项审计必须先检查“两个完全相同 Writer 分支误差一致”。正确 Writer 的 FM 优势仍只是条件信息被利用的证据，最终书风需要完整采样验收。

### M2：直接检验“生成的书家差异是否像真实差异”

对相同字符、书体下的书家 \(a,b\)，在固定区域特征 \(q\) 上定义：

\[
d^{GT}_{ab,c,s}=\overline q^{GT}_{a,c,s}-\overline q^{GT}_{b,c,s},\qquad
d^{gen}_{ab,c,s}=\overline q^{gen}_{a,c,s}-\overline q^{gen}_{b,c,s}.
\]

每个生成条件用相同的多个噪声seed，再比较跨seed均值。共同噪声降低对比方差，但不代表两张图拥有真实笔画的一一对应。

至少报告方向、幅度和残差三类量。幅度可用整体回归斜率：

\[
\alpha=\frac{\sum_i\langle d_i^{GT},d_i^{gen}\rangle}
{\sum_i\|d_i^{GT}\|^2},\qquad
E=\frac{\sum_i\|d_i^{gen}-d_i^{GT}\|^2}
{\sum_i\|d_i^{GT}\|^2}.
\]

避免逐对除以接近零的 GT 差异。特征尺度仅由训练集确定；GT样本少时，斜率会受测量误差影响，有重复真迹时应做拆半可靠性检查。没有重复样本时明确这一限制。

全局墨量/笔宽与局部形状分开报告；原始指标和墨量匹配后的指标同时保留。墨量匹配会改变边缘与连接，不能把匹配后的差值视作严格的“纯风格因果效应”。

### M3：模块是否真的使用了局部信息

对训练后的 Cl，比较完整 \(b(p)\)、广播 \(\bar b\)、空间置乱 \(b\) 三种推理干预；同时记录新增响应能量与内容损伤。若广播后结果基本不变，新模块可能主要在做全局控制。

空间置乱属于分布外干预，只是机制诊断；最终证据仍是训练时就使用广播条件的 Cg 与 Cl 的公平比较。不能仅凭置乱后图变差宣布“学到了笔法”。

对已有条件路径可做2×2交换：原主干/新支路分别使用 Writer A 或 B，保留四个输出。总变化包含交互项：

\[
v_{BB}-v_{AA}=(v_{BA}-v_{AA})+(v_{AB}-v_{AA})
+(v_{BB}-v_{BA}-v_{AB}+v_{AA}).
\]

分别比较它们对同一个 FM 目标的误差及完整采样结果；负余弦不能单独证明两个分支在有害对抗。

### M4：统计与图像验收

- **主层级**：未见字符、未见 Writer×Script×字符组合分别报告；训练未见不等于通用预训练未见。
- **来源层级**：真实作品ID不足时，只称“来源代理留出”。书家与来源高度混杂，不能靠换一种bootstrap解决不可辨识性。
- **统计单位**：按字符重采样，保留该字符下所有书家与seed；同时给每位书家/书体结果。不能把1200个共享字配对当作1200独立样本。
- **风格判据**：M2方向/残差、独立跨字表征、盲评共同判断。独立分类器可能共享数据捷径，意见一致也不是最终证明。
- **内容判据**：LPIPS、Ink-IoU、多阈值连续性，加固定问题字的缺笔/错连/异体合理性盲评。Frag降低可能只是粘连增加。
- **盲评面板**：同字多书家、同书家多字；同时展示GT内部变异。随机化模型标签，分别评分内容正确性与书风相似性。

置乱检验应破坏跨字符的书家关联，并尽量保持书体/字符覆盖和边际频数。把全部 Writer ID 做一次统一重命名不会破坏任何可学习结构，不能当作有效负对照。

## 8. 决策规则

| 观察 | 更合理的下一步 |
|---|---|
| 正确 Writer 的 FM 和完整采样均有用，Cg/Cl都无新增收益 | 优先检查数据覆盖、训练预算和评价可靠性，保留现有注入 |
| Cg胜C0，Cl与Cg相当 | 收益主要支持额外条件适配，优先选简单模块 |
| Cl稳定胜Cg，且局部方向更准、内容不退化 | 支持显式空间交互，再考虑扩层或rank |
| 分类分数升，墨量变化大，局部方向/盲评不改善 | 不能验收为笔法进步，不继续放大风格强度 |
| V0/V1只改善重建、生成反而变差 | Decoder更新不能直接替换P2，另查生成latent的域匹配 |
| R3能改善重建，但优化latent偏移大或round-trip不稳定 | 说明存在更好可解码点，尚不能归因Encoder或FM |

**我会保留“低维 Writer 参数 + 共享局部算子”的建模方向，把新增机制定义为可检验的优化先验。下一步最有价值的结构比较是 Cg 与 Cl：在相同容量下，空间变化本身有没有用。**

## 9. 与相关工作的关系

这些工作提供设计依据，不替代本项目的实证：

- **LF-Font**：局部风格与内容因子分解，支持共享因子的思路；字体生成任务并不直接证明历史书法中的交互强度。[论文](https://ojs.aaai.org/index.php/AAAI/article/download/16340/16147)
- **MX-Font**：多个局部专家学习局部表示，说明可以学习局部概念而非完全依赖手工笔画分类；不意味着当前必须加入专家路由。[论文](https://openaccess.thecvf.com/content/ICCV2021/html/Park_Multiple_Heads_Are_Better_Than_One_Few-Shot_Font_Generation_With_ICCV_2021_paper.html)
- **Fine-Grained Local Styles**：强调内容与参考字空间风格的对应，提醒我们“局部信息存在”和“能找到对应关系”是两个问题。[论文](https://openaccess.thecvf.com/content/CVPR2022/html/Tang_Few-Shot_Font_Generation_by_Learning_Fine-Grained_Local_Styles_CVPR_2022_paper.html)
- **SDT**：区分书家级共性与字符级细节，支持分层解释；其在线笔迹任务与离线书法图像生成不同。[论文](https://openaccess.thecvf.com/content/CVPR2023/html/Dai_Disentangling_Writer_and_Character_Styles_for_Handwriting_Generation_CVPR_2023_paper.html)
- **SPADE**：空间条件可通过位置相关的归一化调制进入生成器；我们使用的STD是布局先验，不是需要严格遵循的语义分割标签。[官方项目](https://nvlabs.github.io/SPADE/)
- **StyleGAN2**：低维风格参数可以调制共享卷积权重，支持条件算子的理解；不保证该机制在当前FM和数据规模下优于AdaGN。[论文](https://openaccess.thecvf.com/content_CVPR_2020/html/Karras_Analyzing_and_Improving_the_Image_Quality_of_StyleGAN_CVPR_2020_paper.html)

本文引用的仓库报告包含不同时间的归因修订；第2节的证据边界优先于早期报告中“唯一瓶颈”“完全无损”“不可能同时成立”等过强表述。
