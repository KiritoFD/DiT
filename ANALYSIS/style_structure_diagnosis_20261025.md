### 3. 判别结构

- LDA 谱：rank1 .177 → rank9 .328（弥散，不集中少数方向；方向跨折主角度 65.3°）
- 分类器阶梯：质心 .284 < LDA .328 < QDA20 .361 < logistic .426；MLP .403 无非线性增益
- 判别谱（logit SVD）：rank1 .181 → rank7 41.3% → rank9 42.5%，**d_eff95 = 7**
- 脚本控制：楷 .490 / 行 .436 / 隶 .889（同书体内可分性不降；隶书高分为书家-书体共线，作上限参考）
- 跨字形类别泛化矩阵：对角 .366–.420，非对角均值 .350（同类优势 +2.7pp，无结构条件化模式）
- Writer×STD 交互（M2 双线性 K=2..16，两种 g_c，严格留字）：**ΔR²_test = 3.2e-8 ≈ 0**，train 增益 0.09%（连训练字都拟合不动）
- K-shot 原型：K=1 12.6% → K=8 18.1% → K=32 24.0%（**K90=32 未饱和**）；原型方向余弦 .973（方向稳、收敛慢）
- QDA log-loss 比 LDA 差 1.34（协方差差异在留字上不稳定，推翻准确率口径的 QDA 增益）

### 4. 像素验证（P1 面板）

交互项是真实的书家行为，但属于**词汇性逐字选择**，与 STD 字形结构无关（结构 kNN 失败的原因）。

## 三、最终结论

1. **书家风格跨字共享且线性可读**：43.6% 留字 Top-1（随机 10%），弥散于 ~7 个有效维度 + 协方差项，不集中于少数方向。
2. **无可泛化的字形条件调制**：聚类交互、跨类矩阵、G+C、双线性 M2 四方一致为零或负——Writer×STD 交互路线（含 CrossAttention-by-glyph）关闭。
3. **参考图路线关闭**：可迁移的只有全局分布形态；逐字特异性（词汇性草化）无法从其他字外推，参考聚合的均值原型收敛慢（K90≥32）且不优于学习型 embedding。
4. **单一 Writer Embedding 容量足够**：风格 ≈ 中等维度线性可读结构，embedding 经 U-Net 非线性足以表达 b_w；h(w,c) 本无可泛化信号。
5. **诚实边界**：全部结论限于 DINO 表征 + 本数据 + 线性/低秩预测器族；43.6% 之外仍有 >50% 方差属 ε 与不可预测项；笔锋级信息可能需要像素级/在线轨迹特征才能验证（未做）。

## 四、路线决策

依据以上测量 + P1/P2 验收（`ANALYSIS/p1p2_writer_aware_20261025.md`）：
**114M U-Net + STD + Script + Writer Embedding，普通 FM；通用预训练 → writer-aware 混合 10k → Top10 配对专精 20k**。
不加 Reference Encoder、CrossAttention、Writer×STD 模块、风格码本。
