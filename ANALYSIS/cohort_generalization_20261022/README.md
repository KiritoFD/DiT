# Top2 / Top5 / Top10 / Top20：拟合与泛化阶段报告

2026-10-22。完整评测于16:07:37完成：20个checkpoint、112项结果。

## 结论

**训练拟合与测试泛化存在明显差距，但不能概括为四条线都在“越训越坏”。**

- Top5在15k后测试LPIPS回退，继续训练的感知质量收益最可疑。
- Top10的测试SSIM、LPIPS直到30k仍改善；不能仅凭train/test差距认定应该更早停止。
- Top20在25k后测试收益很小，训练拟合仍改善，表现为泛化收益饱和。
- 在同一Top10测试集上，Top20与Top10基本持平；不能拿Top20自身400张的0.5703与Top10自身200张的0.6022横比，宣称扩充书家导致退化。
- Top2模型只完成10k；与其他模型30k的对比不等预算。本报告额外列出统一10k的比较。

本轮没有72M或REPA开关对照，因此不能据此断言114M过大、REPA关闭是主因，或某种架构改造必然有效。

## 口径与产物

所有模型均为普通约114M FM U-Net：channels192/384/576、对称4个ResBlock、共享Writer/Script条件；不启用硬分离、DiC、额外Gate、REPA或Critic。
Batch512，LR7e-5，warmup1500，50k总调度，各组阶段停止点30k；Top2按用户要求在约13k停止，只评估已完整保存的5k/10k。
Top20/10/5各评5k、10k、15k、20k、25k、30k。统一EMA、CFG1、Heun50、相同VAE和逐图噪声。

| 集合 | 完整训练量 | 正式test | half-seen训练探针 | 支持的模型 |
| --- | ---: | ---: | ---: | --- |
| Top2 | 6226 | 40 | 20 | M2 / M5 / M10 / M20 |
| Top5 | 14069 | 100 | 50 | M5 / M10 / M20 |
| Top10 | 23485 | 200 | 100 | M10 / M20 |
| Top20 | 30386 | 400 | 200 | M20 |

M数字表示训练书家数。half-seen就是冻结的`train_half`训练探针，不是seen/unseen混合集。
探针每书家10张，test每书家20张；尽可能匹配书体比例，跨层级嵌套。测试与所有训练集合隔离；不保证严格作品级留出。
数量和书体匹配不等于字符、作品和难度完全匹配，因此train/test均值差不能全部归因为过拟合。

为避免重复GPU生成，每个checkpoint只采样本层最大test和train_half，再按固定样本身份、噪声和逐图指标汇总嵌套的小档位。
复用3组既有30k完整test前核验权重文件SHA、CSV SHA和原生协议/PNG/指标完整性。GPU空闲后采用batch32、VAE batch8。
聚合来自原生4–5位小数逐图CSV；SSIM舍入误差最多5e-5，不宣称未舍入浮点精确值。

## 2. Top5集合：15k之后的感知回退最清楚

![Top5训练与测试曲线](G:/GitHub/DiT/ANALYSIS/cohort_generalization_20261022/figures/top5.png)

| 模型 | 步数 | SSIM 训/测 ↑ | LPIPS 训/测 ↓ | Ink-IoU 训/测 ↑ |
| --- | ---: | --- | --- | --- |
| M5 | 30k | 0.8461 / 0.6009 | 0.1288 / 0.3499 | 0.7454 / 0.2819 |
| M10 | 30k | 0.8595 / 0.6053 | 0.1088 / 0.3396 | 0.7946 / 0.2850 |
| M20 | 30k | 0.8387 / 0.6027 | 0.1227 / 0.3397 | 0.7734 / 0.2986 |

M5测试LPIPS在15k为0.34459，到30k回退至0.34990；测试IoU由0.28547降至0.28190，SSIM基本不变。
训练SSIM由0.83807升至0.84607，但训练LPIPS也没有继续改善，不能把所有变化都描述为单纯“训练越好、测试越坏”。
更准确的判断是：**M5后期拟合收益已很有限，测试感知质量出现回退，继续长训缺乏收益依据。**

M10/M20在该测试集上仍有小幅改善；两者30k LPIPS几乎相同，M20的IoU点估计更高。
说明扩充书家并没有在这一共同测试集上造成明显损伤；M20对M5的LPIPS改善属于有限、探索性证据。

## 3. Top10集合：M10与M20基本持平，不能认定越训越坏

![Top10训练与测试曲线](G:/GitHub/DiT/ANALYSIS/cohort_generalization_20261022/figures/top10.png)

| 模型 | 步数 | SSIM 训/测 ↑ | LPIPS 训/测 ↓ | Ink-IoU 训/测 ↑ |
| --- | ---: | --- | --- | --- |
| M10 | 30k | 0.8509 / 0.6022 | 0.1156 / 0.3373 | 0.7808 / 0.2961 |
| M20 | 30k | 0.8332 / 0.6005 | 0.1258 / 0.3375 | 0.7654 / 0.3027 |

M10从5k到30k，训练SSIM增加0.2679，测试增加0.0474；训练改善远大于测试改善，但测试LPIPS仍由0.37239降至0.33733。
因此它存在明显拟合/泛化差距，却没有显示30k比早期checkpoint更差。
先前验证集在20k后的波动不能直接替代这批独立test的完整轨迹；两者应分别记录。

M20−M10在30k的配对差：SSIM −0.00168，LPIPS +0.00012，IoU +0.00666；三个95%区间均覆盖0。
**当前没有证据认为增加后10位书家显著提升或破坏了原Top10总体质量。**

## 4. Top20集合：后期平台，训练拟合继续增长

![Top20训练与测试曲线](G:/GitHub/DiT/ANALYSIS/cohort_generalization_20261022/figures/top20.png)

| 步数 | SSIM 训/测 ↑ | LPIPS 训/测 ↓ | Ink-IoU 训/测 ↑ |
| --- | --- | --- | --- |
| 5k | 0.5519 / 0.5299 | 0.3634 / 0.3838 | 0.2954 / 0.2673 |
| 10k | 0.6154 / 0.5477 | 0.3028 / 0.3685 | 0.4155 / 0.2856 |
| 15k | 0.7074 / 0.5575 | 0.2146 / 0.3605 | 0.5933 / 0.2899 |
| 20k | 0.7706 / 0.5652 | 0.1653 / 0.3549 | 0.6962 / 0.2917 |
| 25k | 0.8020 / 0.5689 | 0.1432 / 0.3535 | 0.7418 / 0.2938 |
| 30k | 0.8302 / 0.5703 | 0.1247 / 0.3540 | 0.7771 / 0.2907 |

25k→30k：训练SSIM继续提升0.0282，测试只提升0.0014；测试LPIPS略变差0.00043，IoU下降0.00311。
这支持**泛化收益接近平台**，不支持继续把全部预算用于强化训练集拟合。
但LPIPS这点回退很小，不能仅凭一个5k间隔宣称Top20已发生严重、持续的崩坏。

Top20新增书家的难度和来源构成不同，整体0.5703不是与Top10整体0.6022可直接横比的性能排名。

## 5. 统计边界与下一步

探索性配对区间按字符分组bootstrap，2000次、seed90，未做多重比较修正，也不是作品级独立泛化保证：

| 共同测试集 / 对照 | 差值 | 95%区间 |
| --- | ---: | --- |
| Top10，30k，M20−M10，SSIM | −0.00168 | [−0.00779, +0.00475] |
| Top10，30k，M20−M10，LPIPS | +0.00012 | [−0.00532, +0.00569] |
| Top5，30k，M20−M5，LPIPS | −0.01024 | [−0.02097, −0.00008] |
| Top2，10k，M20−M2，SSIM | −0.04184 | [−0.06853, −0.01581] |
| Top2，10k，M20−M2，LPIPS | +0.02449 | [+0.00258, +0.04903] |

Top5的区间仅勉强不含0，不把它升级为已确认的全面优势。Top2只有40张，也不能替代更多seed/来源的复核。

1. 当前最清楚的问题是：模型能记住训练字，却只把一小部分拟合收益带到留出字；优先研究泛化而非盲目延长训练。
2. 下一步定位应区分书家、书体、seen字符/未见字符和作品来源，避免把内容或来源分布差异全算成过拟合。
3. 表中事后“最优test checkpoint”只能描述曲线；正式模型选点仍用独立validation，不能再用test挑点并报告为无偏最终成绩。
4. Frag受微小墨点、真实断笔和错误连接共同影响，不能只靠其均值下降宣布笔画改善。完整IoU、软墨量、空白率等见112项总表。
5. 本报告没有新增独立书家指标、OCR或人工盲评，不把SSIM/LPIPS改善等同于真实书风改善。

## 7. 48.33M冻结表：拟合差距变小，但留出质量没有同步改善

X1于2026-10-22 20:37:41完成30k，raw与EMA书家表均通过精确不变检查。
补评固定Top20训练探针200张、test400张；EMA/CFG1/Heun50、同路径同逐图噪声。不是前述validation200。

| 模型 / 步数 | SSIM seen/test ↑ | LPIPS seen/test ↓ | IoU seen/test ↑ |
| --- | --- | --- | --- |
| 旧114M / 25k | 0.8020 / 0.5689 | 0.14317 / 0.35353 | 0.74179 / 0.29385 |
| 新48.33M / 25k | 0.7504 / 0.5616 | 0.17991 / 0.35927 | 0.67762 / 0.29182 |

30k SSIM seen-test差从0.25985缩到0.21070（−18.9%），LPIPS test-seen差从0.22922缩到0.19538（−14.8%）。
但是seen SSIM下降0.0549、test下降0.0057；seen LPIPS变差0.0372、test变差0.00336。
因此主要是训练拟合减弱，而不是留出质量超过旧模型。test IoU略高0.00185，不能替代整体感知质量判断。
30k test Frag新2.8049、旧2.1982，碎片化指标仍较差；尚无本轮独立Writer或人工盲评成绩。

新模型25k→30k：seen SSIM提升0.0249，test仅提升0.0030；seen LPIPS降低0.01797，test仅降低0.00195。
SSIM gap由0.1888增至0.2107，LPIPS gap由0.17936增至0.19538，拟合/泛化分离依然存在。
不能把较小gap直接宣布为过拟合修复；这些集合没有逐字难度匹配，且当前只有单seed、架构与表契约联合改动。
