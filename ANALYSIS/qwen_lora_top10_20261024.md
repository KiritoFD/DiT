# Qwen-Image-2.1-Turbo LoRA Top10 书家风格训练总结（2026-10-24）

目录：48机 `/home/ds/Workspace/xy/qwen-lora-top10-20261024`；代码 `tools/qwen_lora/`（本地仓库同步副本）。

## TL;DR

- **方法**：冻结 Qwen-Image-2.1-Turbo 全部原生权重，仅训 Attention q/k/v/out 的 rank16 LoRA（16.78M）；条件**只走文字 prompt**（书家名+书体+目标字），冻结文本编码器；不再使用书家表 embedding/书体 token 任何特殊条件链路。
- **最终配方**：256 分辨率（GT 原生）、B12、无梯度检查点、LR 1e-4 余弦退火至 1e-5（warmup 100）、20,000 步 = 240k 样本 ≈ 10.2 epoch，每 4k 步保存+评测。全程 1.216 s/步、峰值 44.07 GiB、零重启。
- **test200**：SSIM **0.5821** / LPIPS **0.4365** / Ink-IoU **0.2827**（对照底模 256 探针 .588/.507/.184：LPIPS、Ink 明显更好，SSIM 持平略低）。
- **收敛判定**：**基本收敛、合理停点**。Ink-IoU 与 SSIM 自 8k 起进入平台（波动 ≤±0.006，验证集噪声水平）；LPIPS 至 20k 仍小幅单调改善但斜率很低（前 8k 贡献了总改善的 61%，末 4k 仅 −0.005），LR 已退火至 1e-5。继续训练边际收益约 0.003–0.01 LPIPS，性价比低；如需再压可从 20k resume 延长 5–10k 步。

## 2. 条件设计：纯 Prompt（本轮核心改动）

旧轮（3 书家）：冻结 32D 对比学习书家表 → MLP → 4 个上下文 token；书体 embedding → 1 token；文字里无书家名且写死"楷书"。本轮按用户决策全部删除：

- 文字模板：`书法家：{名}。书体：{楷|行|隶}书。请用该书法家的{书}书风格书写汉字「{字}」。纯白背景、黑色毛笔单字，字形完整，单字居中且几乎铺满画幅，无边框、无印章、无落款。`
- 文本缓存键从"按字符"改为**（字, 书家, 书体）**，共 17,453 个键，避免旧缓存污染新条件；GT 不进条件，只做 FM 目标。
- 推理=训练同构：同模板 prompt → 冻结文本编码器 → LoRA 生成器；无 STD、无参考图、无条件适配器需要保存，部署只需 LoRA 权重。
- 代价与收益：去掉 writer-dropout 正则与显式 ID 注入，书家身份完全由 prompt 文本承载；test200 分书家 SSIM 极差仅 .084（.546–.629），未见某书家系统性学不到，说明纯文本条件对本任务是够用的。

## 3. 训练配方与关键工程决策

最终 config（`tools/qwen_lora/top10_turbo.json`）：res 256 / rank 16 / LR 1e-4→1e-5 余弦 / warmup 100 / B12 / 累积 1 / 20k 步 / 每 4k 保存评测（每书家×书体 1 张、Turbo 原生 8 步、seed90）/ writer 均衡采样 / AdamW FP32 状态 + BF16 前向 / 无梯度检查点 / `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`。

达成该配方的实测链路（全部 48 机实测，无估算）：

| 实验 | 结果 | 结论 |
|---|---|---|
| 512 / B8 / 带检查点（旧协议） | 4.195 s/步 = **0.524 s/样本**，18.58 GiB | 基线；GPU 已 100% 算力打满 |
| 512 / B32 / 带检查点 | 16.58 s/步 = 0.518 s/样本 | **加大 batch 不提速**（算力受限），只改每步样本数 |
| 512 / B8 / 无检查点 | OOM @46.5 GiB | 512 下无检查点不可行 |
| 分辨率探针（底模，9 字 ×256/512 对照 GT） | SSIM .588/.597、LPIPS .507/.501、Ink .184/.192；VLM 复核 256 九字结构完整 | **256 可用**：底模低分辨率无崩坏，且为 GT 原生带宽，512 属 LANCZOS 上采浪费 |
| 256 / B16 / 无检查点 | OOM @46.9 GiB | 文本 token 不随分辨率缩：每样本序列 ≈80 文本+64 图像=144（512 为 336，仅 0.43×），激活 ≈1.7 GiB/样本 |
| **256 / B12 / 无检查点（最终）** | **1.216 s/步 = 0.101 s/样本，44.07 GiB 稳定** | 比 512/B8/检查点**快 5.2 倍**；关检查点省 ~1/3 重算 |

计算量说明：LoRA 冻结权重更新而非计算——每步仍对 7.1B 底模（13.25 GiB bf16，32 层/hidden 4096）做全量前向+反向，每步 ≈0.46 PFLOP，与可训练参数量（0.24%）无关；这是 batch 不提速、4090 全程满载的根本原因。

其他要点：VAE 后验 mean/std 按图像缓存（23,785 张；256 版 4 分钟，512 版存档 `latents512.pt`）；FM 目标 noise−clean、均匀抽原生 scheduler timestep；LoRA 参数训练时升 FP32（评测加载亦需同样转换，已修复严格逐张量相等校验）；检查点含优化器/RNG/配置与数据 SHA，支持精确 resume 延长训练。

## 4. 训练过程

- 编码：VAE 后验 23,785 张约 4 分钟；文本 17,453 键约 25 分钟；Turbo 底模 33GB 逐文件 SHA 校验通过。
- 训练：10:19 CST 前完成 20,000 步，总训练时长 ≈6.75h（1.216 s/步），全程零重启/零 OOM；loss 逐 10 步在 0.10–0.24 波动（FM 随机 timestep 的正常方差），LoRA 初始梯度范数 0.211 非零。
- 检查点 4k/8k/12k/16k/20k 共 962MB 全部落盘。

## 5. 收敛评估

验证集（23 张，seed90，8 步采样）逐步趋势：

| 步数 | SSIM | LPIPS | Ink-IoU | LPIPS 增量 |
|---|---|---|---|---|
| 4k | 0.5693 | 0.4520 | 0.2653 | — |
| 8k | 0.5705 | 0.4403 | 0.2868 | −0.0117 |
| 12k | 0.5671 | 0.4394 | 0.2879 | −0.0008 |
| 16k | 0.5716 | 0.4379 | 0.2834 | −0.0016 |
| 20k | 0.5750 | 0.4327 | 0.2891 | −0.0052 |

**判定：基本收敛，20k 是合理停点，但非严格饱和平台。**

- Ink-IoU：8k 后进入 .283–.289 平台（波动 ≤±0.006 ≈ 验证集噪声量级），收敛。
- SSIM：全程在 .567–.575 窄幅波动，20k 达最优，收敛。
- LPIPS：唯一仍单调改善的指标，但前 8k 贡献总改善（−.0193）的 61%，后 12k 仅 −.0076，且 LR 已退火至 1e-5，单位步数收益递减。
- 无过拟合迹象：验证无回退，test200（.5821/.4365/.2827）与验证一致略好。
- 若继续：从 20k resume 延长 5–10k 或末段 LR 回升（同旧 turbo_extend 模式），预期 LPIPS 再降 ~0.003–0.01，其余指标大概率持平——**边际收益小，当前优先做定性对比/CFG 等推理侧实验比加练更划算**。

## 6. test200 结果（20k 检查点）

分书体：

| 书体 | SSIM | LPIPS | Ink-IoU |
|---|---|---|---|
| 楷 | 0.5949 | 0.4071 | 0.2846 |
| 行 | 0.5751 | 0.4620 | 0.2724 |

分书家（SSIM 降序，每家 20 张）：褚遂良 .629 > 欧阳询 .626 > 王羲之 .594 > 苏轼 .584 > 柳公权 .578 > 赵孟頫 .576 > 米芾 .570 > 何绍基 .559 ≈ 文徵明 .559 > 颜真卿 .546。极差仅 .084，无明显掉队书家；最小书体隶书反而 Ink-IoU 最高（波磔墨量贴合最好）。注意：训练期验证每槽仅 1 张，其"褚遂良最弱"信号与 test 全量结论相反，**分书家结论以 test200 为准**。

定性（200 对对照图整体观察）：骨架结构稳；墨迹普遍比 GT 略淡/略细（Ink .28 的主要来源）；行书连笔处差异最大（与其 LPIPS 最高一致）。

## 7. 推理侧参考图实验（负结果）

协议：test200 每图注入 2 张同书家同书体**异字**训练集参考图（该组合 train 中最高频 2 字，确定性选取），经 `pipe(prompt, image=[...])` 由 Qwen3-VL 编码进条件序列；prompt 保留书家/书体身份并加"学习参考真迹"指令；其余与基线一致（256/8步/seed90），逐图配对比较。

| 组合 | SSIM | LPIPS | Ink-IoU |
|---|---|---|---|
| 20k LoRA 无参考（基线） | 0.5821 | 0.4365 | 0.2827 |
| 20k LoRA + 2参考 | 0.5705 | 0.4453 | 0.2576 |
| 底模 无参考 | 0.6032 | 0.5027 | 0.1948 |
| 底模 + 2参考 | 0.5595 | 0.5035 | 0.2136 |

- LoRA 配对 Δ：SSIM −0.0116（71/200 改善）、LPIPS +0.0089（95/200）、Ink −0.0251（64/200）——三项全降。
- 底模配对 Δ：SSIM −0.0437、LPIPS +0.0008、Ink +0.0188——同样净负（SSIM 大跌）。
- **判定：参考图注入在纯文本训练的适配器上无效，且在底模上也无效，非 LoRA 分布偏移单因所致**；可能机制是参考图占据条件容量并扰动构图/布局，而 GT 扫描图的输入域与"纯白底单字"输出域不完全匹配。若要启用参考条件，需"带参考训练"（训练时同样注入参考图），属独立训练实验。产物 `ref_eval_20k/`、`base_ref_diag/`。

## 8. 已知局限

- test 每图仅 1 个 seed（90）、8 步采样：无多 seed 方差，无 CFG 扫描。
- 验证集 23 张偏小，趋势判断含噪声；底模对照探针是另一 9 字集合，仅方向性可比。
- 未与旧 3 书家（512+条件 token）方案做同预算严格对照——两者分辨率、条件机制、数据规模均不同，不可直接归因。
- SSIM 未超底模（.582 vs .588 探针），墨量偏淡未完全收敛到 GT 分布。
- 参考图推理注入已证伪（§7）；后续变化是"带参考训练"或 CFG/多 seed 等其他方向。
