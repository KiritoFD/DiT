# v68 与 v80 的 SDE：数学与实现诊断（2026-10-12）

## 结论先行

v80 上 corrected SDE **不是完全没有工作**。在同一个 50k checkpoint、同一 VAE、同一初始噪声、50-step Heun 下，三条独立 SDE 路径的共同结果是：

- 碎片率（frag ratio）平均下降 `0.07197`，逐样本 bootstrap 95% CI 为 `[-0.14787, -0.00219]`，这是目前唯一稳定越过零线的收益；
- SSIM 平均只上升 `0.000576`，95% CI 为 `[-0.000315, 0.001512]`，不能认为存在稳定的全局重建质量增益；
- MSE、LPIPS、ink SSIM、ink IoU、skel IoU 的置信区间也全部跨零。

因此更准确的判断是：**corrected SDE 在 v80 上仍然能修连通性，但它不再产生 v68 那种显著的 paired-SSIM 提升。**

v68 的大幅提升不能直接外推到 v80，因为历史 v68 结果同时满足三个特殊条件：

1. 使用的是后来确认不保持目标边缘分布的旧 SDE 漂移；
2. 模型用 C2OT 训练，破坏了从 velocity 推导 score 所需的 `x0` 与噪声独立配对假设；
3. ODE 基线碎片率高达 `5.06`，存在极大的连通性修复空间。

这表明 corrected SDE 的实际作用主要是修补本来就断裂严重的字，而不是普遍提升图像保真度。

## 2. 数学上为什么不该预期 corrected SDE 必然超过 ODE

线性 flow matching 路径为

`x_t = (1-t) x_0 + t epsilon`。

模型学习的 conditional velocity 是

`v(x,t) = E[epsilon - x_0 | x_t=x]`。

由此可得

`E[epsilon | x_t=x] = x + (1-t)v(x,t)`，

以及 score

`score_t(x) = -[x + (1-t)v(x,t)] / t`。

corrected SDE 使用这个 score 修正漂移，并在 `t=1 -> 0`、代码中 `dt<0` 的约定下与 probability-flow ODE 共享同一组边缘分布 `p_t`。若 velocity 精确、积分精确，则：

- ODE 和 corrected SDE 的终点分布都是同一个 `p_0`；
- corrected SDE 没有“理论上必然比 ODE 更接近 GT”的性质；
- 两者的差别只能来自 velocity 误差、有限步积分误差、以及对随机样本使用单张 paired GT 的评价方式。

因此 v80 上“SSIM 基本不动”其实更符合正确构造的预期。corrected SDE 可以改变单条轨迹、修复部分局部拓扑，却不应该凭空把同一个已学分布整体推向那张固定 GT。

## 3. v68 为什么能大幅提升

### 3.1 v68 的提升主要是连通性和平滑，不是所有质量指标都提升

历史结果：

| 指标 | v68 ODE | v68 旧 SDE | 变化 |
|---|---:|---:|---:|
| SSIM | 0.6169 | 0.6260 | +0.0091 |
| LPIPS-alex | 0.3911 | 0.3989 | **+0.0078（变差）** |
| ink IoU | 0.3044 | 0.2961 | **-0.0083（变差）** |
| frag ratio | 5.06 | 2.38 | -2.68（-53%） |
| HF / GT | 0.811 | 0.760 | -0.051 |

所以“v68 大幅提升”准确指的是 SSIM 和碎片率，并不是感知质量、墨迹区域和高频细节的全面提升。旧 SDE 把大量断裂笔画连起来并变平滑，SSIM 奖励了这个变化；LPIPS、ink IoU 和高频同时退化，证明它也是一个明显的 trade-off。

### 3.2 v68 用的是错误但有强偏置的旧漂移

旧实现近似为：

`drift_old = v * (1 + gamma^2 t)`。

它缺少由 score 导出的状态相关修正项。忽略随机项并把 `v` 看成局部常量时，额外漂移的积分量为

`integral_0^1 gamma^2 t dt = gamma^2 / 2`。

在 `gamma=0.5` 时相当于额外 `12.5%` 的速度行程。这不是保持同一 `p_t` 的“等价随机采样”，而是沿模型速度场继续推了一截的启发式外推/过度去噪。独立方差测试也显示，`gamma=0.5` 时旧式会把目标方差从 `1.0000` 推到 `1.0432`。

因此旧式完全可能偶然补偿 v68 velocity field 的系统性偏差，尤其是把断笔进一步推成连笔。这个收益可以是真实的工程收益，但它不等于 corrected SDE 的理论收益。

### 3.3 C2OT 使 v68 不满足 score 推导前提

上述 score 恒等式建立在原始训练耦合 `x_0` 与 `epsilon` 独立的前提上。v68 使用 C2OT，在同条件子集内根据样本重排噪声，训练联合分布已经不是独立乘积分布。

所以即便把 corrected score 公式机械套到 v68 的 velocity 上，也不能保证它真是该训练路径的 score。历史 v68 是“C2OT 学到的场 + 错误旧漂移”这一组合，不能作为“无 OT + corrected SDE”必须复现 `+0.0091` 的基准。

### 3.4 v68 有远大于 v80 的碎片修复空间

- v68 ODE frag：`5.06`；旧 SDE 后：`2.38`；绝对修复 `2.68`；
- v80 ODE frag：`1.7449`，已经比 v68 **SDE 修完后**还低；
- v80 corrected SDE 三 seed 平均只再修 `0.07197`。

用纯经验比例作量级检查：v68 每修 1 个 frag 得到约 `0.0091 / 2.68 = 0.0034` SSIM。乘以 v80 的 `0.07197` 修复量，得到约 `0.000245`，与实测 `+0.000576` 同一数量级。它不是严格因果模型，但说明 v80 的微小 SSIM 增益与“剩余修复空间太小”完全相容。

## 4. 实现层审计

当前 v80 corrected-SDE 链路没有发现能解释“少掉 0.009 SSIM”的实现错误：

1. ODE 本地结果复现 4090 自动评测，排除 checkpoint、VAE、EMA、ID 映射和 metric 口径错位；
2. `sde_gamma` 从命令行进入 `flow_kwargs`，运行描述能确认 corrected 分支实际开启；
3. v80 使用 `use_c2ot=false`，满足 `x_0`/噪声独立耦合前提；
4. predictor/corrector 对修正后的完整 drift 做 Heun 平均，并共享同一个随机增量 `dW`；
5. 完美线性 velocity 的端到端测试中，50-step corrected SDE 能保持目标终点方差：`s0=1, gamma=.5 -> 1.0004`，`s0=.2 -> .0409`；
6. CFG 为 1，没有额外 guidance 对 score 关系的干扰。

有限步长当然仍会造成误差，但 oracle 测试的量级不足以解释 v68 与 v80 的差异。当前证据更支持“算法行为不同”，而不是“corrected SDE 分支没生效”。

## 5. 新 VAE 在这里扮演什么角色

新物理 VAE 的全局 latent std 已约为 `0.996`，因此旧数据中最明显的噪声/数据幅度失配已经消失。它的 posterior 相对宽度约 `0.277`，确实会让同一图像对应更宽的 latent 分布，使随机路径较难对齐一张固定 GT；但这只能是次要解释：此前把 posterior sampling 收窄/改成 mode 的 v74 实验在全部 23 个点上更差（SSIM 约 `-0.008`，LPIPS 约 `+0.032`），并没有恢复 SDE 优势。

所以不应把结论写成“新 VAE 太随机，导致 SDE 失效”。更稳健的结论是：

- 新 VAE 修好了全局 scale；
- v80 no-OT 让 corrected score 公式在数学上可用；
- corrected SDE 按理论只应保持分布并改变路径，不承担纠正条件语义/字形路由错误的任务；
- 当前剩余误差更多来自模型场和条件结构本身，而不是 sampler 能解决的碎笔问题。

## 6. 最终判断

1. **SDE 到底有没有 work？** 有，但目前可确认的是拓扑/连通性层面的 work：三 seed 的 frag 改善稳定显著。
2. **为什么没有 v68 的大幅 SSIM 提升？** 因为 corrected SDE 本来就不改变理想边缘分布；v68 的结果混合了旧漂移的启发式外推、C2OT 场和巨大的断笔修复空间。
3. **是新 VAE 导致的吗？** 没有证据支持它是主因。posterior 宽度可能削弱 paired-GT 指标，但已有 mode-target 反例，不足以解释全部现象。
4. **当前实现有明显 bug 吗？** 在 ODE 复现、参数透传、no-OT 前提、随机 Heun 和 oracle 方差测试五个门禁下，没有发现。
5. **工程上怎么定位它？** corrected SDE 应被视为一个可选的“高碎片样本连通性修复器”，而不是默认的全局质量增强器。v68 的旧 SDE 则更像一个偶然有效的 biased sampler；若想复现那种大幅 SSIM，研究对象应叫“受控外推/拓扑引导”，而不是继续要求严格 marginal-preserving SDE 做它理论上并不保证的事。
