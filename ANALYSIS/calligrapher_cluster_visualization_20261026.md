# 书法家特征空间聚类与流形可分性可视化分析（2026-10-26）

本分析完全基于远端 48 服务器 CPU/GPU 计算，拉回轻量指标与高清可视化图表，回答核心问题：
**“不同书法家在数据特征空间中，到底能不能分得开？为什么通用模型看着分不开，而风格判别器却能分开？Qwen 生成的又为什么分不开？”**

## 1. 为什么在通用视觉特征下“分不开”？（字形方差 vs 风格方差）

在没有专门解耦字形结构的通用视觉模型（如 DINOv2、CLIP、ViT）中，抽取 26,002 张真实书法样本降维：

- **第一主成分 (PC1)** 解释了 26.5% 的方差，**第二主成分 (PC2)** 解释了 6.6% 的方差；
- **按书体着色时**：楷书、行书、隶书呈现出极清晰的三大分支，说明宏观连笔率和结构拓扑是视觉特征的第一主导因素；
- **按书家着色时**：10 位书法家的散点完全混合成团（ARI 仅 0.010）。
- **根本原因**：同样是写“安”字，颜真卿的“安”和欧阳询的“安”，在像素级都有“宀”和“女”，笔画拓扑重合度高达 85% 以上。通用视觉网络自然将“它是哪个字”作为主信号，书法家微小的藏锋、露锋、提按变化仅相当于高频扰动，因而在无监督空间中无法区分书家。

---

## 2. 真实真迹在受控风格空间中“不仅分得开，而且极其分明”

当使用经过书家对比学习和留出集验证的风格判别网络（ResNet18 256D 嵌入空间），并将书体受控（固定楷书或固定行书）时：

### (1) 楷书五大家（颜真卿、欧阳询、柳公权、褚遂良、赵孟頫）
- **聚类指标**：K-Means (K=5) 的 **ARI 达到 0.9142，NMI 达到 0.9152**，纯度超 93%；
- **流形几何特征**：
  - **欧阳询（欧体）**：笔画严谨瘦劲、结体方整，在 PC1 轴最左侧形成独立紧致椭圆；
  - **颜真卿（颜体）**：篆籀起笔、内紧外拓、中实厚重，在 PC1 轴最右侧，与欧阳询拉开最大几何距离；
  - **柳公权（柳体）**：骨力内挺，中心余弦相似度与颜真卿最高（0.417，印证书法史上“颜筋柳骨”的渊源），但其骨架内敛与骨节点强化使其与颜体保持显著可分界限；
  - **赵孟頫（赵体）**：楷中带行、圆润妍美，与其他唐楷四大家相似度最低（与柳公权甚至为负相关 -0.035）。

### (2) 行书四大家（王羲之、米芾、苏轼、文徵明）
- **聚类指标**：K-Means (K=4) 的 **ARI 达到 0.9029，NMI 达到 0.8796**；
- **流形几何特征**：
  - 王羲之作为晋人神韵代表，具有高度独立的连贯流形；
  - 米芾（八面出锋、倾侧自如）与苏轼（丰腴跌宕）在空间中存在合理的宋代行书笔意接近性（相似度 0.399），但边界依然清晰不混淆。

## 3. 为什么 Qwen 生成样本在漏斗测试中通过率低？（“风格塌缩”的可视化真相）

将真实真迹与 Qwen P2-A 4k 生成的 1,000 张样本投影到同一风格流形空间对比：

1. **真迹分布**：欧阳询、颜真卿、柳公权分布在互不重叠的三大流形区域，两翼展开；
2. **Qwen 生成分布**：
   - 无论 Prompt 提示词写的是“颜真卿”还是“柳公权”，生成的样本在风格空间中的散点**全部聚拢在原点和标准字（STD）中心**；
   - 生成样本在五大楷书书家间的 K-Means **ARI 暴跌至 0.0387**，几乎完全混成一团！
3. **解释闭环**：
   - Qwen LoRA 依靠 STD 图像条件虽然解决了“错别字和笔画缺损”（物理过关率从 0% 升至 39%），但 LoRA 仅仅学会了“如何临摹参考字形的轮廓”；
   - 它生成的笔触本质上是“标准楷书 + 通用毛笔纹理”，并没有真正深入到颜体的“筋肉”或柳体的“风骨”。这也是为什么在之前的漏斗测试中，只有 7.5% 的样本能被判别器确认，其余全被降级为 Null-Writer（通用字）。
