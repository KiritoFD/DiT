## 【已实现】FEW-SHOT 新书家实验（等 v15 跑完再执行）

### 为什么做
实测 **r(训练样本数, strict) = −0.62**（n=25 书家）：
苏轼 3131 张 → strict 0.3485（最低）；李邕 1168 张 → 0.6300（最高）。
→ 样本多的书家**风格跨度大**，而书家条件是**一个预训练且冻结的 128 维向量**。
few-shot 是检验"单向量能否捕获新书家"最干净的实验。

### wild 里被扔掉的书家（13 个候选，不在 50k）

**选用 怀素**（狂草，风格最独特，500 张够做 K 扫描）。

### 实现（4 处）
1. **`src/train/train.py`** — 预训练书家表比新表小时，不再 assert，
   新行用**已有书家的均值**初始化（`--init-new-callig mean|zeros|random`）
2. **`--train-only-new-callig`** — 冻结全部，**只训书家表新增行**。
   ⚠ `requires_grad` 是**逐张量**的，无法只放开某几行 →
   整表放开 + **grad hook 把旧行梯度清零**（保证已训好的 45 个不漂移）
3. **`tools/build_fewshot_csv.py`** — 从 wild 目录生成 few-shot train/eval CSV。
   文件名(**不含扩展名**) 就是字符；字符→标准字形映射取自 50k
   （wild 里 17/500 个生僻字在 50k 没出现过 → 无 std_path → 跳过，
   否则 g=ZERO 字条件失效）。
   ⚠ **先切固定 eval 块，再从剩下池里取 K** —— 否则不同 K 的留出集
   不一样，K 扫描无法横向比较（实测踩过，已修；现在各 K 的 eval md5 相同）
4. **`v13_fewshot_k{5,10,20,50}.json`** + `_review/launch_fewshot.sh`
   num_calligraphers 46 / batch=K / lr 1e-3 / cond_drop 0.0 / max_steps 500

### 【实现过程中连撞 6 个坑】（都有价值）
1. **`--train-only-style` 的类型** — `type=_str_to_bool` → `expected one argument`，
   改 `action="store_true"`
2. **`ctx_pos_g` 重复注册** — line536 设成普通属性、line717 又 register_buffer
   → `KeyError: attribute already exists`。说明 **xattn+style_token 从未跑通过**
3. **只放开 callig_style_ca 不够** — 换 adaln→xattn 是**换架构**，53 个新权重
   被冻结 → Diff 0.20 炸到 1.73
4. **requires_grad 是逐张量的** — 无法只放开某几行 → 整表放开 + **grad hook 清零旧行**
5. **wild 图没有预编码 latent** — 训练走 latent-only 模式，
   报 `无法提取 img_id (preload)` → 写了 `tools/encode_fewshot_latents.py`
   ⚠ VAE 路径是 `data/pretrained/pretrained_models/sd-vae-ft-ema`
   （不是 `data/pretrained/sd-vae-ft-ema`，后者不存在）
6. **wild 图尺寸不一**（有 288×256）→ 评测 broadcast 失败 →
   统一 resize 到 256×256 存副本（与编码时的 resize 一致）
7. **callig_id_map 格式** = `{"num_calligraphers":N, "id_map":{原id:紧凑id}}`，
   新书家要加到 `id_map`（我第一版加到顶层，错）→ CSV 用原始 id 9999 → 45
8. **ckpt_every 与 epoch_steps 必须相等**（我改了前者没改后者）

### 【❌ 结果】few-shot 训练新书家 embedding —— **让结果变差**
| 书家 | 基线(不训) | 训练 1.5k 步后 |
|---|---|---|
| 徐渭 | 0.4163 | **0.3968** ✗ 变差 |
| 沈周 | 0.4187 | 0.4244 → 0.3924 → **0.3881** ✗ 持续下降 |
| 怀素 | 0.4442 | （run 失败，无 eval）|
| 伊秉绶 | 0.1958 | （run 失败，无 eval）|

**基线全部有效**（0.20~0.44，明显低于已训书家 0.57，符合"全新书家"预期）

**⚠ 失败原因分析**（按顺序撞到的）:
1. **EMA 掩盖了训练** ✗✗★ —— `ema_decay=0.9999, interval=4`，
   1.5k 步只有 375 次 EMA 更新 → `0.9999^375 = 0.963` →
   **EMA 只反映约 3.7% 的更新**。评测默认用 EMA → 训练看不见。
   解法：`use_ema=False`（few-shot 短跑本就不需要 EMA）
2. **均值初始化量级不对** —— 预训练表各行范数 med=11.0 / mean=8.9
   （row44=0.216 是异常小的一行），而**均值向量范数只有 2.06** →
   用 mean 初始化比典型书家**小 5 倍**，起点就是分布外
3. **LR 1e-3 太高 + 1.5k 步 = 15k epochs 过 10 张图** → embedding 漂移出分布
   （实测新行范数涨到 2.0，旧书家~11 量级完全不同）

### 【★ 结论】单向量 + 冻结主干，few-shot 学不了新书家
这**不是**"风格 token 无效"的证明（那需要解冻/从零训），但它说明：
**只调一个 128 维向量、主干不动，学不会一个新书家的风格** ✓
→ 与前面 r=-0.62（样本多→风格跨度大→单向量装不下）**互相印证** ✓

### 【下一步该试】（按优先级）
1. **降 LR + 减步数**：1e-3 → 1e-4，1.5k → 300~500 步（先排除超参问题）
2. **加范数约束**：把新行 clamp 到典型书家范数量级(~11)
3. **解冻更多**：放开 adaLN/final_layer 一起训（而非只训 embedding）
4. **从零训**：style_token_n=32 + xattn，不用 --train-only-*
   → 这才是公平检验"多 style token"的方式
