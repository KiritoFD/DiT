## 【已实现】FEW-SHOT 新书家实验（等 v15 跑完再执行）

### 为什么做
实测 **r(训练样本数, strict) = −0.62**（n=25 书家）：
苏轼 3131 张 → strict 0.3485（最低）；李邕 1168 张 → 0.6300（最高）。
→ 样本多的书家**风格跨度大**，而书家条件是**一个预训练且冻结的 128 维向量**。
few-shot 是检验"单向量能否捕获新书家"最干净的实验。

### wild 里被扔掉的书家（13 个候选，不在 50k）
```
宋高宗 980(草492/楷488)  徐渭 832  伊秉绶 819(行500/隶319)  傅山 694
文征明 679  宋徽宗 500  张瑞图 500  怀素 500(草)  成亲王 500
李阳冰 500(篆)  沈周 500  陈道复 500  王福庵 129(篆)
```
⚠ **文征明(wild) vs 文徵明(50k) 是同一个人、两种写法**，别误当新书家。
**选用 怀素**（狂草，风格最独特，500 张够做 K 扫描）。

### 实现（4 处）
1. **`src/train/train.py`** — 预训练书家表比新表小时，不再 assert，
   新行用**已有书家的均值**初始化（`--init-new-callig mean|zeros|random`）
2. **`--train-only-new-callig`** — 冻结全部，**只训书家表新增行**。
   ⚠ `requires_grad` 是**逐张量**的，无法只放开某几行 →
   整表放开 + **grad hook 把旧行梯度清零**（保证已训好的 45 个不漂移）
3. **`tools/build_fewshot_csv.py`** — 从 wild 目录生成 few-shot train/eval CSV。
   文件名(**不含扩展名**) 就是字符；字符→标准字形映射取自 50k
   （wild 里 17/500 个生僻字在 50k 没出现过 → 无 std_path → 跳过，
   否则 g=ZERO 字条件失效）。
   ⚠ **先切固定 eval 块，再从剩下池里取 K** —— 否则不同 K 的留出集
   不一样，K 扫描无法横向比较（实测踩过，已修；现在各 K 的 eval md5 相同）
4. **`v13_fewshot_k{5,10,20,50}.json`** + `_review/launch_fewshot.sh`
   num_calligraphers 46 / batch=K / lr 1e-3 / cond_drop 0.0 / max_steps 500

### 数据
```
怀素-草 500 张 -> 有标准字形 483 -> 去重每字一张 483
eval 100 张（固定）  train K 张（K=5/10/20/50）
```

### 判据（基线必须先测）
- 先 `--eval-only`（不训，新行=均值）拿到 **ssim_base**
- 再训 K=10 拿 **ssim_k10**
- **ssim_k10 明显高于 ssim_base** → 单向量能捕获新书家 → 该上多 style token
- **两者差不多** → 单向量装不下风格，多 style token 才对症
