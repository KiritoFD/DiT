### 【★ 诊断】seen 与 strict 分叉 —— 不是经典过拟合，但评测设计有缺陷
v13 base 到 step 150k 的轨迹（每 5k 评一次）：
```
step   seen    strict
10000  0.5348  0.5216

100000 0.6447  0.5450

```

**判断：不是经典过拟合** —— 经典过拟合是验证指标**下降**，而 `strict` 一直在**微升**
（95k 0.5440 → 150k 0.5530，+0.009/55k 步），只是**平台化**。

**但 `seen` 根本不该用来判断过拟合** —— 它是 **20 张训练集内的图**，模型直接记忆它们，
上升是必然的、**不含泛化信息**。这是**评测设计的缺陷**：seen 与 strict 语义不对称。

**真问题有三条**：
1. **训练量远超数据量**：150k 步 × 360 batch = 5,400 万样本 / 50,786 张
   = **已过 1,063 个 epoch**，每张图被看了 1000+ 遍
2. **评测采样太少**：`strict` 有 250 行但配置写的是 `:50` → **只评前 50 张**（噪声大）；
   `seen` 只有 20 张
3. **缺"真正的验证集"**：现在只有两个极端（训练图 / 未见字组合），
   缺中间档 —— **留出图 + 已见的字组合**，这才是区分"记忆 vs 泛化"的关键

- **让它跑完**（还剩 ~6.4h）：LR 还在 3.94e-05，cosine 到 250k 会衰减到 1e-05，
  通常还有一波提升；strict 也还在升，没到退化点
- **改评测**：strict 采样 50 → 250；`seen` 改名 `fit`（语义明确）；
