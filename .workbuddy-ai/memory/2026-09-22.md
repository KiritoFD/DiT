### ★ 关键发现：**ssim 对"字形正确性"完全不敏感**
v15c_fixed 210k，seen 20 样本：
| 指标 | 值 | 解读 |
|---|---|---|
| ssim | 0.5697 | "还不错" ✗ **误导** |
| **OCR 字准率(rapidocr)** | **0.15** | 20 字只对 3 个 |
| **OCR 字准率(Qwen3-VL)** | **0.30** | |
| KID (inception) | 0.170 | |
| **GT 图的 rapidocr 准率** | **0.45** | ← rapidocr 上限 |

**归一化: 0.15 / 0.45 = 33%** ✗ —— **生成图可读性只有真实书法的 1/3**

**ssim 0.57 完全掩盖了"字写不对"** ✗ —— 因为 SSIM 只看局部结构相似度，
笔画位置大致对但糊成一团也能到 0.5+ ✗

### ⚠ 但 Qwen3-VL-4B 也不可靠
**GT 图的 Qwen3-VL 准率只有 0.05（5%）** ✗✗✗ —— 比生成图(30%)还低 ✗
明细: `gt=欄 vlm=嘆`、`gt=敢 vlm=報`、`gt=厲 vlm=厲 ✓`
**看图验证过: gt0.png 确实是「欄」** ✓ csv 对齐没问题 ✓
→ **是 VLM 认不准书法** ✗（生成图更"规整"所以反而认得更准 ✗）

**所以 OCR 指标需要更强的 VLM（7B/32B）或换思路** ✗
