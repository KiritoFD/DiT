## 【★★★ 重大 bug】batch_eval 把 ckpt args 强制转 dict -> 所有架构参数被静默忽略

### bug
`src/eval/batch_eval.py:93-96`
```python
a = ck0.get("args", {})
if not isinstance(a, dict):
    a = vars(a) if isinstance(a, _ap.Namespace) else {}
# -> a 永远是 dict！
```
但下游用 **getattr**：
```python
model = build_model_from_args(a, dev)      # 内部 getattr(a, k, d)
apply_post_construction(model, a)          # 内部 getattr(a, k, d)
```
**dict 没有属性 -> ckpt 的架构/开关参数全部走默认值** ✗✗✗

### 两个后果
1. `freeze_callig_table` 取不到 -> 不调 `freeze_table()` ->
   ckpt 里的 `y_callig_embedder.null_embed` 成 unexpected key ->
   **strict 加载失败**（v13 系列因此完全评不了）
2. `cond_drop_*` / `glyph_vec_cond` / `image_channels` 等**全用默认**
   -> 独立 eval 与训练内 eval 口径不一致

### 实测影响（seen 20 样本）
```
v13base_155k:  0.5697  ->  **0.7590**   (跃升 0.19!)
```
**与历史训练内记录 0.7691~0.7723 对上了** ✓
-> **之前所有用 batch_eval 的独立评测都不可信** ✗

### 修法
用一个 `_AttrDict`（dict 子类 + `__getattr__`），同时支持 `a.get(k)` 和 `getattr(a,k)`
（Namespace 没有 `.get`，纯 dict 没有属性 -> 都不行）
备份: `src/eval/batch_eval.py.bak_dictbug`
已提交 `15df161`

### 顺带确认的正确做法
`src/eval/model_io.py` 的 `load_model_from_ckpt` 是对的（它做了 `Namespace(**a)`）✓
