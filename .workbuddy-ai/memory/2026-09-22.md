## 【★★★ 重大 bug】batch_eval 把 ckpt args 强制转 dict -> 所有架构参数被静默忽略

### bug
`src/eval/batch_eval.py:93-96`
```python
a = ck0.get("args", {})
if not isinstance(a, dict):
    a = vars(a) if isinstance(a, _ap.Namespace) else {}
# -> a 永远是 dict！
```
但下游用 **getattr**：
```python

```
**dict 没有属性 -> ckpt 的架构/开关参数全部走默认值** ✗✗✗

### 两个后果
1. `freeze_callig_table` 取不到 -> 不调 `freeze_table()` ->
   ckpt 里的 `y_callig_embedder.null_embed` 成 unexpected key ->
   **strict 加载失败**（v13 系列因此完全评不了）

-> **之前所有用 batch_eval 的独立评测都不可信** ✗

用一个 `_AttrDict`（dict 子类 + `__getattr__`），同时支持 `a.get(k)` 和 `getattr(a,k)`
