# Task: char 条件信号——什么信号是"好"的

## 目标
回答：给 base model 的 char 条件信号，怎么做才能**同时具备区分度与正确性**；
并通过实测比较多种"信号处理方案"，找出最优解。

## 成功标准
1. 建立**可量化判据**：能说清"好信号"长什么样（不只是 ssim）。
2. 实测 ≥5 种处理方案，给出对比表与结论。
3. 检索并归纳相关工作（Few-shot Font Generation 等）的做法，与我们的方案对齐。
4. 产出可执行建议（下一步做什么）。

## 关键认知（本任务起点）
对**查表式** char embedding，区分字不靠 embedding 距离（查表天然唯一），
而靠 embedding 是否携带**正确的字形结构**且**形近字之间不混淆**。

**核心判据：三层次 cos 必须有序**
```
cos(同字跨书家/跨样本)  >  cos(形近字)  >  cos(随机字)
       高                     中              低
```
当前 DINO 特征的问题是**层次错乱**：
- 同字同书家 0.817、同字跨书家 0.790
- 异字 0.600
- **形近字 0.986（土/士）、0.975（王/玉）** ← 比同字还高！

→ "土"的 embedding 更像"士" → 模型生成时会混淆形近字。这是当前信号最根本的病。
