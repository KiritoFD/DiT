诊断: MSE=0.32 但 SSIM=0.0036 的原因

SSIM 极低但 MSE 也不高，最可能的原因:

  • 全局 SSIM 公式问题: 用的简化全局 SSIM (整图当一个窗口), 书法图大部分白底 (mean~0.9, var~0.05), pred 如果颜色分布稍有偏移, SSIM 就接近 0
  • pred 可能是均匀灰色或噪声: MSE=0.32 在 [0,1] 域不算特别高 (随机噪声 MSE≈0.33), 但如果 pred 是均匀灰 (如全 0.5), MSE = mean((0.5-gt)^2) ≈ 0.1, SSIM 接近 0
  • 55k 步对 pixel diffusion 仍偏早: 训练 loss 0.012 说明 eps 预测在学, 但生成链 (从纯噪声到 coherent 图) 需要更多步数才出现
  • cfg=4.0 可能过高: 从零训练的模型, 条件 embedding 还没学好, cfg=4.0 放大了噪声方向, 可能把输出推向灰雾

关键判断: 看 pred 图 —— 如果全是灰雾/噪声, 说明模型还没学会生成, 需要继续跑; 如果有字形轮廓但模糊, 说明方向对但需要更多步数。
