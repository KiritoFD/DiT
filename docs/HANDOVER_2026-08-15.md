## 0. 任务目标与当前状态（先读这个）

**目标**：生成以「书家 calligrapher × 字形 glyph」为条件的书法字（256×256，latent DiT），
重点解决稀疏组合（0.264% 覆盖）下的泛化。用户最终决策：

1. **script 不是独立第三因子** → `glyph = script×character` 合并为一个类（`glyph_id = script_id×7026 + character_id`，共 35130 类，活跃 21495）。
2. **模型**：`DiT-2Cond-S/2`（depth=12, hidden=384, heads=6, patch=2）+ `factorized_add`
   条件（callig 128 + glyph 192 → 投影相加），39.58M 参数，**从头训练**。
3. **V3-A 可组合 score**：4-way mask 训练（full 60% / callig-only 15% / glyph-only 15% / uncond 10%）。
4. **结构损失**：主 batch=12，**每张都算全量 pixel canny + skeleton loss**，权重 w_canny=w_skel=1.0。
5. **每个 ckpt 保存 5 张取样图**（含 step0 初始化 base），供"一行=一个 ckpt"的历史海报展示。

### 当前正在跑的训练（**XL 甲2 标准字形条件 · 楷隶 · v3b**，勿干扰）
**核心突破（2026-08-16 15:07）**：之前所有方案（factorized_add / xl_highdim 保留头 / latent skel_head）图都乱码，根因是**光靠离散 ID 条件学不会 21495 种字形拓扑**。改为**标准字形空间条件**：
- **标准字形 latent 库**：本地 sd-vae-ft-ema encode 楷体(simkai)/隶书(SIMLI)渲染 7923 字 → (4,32,32) latent，传到远程 `std_glyph_latent/`。
