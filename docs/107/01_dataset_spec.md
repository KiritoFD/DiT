## 4. 汉字与稀疏性

| 项 | 值 |
|---|---|
| 训练集唯一汉字 | **4,677** |
| 词表汉字（char_table） | **4,690**（多 13，来自源池未入选样本）|
| `character_id` 唯一 | 5,660 |
| `glyph_id` 唯一 | 7,193（glyph 比 character 更细，含同字异形）|

| ≥2 张真迹的组合 | **4,865 个**（覆盖 12,213 张 = 47%）|

## 5. 评测集的组合泄漏（关键）

`eval200_fixed.csv`（187 张）与 `train.csv`：
- **样本级 0 泄漏**（img_id / image_path / src_image_path 均无交集）✓
- **组合级 75/187（40%）的 `(书家,书体,字)` 在训练里出现过** ⚠ —— 且该子集对所有模型都更容易（v68 +0.0576 / v66 +0.0771）。
- 分档里 Best 62 张含 **53%** 组合见过 → **Best 档的绝对分偏高**，引用时必须按"组合未见 112 张"或各分档严格口径（见 [02](02_model_benchmarks.md) 与 `exp-std/csv/eval200_split_midstrict.csv`）。

## 6. 三个口径坑

1. **4,677（train.csv 里的字）≠ 4,690（词表）**。
2. **`character_id`(5,660) / `glyph_id`(7,193) / `character`(4,677) 三者不同**，不是一对一 —— 编码脚本按号段反解会错位（aug 数据踩过 `-1` 的坑）。
3. **`imgs_aug_sym` 目录里没有原图**（只有 tp/tn 变体）。
