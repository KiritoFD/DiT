## 0. 一页结论（TL;DR）

1. **旗舰 v68（Sp/2 59.1M + 3x增强 + C2OT，200k 步）同协议 SSIM = 0.6169**，比 MoYi 4ch（252M，80k）高 **+0.0183**（p=6.6e-6）、比 MoYi 12ch（252M，50k）高 +0.0404。
   **但**"明显更强"不成立：① 墨迹 IoU 反而**更差**（vs 4ch −0.0215，p=0.019）；② **最难 25% 的字打平甚至更差**；③ 我们的采样算力是 Moyi 的 **2 倍**（Heun 50 步 ≈ 100 NFE，Moyi 用 Euler 50 NFE），优势里有多少属于采样器**未拆开**。
2. **真正的硬约束不是"打不过 MoYi"，是"未见组合"。** 组合未见 112 张上 v68 = 0.5934，只比"跨书家取最近真迹"这个检索基线 0.5743 高 0.019；而组合见过 75 张已达 0.6520 ≈ 真迹参照线 0.6503（这部分是**记忆红利**，Best 档里 53% 组合见过）。
3. **唯一量级巨大的已知改进方向是 VAE**：FLUX 16ch 的往返 skel_iou 0.7929 → **0.9942**（断线率 20.7% → 0.58%），理论上限 0.650 → 0.658。**但**唯一一次端到端（v63b）55k 停在 **0.478 惨败**，疑似 flux VAE 的 latent scale/shift 因子没接对 —— **要先修再验，不是方向错**。
4. **三件事测不出来 / 没证据**：
   - 数据增强：唯一同频点 **+0.0013**（且 aug 臂 LR 高 8.7%）；条件侧增强 45k 步**零增益**且自设判据（frag）失败。
   - C2OT：只有数学无偏性 + 单元测试（跨槽位配对 0、先验偏差 0.3064→0.0039、代价 −2.4%），**零质量证据**；干净单一变量臂 `v67` 已就绪但**从未跑**。
   - 模型变大：**无反转点**（33.9M–458.6M），且**样本数比参数值钱**（每 10× 样本 ≈ +0.065，参数翻倍 ≈ +0.01~0.026）。
5. **参照上界（全数据集穷举，解码域）**：**条件平均 0.6503 / 均匀抽对 0.6235**。`DOC-105-04` 的 0.6588 是 300 键抽样（偏高、不稳健），且它的天花板公式 `0.6588×√0.8200≈0.6280` **算错 + 重复扣减**（勘误见 [03](03_evidence_grade_and_errata.md)）。
