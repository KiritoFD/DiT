## 0. 问题（一句话）

> **术语与口径**：本文以 **v68（SD-VAE 数据集）** 为对照**基准**（它是拿到 SDE 正收益的那一档）；
> 实验（experiment）协议见 §1，指标口径（protocol）见 §1.2，候选解释见 §5，给专家的数学问题见 §6。
> **本文件不给最终结论** —— 目的是把事实、数据与方程交给专家做数学判断。

我们的生成主干是 **linear-interpolant flow matching**（SiT 家族）。把 ODE 采样器换成 **SiT 随机插值 SDE 采样器**（γ>0，代码见 §2）后：

- 在**用 SD-VAE 的数据集**上（模型 v68）：**SSIM +0.0091、frag −53%**（明显获益）；
- 在**用自训 Calli-VAE 的数据集**上（模型 v72 / v79）：**SSIM 增量 ≈0 或为负**（v72 甚至 frag 变差 +12%）。

**问题**：同一采样器、同一评测协议、同一批 187 张图，**为什么收益随 VAE 而翻转？是何种数学条件被破坏了？**

## 2. 采样器的**精确更新式**（逐行来自代码）

`src/loss/flow_matching.py` L478–L498（原文）：

```python
elif use_heun:
    v1 = self._v(model, x, t_batch, model_kwargs, C)
    x_euler = x + dt * v1
    t2 = ts[i + 1].expand(B)
    v2 = self._v(model, x_euler, t2, model_kwargs, C)
    v_eff = 0.5 * (v1 + v2)
else:
    v_eff = self._v(model, x, t_batch, model_kwargs, C)

# ── SiT SDE 随机纠偏采样器 (Stochastic Interpolant SDE Sampler) ──
if self.sde_gamma > 0:
    h = -dt                      # 正步长
    drift = v_eff * (1.0 + (self.sde_gamma ** 2) * t_i)
    noise_scale = self.sde_gamma * th.sqrt(th.clamp(2.0 * t_i * (1.0 - t_i) * h, min=0.0))
    x = x + dt * drift + noise_scale * th.randn_like(x)
else:
    x = x + dt * v_eff
```

**符号**：`t` 从 1 积分到 0（故 `dt < 0`，`h = −dt > 0`）；`t_i` 为当前时刻；`γ = sde_gamma`（本文件全部实验：**γ=0 与 γ=0.5**）；`ξ ~ N(0,I)` 与新 `x` 同形。

写成连续形式（令 `Δt = h`）：

```
x_{i+1} = x_i + (−h)·(1 + γ²t)·v_eff(x_i,t) + γ·√(2t(1−t)h)·ξ
```

**要点（供专家核对）**：

1. **漂移系数为 `(1+γ²t)`**，即只对速度场做**乘性放大**，**没有显式出现 score 项**（即没有 `(g²/2)∇log p_t` 的独立计算）；
2. **扩散系数 `g² = 2γ²t(1−t)`**：在 `t=1` 与 `t=0` 两端**同时归零**，峰值在 `t=0.5`；
3. 该实现隐含地把 score 写成了与 `v_eff` 的某个代数关系（`(g²/2)∇log p_t ≡ γ²t·v_eff` 的形式）。**该恒等式对 `x₁~N(0,I)` 与"数据端为任意分布 `p₀`"的插值是否严格成立、是否依赖 `Var[x₀]` 的取值 —— 这是请专家首先核对的地方。**
4. 采样起点：`x_T ~ N(0,I)`（`flow_matching.py:437` `x_T = th.randn(*shape)`）；`clip_denoised=False`。

## 4. 观测到的规律（全部可复核）

1. **SDE 一律降低高频**：v68 HF/GT 0.811→0.760、v79 0.647→0.622；逐图配对中位数同样下降。
   → **SDE 不是"免费"的**：它在修复连通性（frag）的同时**付出高频代价**。
2. **SSIM 增益与 frag 的绝对修复量同向**：v68 frag 5.06→2.38（**绝对 −2.68**）换来 SSIM **+0.0091**；v79 frag 1.88→1.47（**绝对 −0.41**）只换来 **−0.0011**。
3. **SDE 收益与"数据端幅度/噪声端幅度"同向**：存盘 std 1.07（v68）获益最大；0.198（v72/v76）获益为零甚至为负；0.996（v79）部分获益。
4. **SDE 收益与后验宽度反向**：后验相对宽度 4e-5（SD）获益最大；0.277（物理）部分；0.391（DINO）**有害**。
   ⚠ 注意 3 与 4 在本数据里**共线**（SD/物理/DINO 三档同时满足"std 更接近 1"与"后验更窄"），无法据此区分。
5. **观察 5（备查）**：SDE 对 v68 的收益在 TOP/MID/WORST 三段上均匀，说明并非"只救简单样本"。

## 5. 候选解释（含支持/反对证据与可否证实验）

### H1 — 分数恒等式依赖"数据端方差为 1"，我们的尺度缺陷破坏了它
- **机制**：代码的 SDE 漂移只做了 `v_eff·(1+γ²t)`；若其隐含的 score–v 恒等式在数据端方差 ≠ 1 时不成立，则**纠偏力被错误缩放**，注入的噪声失去与之匹配的"拉回力" → 表现为**掉高频但不修 frag**（正是 v72/v76 的现象）。
- **支持**：收益次序与存盘 std 同向（§4.3）；v68 的 std=1.07 最接近 1；v72/v76 的 0.198 偏离最远。
- **反对**：v79 的 std=0.996（几乎完美）却仍拿不到 SSIM 增益（只拿到 frag −22%）。
- **可否证实验**：在 v68 的数据上人为把存盘 latent 乘以 5（数据端幅度 5，噪声端仍为 1）→ 若 SDE 收益按该方向恶化，则 H1 成立。（代价：需重训 DiT。）

### H2 — 宽后验 ⇒ 训练目标自带噪声 ⇒ 模型学到的分布天生模糊
- **机制**：DiT 的目标是 `z ~ q(z|x) = N(μ, σ²)`（我们 `encode_mode=sample`）。`σ/|z| = 0.28`（SD 为 4e-5）意味着每个字对应一个**球**而不是一个点 ⇒ 模型学到的先验是 μ-流形被 σ 卷积后的版本 ⇒ **SDE 只是采样器，只能从"已学到的分布"里采样**，无法补出模型没学到的细节；而注入噪声又把这个本已模糊的分布**推得更宽** ⇒ 高频下降、frag 修复有限。
- **支持**：后验宽度次序与收益次序一致（§4.4）；SDE 完全无法提升"用掉天花板"的比例（v79 0.718→0.690）。
- **反对**：与 H1 共线；且 v72（0.391）与 v79（0.277）的差异也可能只是基线 frag 差异（H3）。
- **可否证实验（便宜，~4h）**：用 `--w-std`（后验 std 惩罚）或 `--logvar-max`（硬夹紧 σ≤0.011）把后验压成点质量 → 重编码 → DiT 训 35k → 重测 SDE。判据：**frag↓ 且 HF 不掉**是否随之后升。

### H3 — "无事可修"：SSIM 增益本来就是 frag 修复的副产品
- **机制**：SDE 的随机项 + 纠偏 = 对邻近 latent 状态做加权平均 ⇒ 平滑。若基线已经平滑/连通（frag 低），则**没有可修复的错误**，却照付平滑代价。
- **支持**：§4.2 的定量同向；v79 的基线 frag 1.88 已低于 v68 **用 SDE 修完之后**的 2.38；v68 的收益量级（+0.0091）与其 frag 绝对修复量（−2.68）量级匹配。
- **反对**：v72 的基线 frag 2.57 **高于** v79 的 1.88，SDE 结果却相反（+12% vs −22%）→ **单靠 H3 无法解释符号翻转**。

### H4 — 离散化误差不足
- **机制**：SDE 修复的是 ODE 的**离散化/轨迹**误差；若 ODE 已收敛，则无可修。
- **支持**：步数扫描显示 `SSIM(10 步) ≈ SSIM(200 步)`（即 50 步已收敛）；且 CFG 扫描显示高 CFG 下 SDE 收益消失。
- **反对**：若仅此一条，无法解释 v68（同为 heun-50）为何仍能获益 +0.0091。

### H5 — SDE 参数化/系数本身的正确性问题
- **机制**：`drift = v_eff·(1+γ²t)` 与 `g² = 2γ²t(1−t)` 是否构成某个**正确**的 SDE（即其 stationary/marginal 是否等于 `p_t`）？若系数不匹配（例如缺少 `(g²/2)∇log p_t` 的精确形式，或 γ² 的量纲位置不对），则 γ=0.5 时注入的噪声与纠偏力**不成比例**，恰好表现为"掉高频、不修 frag"。
- **支持**：现象（平滑但不修连通）与该假设的预测一致；且 **γ=0 完全不受影响**（因为整段代码被 `if γ>0` 跳过）——这与"ODE 一直正常、只有 SDE 表现异常"的观测一致。
- **反对**：无直接反证；但该假设与"VAE 相关"无关，而收益确实随 VAE 变化 → 若 H5 单独成立，收益应**与 VAE 无关**。**H5 与 H1/H2 可能共同作用。**
- **请专家做的核对**：给出该插值下 `∇_x log p_t(x)` 与 `v(x,t)` 的精确关系，并检验代码系数是否满足；特别是**当 `Var[x₀] ≠ 1` 时该关系如何变化**。

### H6 — 评测/口径伪影（须先排除）
- **机制**：SSIM(frag 之外)对本问题的敏感性不足；或两次生成用了不同 ckpt / 不同 VAE / 不同 cfg。
- **排除依据**：γ0/γ0.5 用**同一 ckpt、同一 VAE、同一 cfg、同一随机起点协议**，仅 `sde_gamma` 不同；v68 的正增益与 v72/v79 的零/负增益都在这套协议下得到（同一脚本）。
- ⚠ 但仍遗留一条**已知口径缺陷**：LPIPS 在训练侧（vgg）与本地（alex）不一致（§1.2），**本文件中比较 LPIPS 的结论只在同一表内有效**。

## 8. 追加（2026-10-11 晚）：**SDE 漂移实现 bug 与修正**（由外部专家指出，已数值确认）

### 8.1 旧实现的错误

代码原文（修正前）：

```python
drift = v_eff * (1.0 + (self.sde_gamma ** 2) * t_i)     # ← 只给速度乘系数
x = x + dt * drift + noise_scale * th.randn_like(x)
```

正确推导（线性插值 + **独立**高斯配对）：

```
连续性方程       ∂_t p = −∇·(p v)
SDE 的 FP 方程   ∂_t p = −∇·( p [ b − (g²/2)∇log p ] )
要求同边缘 ⟹     b = v + (g²/2)∇log p_t
Tweedie          ∇log p_t = −(x + (1−t)v)/t ,   g² = 2γ²t(1−t)
⟹                b = v + γ²(1−t)[ x + (1−t)v ]          ← 含显式 x 项
```

### 8.2 数值确认（本次独立复现，与专家给的两行数字逐位吻合）

判据：完美速度场下解**精确方差 ODE** `dV/dt = 2a(t)V − g(t)²`（时间 t:1→0 倒退积分，故噪声项取负）
—— 终点方差必须严格等于 `s0²`。

| s0 | 理论 | **旧式** | **修正式（加号）** | （错写成减号会得到） |
|---|---|---|---|---|
| 1.00 | 1.0000 | **1.0432** | **1.0000** ✓ | 1.3068 |
| 0.50 | 0.2500 | 0.2586 | **0.2500** ✓ | 0.4043 |
| 0.20 | 0.0400 | **0.0470** | **0.0400** ✓ | 0.0951 |
| 0.10 | 0.0100 | 0.0137 | **0.0100** ✓ | 0.0335 |

γ 依赖（s0=1.0）：旧式 γ=0.5 偏 **+4.3%**、γ=1.0 偏 **+26%**；修正式在所有 γ 下恒精确。

**端到端复验**（`tools/analysis/sde_e2e_test.py`，用**真实采样代码** + 线性完美速度场）：

```
s0=1.00 γ=0.0 → 1.0002 ✓    s0=0.20 γ=0.0 → 0.0401 ✓
s0=1.00 γ=0.5 → 1.0004 ✓    s0=0.20 γ=0.5 → 0.0409 ✓   （修正后）
```

### 8.3 对本文档前面结论的影响（必须诚实写明）

1. **旧式确实错**（缺少 score 修正项、Heun 与修正不可交换）→ 已按专家公式修正，
   并额外修正了 **随机 Heun 一致性**（对修正后的漂移做 Heun 平均，predictor/corrector 共享同一噪声增量）。
2. **但旧式的终点方差误差在 γ=0.5 只有 +4.3%** → **它大概率不是"无 SSIM 增益"的主因**。
   §4/§5 的**任务层解释（frag↔高频权衡、基线已连通）仍然成立且仍是首要候选**。
3. **中间过程的自我更正记录**（供复核）：本次一度判断"专家公式符号写反"，
   原因是**本文档作者的方差 ODE 把噪声项符号写正了**（时间倒退积分时应为负）。
   用正确符号后，专家公式逐位精确 —— **专家推导从头正确**。
4. **前提仍然成立**：该式要求 `x0` 与 `ε` **独立配对**；**C2OT/OT 会改变配对**
   （`_apply_c2ot` 返回 `noise[perm]`）→ **启用 SDE 的模型必须 `use_c2ot=False`**。
5. **因此**：所有历史 SDE 结论（v68/v72/v79）都是在**旧式 + C2OT** 下测的，
   **需要在独立配对训练的模型上用修正式评测**后才能检验边缘保持；仅在推理时关 OT 不会改变旧 checkpoint 的训练耦合。v80 是满足该前提的新训练臂；不能把本条解释为旧 C2OT checkpoint 只改 sampler 就获得理论保证。
