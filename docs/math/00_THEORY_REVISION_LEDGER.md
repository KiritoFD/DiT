# 理论修订账本：从实验反例到可检验的数学解释

> 这份文档记录**2026-10-31 阶段的理论修正，而非新理论的“证明清单”**。每一行保留之前容易产生的过强说法、触发修正的实际数据、现在允许说什么以及能够推翻它的下一次试验。详尽推导见 [01–05章节](README.md)。

| 旧观点（过强） | 冲突数据或严格反例 | 修正后成立的说法 | 必需的新证据 |
|---|---|---|---|
| “std-skel一开始就不能学习，纯STD条件天然低上限” | [616条旧ledger直接复核](../1031/06_RAW_DATA_RECONCILIATION.md)：v70相对v68 **5k +.01164**、30k **−.00379**、65k **−.02977** | 表现是**早期相对受益、后期掉队**；可能涉及训练优化/注入/数据而非固有信息容量定理 | 同架构等步数/等FLOPs与分t的STD条件反事实风险 |
| “同条件真实书法SSIM上界是0.65；超过就泄漏” | 实测真迹条件平均 **.6503**、均匀抽对 **.6235**；历史均值预测和best-of-k的相似度不同 | 这只是**真实图与真实图的某协议经验相似度**，不是SSIM的数学极大值 | 同固定条件的随机真迹、可控生成样本分布评价，而不是只盯SSIM |
| “Writer只有0.5%的信息，因此很弱/易压缩到低维” | DINO平方能量 Writer mean **.5%**、内容 **93.9%**；留字线性Writer Top1仍 **43.6%**，E-G真实pair AUC **95.98%** | 能量小、判别能力和所需生成容量**是不同量**；7个有效判别维不决定生成器的维数 | Writer-FM风险差、同字同噪声swap、局部feature及来源留出 |
| “Writer×STD交互已经证明不存在” | DINO双线性 M2留字 `ΔR²≈3.2e−8`，但逐字草化和Writer×字残差确实存在 | 仅证明**当前DINO特征+简单聚类/低秩调制**没有额外可泛化预测力；不否定真实词汇性Writer差 | 严格留字的生成反事实；若局部调制对真实同字分布有独立净益再重启 |
| “仅训练t=1 Writer Pair就能学到书家完整差异” | 精确FM `v_w^*(ε,1)=ε−E[Z_0\mid w,g,s]` | 噪声端对同z的Writer差**只含第一矩**；协方差/多种写法在中t才可被完整条件score体现 | 同位置分t FM风险差、速度差跨噪声方差、真实swap分布 |
| “同一噪声下两个Writer的中t差即Writer纯效应” | `z_t^a=(1−t)z_a+tε` 与 `z_t^b=(1−t)z_b+tε` 位置不同 | 必须**固定同一个 z_t**，只置换Writer，才能隔离条件网络作用 | 对同一 `(z_t,g,s,ε)` 的correct/wrong/null前向 |
| “正确Writer一定逐样本FM loss最低” | 数学保证仅Bayes最小**期望**风险：`R_0^*−R_1^*=E‖Δv_W^*‖²≥0` | 有限模型、噪声、写法多模态、支持域差异可令某些样本/时间点错Writer损失更低 | 按Writer×char×time配对CI，不做单样本绝对断言 |
| “4ch打败12ch说明一切结构监督无用” | MoYi同50k `.5935→.5949`；等权12ch辅助梯度约51%，且CFG/latent合同存在事故 | 当前12ch在该预算下没净益；结构标签可能有新信息，但需解决**梯度竞争、稀疏性与合同错误** | 同NFE/模型/数据的4ch/12ch+各层梯度cosine；拓扑人工校验 |
| “骨架SSIM好说明中间SkelNet有效” | v45骨架SSIM **.6484** vs基线 **.6410**，IoU **.0870** vs基线 **.1044** | 对稀疏线条/连通性，SSIM可能被背景支配；两阶段还有预测骨架的分布偏移 | 阶段1预测骨架 vs GT骨架作为阶段2输入的oracle差、连通/缺笔评测 |

| “A首点提升说明多训5k有效” | A首点 val100 `.5857→.5914`，同时修正了 LR及cosine重启 | 能证明**新的5k联合干预有收益**，不能给步数单独因果记功 | 同restart/LR对照后再分离训练长度效应；A后续同协议纵向 |

| “SDE γ=.5是任何模型的free lunch” | v80 corrected链 SSIM差 **+.000576**、CI跨0；Frag **−.071973**边际正向 | 精确场+独立高斯+正确score漂移可保边缘；近似模型的质量变化**依赖时间与误差** | 同NFE、固定CFG/模型/seed的独立val选窗+test确认 |

## 总结：新理论应提供四个可独立验证的杠杆

**条件速度场**：由Writer条件多减少多少FM风险，在哪个t真正发生；**内容/交互**：同一char是否被Writer条件破坏且是否属于合法异写；**成像**：在同latent下Decoder变化能带来何种画质/结构收益；**迁移**：等目标曝光、等总算力下预训练是否改变未见字风险。

上述四杠杆不构成声称各项非负可加的“总误差定理”，更不是基于某个样本SSIM的上界论证。它们是一套**能被真实数据推翻的研究问题分解**。
