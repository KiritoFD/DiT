# 历史全实验总天梯榜与里程碑评测 (Master Leaderboard)

## 1. 评测协议与度量指标

所有实验均采用统一的无损内存内评测协议（`in_mem_eval`）与固定种子采样：
- **Strict SSIM (严苛外推保真度)**：在完全未见过的汉字上测试模型遵循书法家风格的形变准确度（决定天梯排名的第一核心指标）；
- **Seen SSIM (重构保真度)**：在书法家已知字形上的重构质量上限；
- **MSE / LPIPS**：均方像素误差与感知特征差异（LPIPS 越低，视觉质感越自然真实）；
- **Target Specificity (目标专属性增益)**：$\Delta = \text{SSIM}(x, y_{tgt}) - \max_{j \ne tgt} \text{SSIM}(x, y_j)$，衡量生成字形是否精确展现该书法家的独特性而非平庸的通用字形；
- **Calligrapher Enrichment (书法家富集倍率)**：同字最近邻命中该书法家真实样本的统计概率比率（$>1.0\times$ 表示模型具有明确的书法家专属风格吸附力）。

## 3. 历史断代与核心突破总结

1. **第一纪元（v1 - v8，2026年8月）**：探索潜空间与像素空间的表征方式。证实了离线 VAE 潜变量分片存储的绝对优越性；经历了数据反色与空心骨架的阵痛；
2. **第二纪元（v9 - v12，2026年9月上旬）**：攻坚条件注入机制。确立了 Flow Matching 最优传输流匹配范式与 2D RoPE 旋转位置编码；
3. **第三纪元（v13 - v16，2026年9月中旬）**：清洗出 50k 高保真数据集，确定 45 位大师词表；风格编码达到 0.5764 的静态重构天花板；
4. **第四纪元（v17 - v20，2026年9月下旬）**：向“真实形变”发起冲锋。通过 8 组证伪实验排除了 LCA 交叉注意力、多 Token 风格等伪方向，最终收敛出显式 SkelNet 方案；
5. **第五纪元（v21，进行中）**：SkelNet + DiT-2Cond 深度解耦协同训练。目标专属性倍增（$1.91\times$），汉字拓扑绝对防断笔，进入高保真自由创作新纪元。
