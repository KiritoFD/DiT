## 四、条件分布与关系几何（新诊断，置换对照内嵌）

- **J组（187字，10书家/书体，槽均值稳健）**：RDM Spearman 0.46–0.61（置换后坍缩至0.01–0.09 ✓）；方向对齐0.85；幅度比0.66–0.75——**书家间关系与差异方向被正确保留，幅度压缩至约72%**。J2的楷书RDM最高（0.608 vs J0 0.544）。
- **S组（100字面板，6–8书家/书体）**：样本量不足以稳定估计RDM——多个置换对照不降（S7-楷0.60、S6-楷0.59），行书全部为负。仅**S5-楷（0.589，置换0.13）**可初步采信。此结论印证：**关系几何必须等共字同噪声的Writer-Swap面板（GPU）**，现有零散PNG补不了。

## 六、Decoder变化分解（J0 vs J2，187字同条件配对）

HQ特征（Hinge/Quill）逐维平均漂移0.00102（其中Quill仅0.00042），约为真实图间波动基线（0.0052）的1/5——**J2的改善主要是纹理/边缘级，笔画几何与书家笔法统计几乎未动**。支持"Decoder适配留作后期画质步骤，不作为下一代书风建模核心"。注意J0/J2是不同训练分支，此为系统级描述；严格归因需同latent交叉解码（GPU）。

## 七、对下一代架构的含义（按方案第十三节对照）

- E-G可靠且非捷径 + S5身份领先 + 方向对齐良好但幅度压缩72% → **支持继续S5系（Stroke×Spatial AdaGN）结构**，重点补幅度（更强/更正确的书风差分），而非换注入算子。
- S5优势的逐字异质性（C类占1/3）与逐书家差异 → 优先审计Writer条件的数据分布与采样，而非新增模块。
- Hinge/Quill负结果 → 放弃手工特征作为独立裁判；书风证据继续依赖E-G族 + 未来Writer-Swap面板。
- J2纹理级改善 → Decoder与生成器分开优化。
