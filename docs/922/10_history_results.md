## 3. 风格编码实验链（本轮设计的核心证据）

| 实验 | 变量 | strict | 裁决 |
|---|---|---|---|
| v13_base | 45 书家 × 128 维**冻结** | 0.5703 | 基线 |

### 3.1 根因链（四次失败不是同一个原因）

```
v14 失败 → 标签粒度不是瓶颈（45→87 无效）
v15 失败 → 不是容量问题，是"表没区分度"：
             DINO CLS pair 质心间余弦 0.956  ← DINO 几乎不区分书家
             K-Means 表行间余弦      0.860  ← 87 行几乎共线
             同一 pair 内 4 子风格    0.884  ← "多风格"也是假的
v13/v14 的"健康几何" → 是标签驱动的（DINO 锚定因提取 bug 从未生效）
```

### 3.2 逐书家分析（style 是瓶颈的最硬证据）

| 书家 | 训练样本 | strict |
|---|---|---|
| 苏轼 | **3,131**（最多） | **0.3485**（最差） |
| 李邕 | 1,168（风格统一） | **0.6300**（最好） |

```
r(该书家训练样本数, strict) = −0.62
```
样本越多 → 风格跨度越大 → 单向量越装不下。
**32/45 书家跨多书体** → 风格与书体纠缠。

## 4. 注入方式实验链

| 通路 | 实现 | ckpt | strict（墨迹口径 ssim/ink） | 成本 |
|---|---|---|---|---|
| **adaLN（全局）** | `c = t_emb + y_emb` → 每 block 6 调制参数 | v13_base | **0.5711 / 0.3872** ✓ | 1.00× |
| adaLN + K-token mean | v15a | v15a | 0.5488 / 0.3599 | 1.00× |
| + `CalligStyleCrossAttn` | 骨架 token 在 K 个风格模态间寻址 | v15b | 0.5504 / 0.3664 | ~1.02× |
| **xattn（每层 ctx）** | K token 拼进每层 xattn context | v15c | 0.5464 / **0.3562** ✗ | **1.33×** |

**效应量对比**：
```
注入方式之间： |0.5504 − 0.5488| = 0.0016   (v15b vs v15a)
              |0.5464 − 0.5488| = 0.0024   (v15c vs v15a)
表/数据之间：  |0.5711 − 0.5488| = 0.0223   (v13 vs v15a)
```
→ **注入方式的效应量比表/数据小一个数量级，且在噪声内。**

⚠ 但"xattn 无用"的历史结论**有口径污染**（见 `30_injection.md` §2）：
CFG 下 `g2 = cat([g,g])` → 任何"只由 g 驱动"的通路在 `(cond − uncond)` 里**恒为 0**。
xattn 的 Q=x、K/V=g_tok → **完全由 g 驱动 → 被结构性绕过**。

## 7. 踩坑清单（12+ 条，同样重要）

1. 结构损失混入扩散损失**有害**（pixel + latent 双重否定）
2. 数据增广**无信息增益**
3. std-skel 冗余条件被门控忽略（IoU 0.09–0.19）
4. 12ch 从头训**劣于** 4ch
5. **xattn 的 Q 没有位置嵌入**（旧实现只给 K/V 加 sincos）→ 空间寻址退化成内容寻址
6. `cond_drop` 的 drop-guard 元组**漏了 `factorized_cat`** → 训练全程零 dropout（2026-09-17 才修）
7. `null_embed` 加载时被静默丢弃（须先 `materialize_lazy_params`）
8. v13/v15 few-shot 的 g 错位（`img_id=0..149` 命中无关骨架，静默不报错）
9. `--train-only-new-callig` mask bug（MultiStyleEmbedder 无 null 行）→ 训练空转 0 参数
10. `--resume-full` 对通道扩展/表扩行**静默跳过**
11. `repa_layers` 未注册 argparse 被**静默忽略**；`w_repa` 默认 1.0 会悄悄占大头
12. eval CFG bug（`cfg_scale` 塞进 `model_kwargs`）
13. **DINO 提取器 `repeat` 维数 bug 被 `except: return zeros` 吞掉** → 全库特征恒定（09-19）
14. **`batch_eval` 把 ckpt args 强制转 dict → 架构参数全被忽略**（09-22，v13 seen 0.5697→0.7590）
15. AdamW 的 weight decay 绕过 grad hook → 已训好的表被逐步缩小
16. `in_mem_eval` 按 `(step,set)` 去重 → 同名 results_dir 重跑会**跳过每一步评测**
17. 二值化去噪标在亮域而非墨域 → 傅山-行 ink 不降反升
