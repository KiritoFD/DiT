## 2. 架构变量严密裁决：死刑清单与待验变量正名

通过对数百组实验记录（`master_leaderboard.md`）和失败用例（`falsification_registry.md`）的交叉审计，我们将所有争议架构变量严谨解耦，确立了两大明确阵营：

### 2.1 彻底判处死刑的技术伪路径 (Death Sentences)
详见专项文献 [`DOC-105-01`](./01_architectural_death_sentences.md)，以下 7 项在物理与数学机理上已被彻底证伪，**永久禁止引入主线**：
1. **12 通道多模态联合扩散从头训练**：Canny/骨架的边缘噪声倒灌真迹通道，产生永久灰白散斑与边缘毛刺，Moyi 12ch（0.5935）被纯 4ch（0.6085）全面击溃；
2. **12 层无节制空间交叉注意力（xattn）插桩**：背景 92% 空白导致 Softmax 概率弥散与尖峰，引发数值崩溃（v17 SSIM 0.089）或笔画枯瘦中空断裂（v50-A SSIM 0.554）；
3. **单像素细线骨架采用连续 VAE 编解码**：连续高斯低通滤波磨平高频几何狄拉克边缘，细笔画丢失率高达 45%；
4. **大模型容量下的纯随机（RandInit）汉字词表长跑**：缺乏拓扑硬约束，233M 参数走捷径死记硬背训练样本，50k 步时 Seen 飙至 0.6704 而 Strict 卡在 0.5858，泛化 Gap 暴涨至 +0.0846；
5. **高权重自然图像 DINOv2 REPA ($w \ge 0.1$)**：ImageNet 物体级全局语义压制书法单像素笔触动力学，产生油画色块晕染；
6. **无网格约束的纯隐式端到端字形扭曲**：形变位移锁死在 0.08px，陷入局部极小值伪装形变；
7. **多 Token 风格条件外推**：风格通道互信息渗透，生成生僻字时强行拼贴训练集部件，引发严重错别字。

### 2.2 待验现代变量正名与单变量消融设计 (Pending Ablations)
详见专项文献 [`DOC-105-02`](./02_pending_ablation_variables.md)。此前将模型停滞全盘推给“现代组件（RMSNorm、SwiGLU、2D-RoPE、QK-Norm）”属于严重的**多变量混杂过度归因**：
- **铁证实锤**：4090 机器历史最高记录模型 **`v53 (100k, Strict SSIM 0.5875, LPIPS 0.3428)`**，其实际配置文件全套开启了 `rms + swiglu + qk_norm + rope`；
- **科学处置方案**：将 RMSNorm、QK-Norm、2D RoPE、SwiGLU 列为待验高价值构件，在统一的 DiT-B 1024 + 冻结先验三表环境下，严格执行单变量对比隔离消融（`ABL-NORM`、`ABL-QKNORM`、`ABL-ROPE`、`ABL-FFN`），不搞无证据的主观定性。

## 3. 数据集内在物理天花板测算：实测探针严谨推导

针对“完美模型理论上界是多少”的核心问题，我们彻底摒弃经验猜测，基于真实底库 `train.csv`（26,002 样本）与官方代码库，在服务器上编写自动化探针脚本 [`tools/probe_theoretical_bounds.py`](../../tools/probe_theoretical_bounds.py) 实测得出确凿数据（详见专项文献 [`DOC-105-04`](./04_theoretical_upper_bound_probes.md)）：

### 3.1 真实真迹内在书法多模态方差 (Aleatoric Uncertainty)
- **统计规模**：26,002 张真实真迹中，包含 18,654 个独立的 `(书家, 书体, 汉字)` 组合，其中 **`4,865 个组合`** 存在 $\ge 2$ 张完全独立的真实真迹；
- **实测结果（300 对相同书家、同书体、完全同字真实墨迹互测）**：
  $$\mathbb{E}[\text{Intra-Class Genuine SSIM}] = \mathbf{0.6588} \quad (\text{中位数 } 0.6490)$$
  $$\mathbb{E}[\text{Intra-Class Genuine LPIPS}] = \mathbf{0.2781} \quad (\text{中位数 } 0.3042)$$
- **绝对物理含义**：
  书法大师（如王羲之、何绍基）自己写两遍同一个字，互相比对也只有约 **0.6588** 的 SSIM！因为起笔微偏 2 度、墨水干湿不同，高斯局部窗口必然产生约 34% 的内在散度。**在仅依赖离散标签 $(c, s, ch)$ 的条件下，任何生成模型的期望 SSIM 绝不可能突破 `0.6588`！**
