## 2. 核心学术与工程认知修正

1. **确立“死刑”与“待决”的严格界限**：
   - 彻底封死已被严格证伪的技术死胡同，避免后续研究陷入“多通道联合扩散”或“全层插桩描边”的重复试错；
   - 恢复对现代主流高效算子（RMSNorm、SwiGLU、QK-Norm）的客观中立态度，杜绝无单变量控制的武断推论。
2. **破除“SSIM 上限是 1.000”的盲目幻觉**：
   - 由真实碑帖自相关实测探针（`0.6588`）确立了绝对客观参照系；
   - 证明当前 Moyi 4ch (0.6085) 和 Ours v61 (40k 时 0.5821) 已经处于理论天花板的 92%~96% 高度，剩余的竞争空间聚焦在 0.6085 至 0.6350 之间极度精微的结构与笔锋雕刻。
