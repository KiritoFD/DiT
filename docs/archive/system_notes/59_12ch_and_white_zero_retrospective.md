# 59. 12ch 辅助目标 与 白底归零(wz) 复盘：为什么放弃，回到 4ch 原版配方

> 日期：2026-09-15
> 相关：[51](51_moyi_aux_alignment.md)（aux 结构通道逐行核对）、[52](52_ref_model_alignment.md)（ref 主模型精读）、
> [54](54_results_and_insights_20260913.md)（结果总表与 insights）、[56](56_white_zero_polarity_and_alignment_fixes.md)（白底/极性修复）、
> [58](58_cfg_channel_fix_and_canny_polarity.md)（CFG 通道数修复）
>
> **结论先行**：12ch 在我们的架构里不是"辅助任务"，而是主任务的**竞争对手**；
> 白底归零理论上有收益但**从未被验证**，却已经造成了一次"生成图全黑/发黄"的事故。
> 两者一并放弃，回到 **4ch + g 骨架条件** 的原版（v10b 0.5680）配方。

## 0. 现象：同一份数据、同一个模型，两条线的差距

| 实验 | 数据 | 目标 | 出字形 | 同期 strict |
|---|---|---|---|---|
| `v11_pretrain_Sp2_base`（**4ch**） | base 54,892 | 4ch | **~30k** | 0.4376 @47.5k |
| `v11_pretrain_Sp2_base_wz`（**12ch + wz**） | base 54,892 | 12ch | **>42.5k 仍未** | 0.4244 @42.5k |

指标上两者接近（0.4376 vs 0.4244），但**图像完全不同**：4ch 线在 42.5k 字形已可辨，
12ch 线到 42.5k 仍是**墨团**。

**⚠ 这里暴露了一个评测盲区**：ssim 对"大面积白底匹配"非常敏感。图糊成一团黑，
只要白底比例对，ssim 就不会太低 —— **它掩盖了"字形根本没出来"**。
判断生成质量**必须看图，不能只看 ssim**。

## 1. 12ch 为什么失败

### 1.1 根因：ref 用 12ch 是"没有别的路"，我们有 g 条件，12ch 是重复投入

| | ref（Moyun） | 我们（DiT_2Cond） |
|---|---|---|
| 条件 | **只有 label**（书家/字体/字） | **g 标准字形**（含骨架结构），via 输入层 token-add + 逐层注入 |
| 结构信息的入口 | **只有 12ch 目标通道** | **g 条件**（已覆盖）+ 12ch 目标通道 |

ref 里结构只能进目标，所以 12ch **必需**；我们结构已经从条件侧喂进去了，
12ch 就成了**第二条结构通路** —— 监督重复下两遍，同时挤压 image 通道。

### 1.2 梯度被稀释（有实测数字）

[54] 号实测：

> 12ch 联合目标需要 per-group 权重：等权时结构通道吃 **~51% 的 final-layer 梯度**
> （`patch_embed` 上 aux 的梯度是 img 的 **2.6×**）；按 ref 等权会压 seen。

按通道数算：img 4ch : aux 8ch = **1 : 2**，等权下 image 只拿 **1/3** 的损失权重。
而 aux 目标（白底归零后 std 只有 **0.57**，img 是 **1.20**）**更容易拟合**，
优化器会优先把 aux 的 loss 压下去 —— 与日志形态吻合：

```
c12[img=0.2766 canny=0.2116 skel=0.1693]     # img 最高、skel 最低
```

**⚠ 我犯的错误**：上一轮"对齐 ref"时把验证过的 `0.3/0.8` 改成了等权 `1.0/1.0`，
**无视了我们自己已有的反对证据（[54]）**。而且"ref 用等权有效"是在完全不同的条件下得出的
（DDPM + `learn_sigma=True` + 1.9M 图 + 500M 参数），不能直接搬到 59M / 54k 图 / flow 上。

### 1.3 CFG 作用域 bug（很可能是"墨团"的直接原因）

`forward_with_cfg` 的 CFG 作用域由 `image_channels` 控制，**而我们所有 12ch 配置里
`image_channels = None`** → 回退成 `in_channels`，即 **CFG 对全部 12 个通道做引导**。

aux（canny/skel）通道的分布与 image 完全不同，却被同一个 `cfg_scale` 放大，
采样轨迹就跑飞了。**4ch 线没有这个问题**（只有 4 通道），所以它一直正常。

这也解释了用户的关键观察：**之前所有训练（4ch）生成的图都是正常黑白，只有 12ch 线出墨团**
—— 这不是"欠训练"，是 bug。

（[58] 号已就 CFG 通道数做了修复，但配置里仍需显式设 `image_channels` 才会生效。）

## 2. 白底归零（wz）为什么放弃

### 2.1 它是什么

```python
lat_wz = lat_orig - lat_white      # lat_white = VAE(全白图).latent
```

白底区 → **0**；笔画区 → `黑 − 白` = 负值。

### 2.2 理论收益（成立的部分）

flow 采样从 `ε ~ N(0, I)` 出发走向 `x0`，看白底区这一项：

| | 未减白底 | 减白底（wz） |
|---|---|---|
| x0 的白底区 | 常数 `[2.18, 1.42, −0.01, −1.14]` | **0** |
| 速度 `v = ε − x0` | `ε − 常数` | **`ε`** ← 恰好就是噪声 |

减白底后白底区的 `v` 等于噪声本身 —— 这部分**不需要学**，模型只需在笔画区做修正。
等价于把"所有样本共享的 DC 分量"从学习任务里移除。CFG 也会更干净：
uncond 分支的理想输出更接近 0（白纸），引导差值更聚焦笔画。

### 2.3 代价（实测）

| 指标 | 未减白底 | 减白底（wz） |
|---|---|---|
| img `mean` | +0.28 | **−0.33**（左偏） |
| img `\|x\|>2` 占比 | 4.1% | **12.1%**（尾部变重 3×） |
| canny / skel `std` | 1.21 / 1.04 | **0.57 / 0.56**（减半） |

分布从近似对称变成**稀疏 + 左偏 + 重尾**，flow 的线性插值路径在这类分布上更弯曲。

### 2.4 它已经造成过一次事故

**SD VAE 的零向量不等于"白"**：实测 `decode(0) = [129, 110, 89]`（灰黄棕，R−B=+40）。
所以减白底后，推理/评测 decode 前**必须加回白底**。

而 `aux_zero_white` **从未在 `train.py` 的 argparse 里注册** —— config 加载器只把键套到
已注册的 action 上，未注册的键被**静默丢弃**（`resolved_config.json` 里该字段出现 **0 次**），
于是所有 decode 路径都没加回 → **生成图整体发黄，更负处发黑**，poster 上看起来"全黑"。

（详见 [56] 号。修复本身已完成并加了 `maybe_add_white()` 单一入口，但**这个事故本身就是
"改动引入了新的隐式不变量"的代价**。）

### 2.5 结论：未证收益，放弃

wz 的收益**从来没有干净对照**：4ch 线没用 wz、12ch 线用了 wz，两个变量是缠在一起的。
在收益未验证、且已经付出一次事故代价的情况下，不值得继续押注。

## 3. 回到 4ch 原版配方

配置：`src/train/configs/v11_pretrain_Sp2_base_sym.json`

```
Sp/2 + 4ch + g 骨架条件 + xattn 全 12 层 + REPA 0.03
+ flow (logit_normal / heun) + rms / swiglu / qk_norm + rope=1
+ lr 5e-5 + batch 128 + cosine 400k + EMA 0.9999
数据: train_base_sym 158,814 (base 54,892 + 笔画粗细对称增强 103,922)
```

**注意**：`norm_type=rms` / `mlp_type=swiglu` / `rope=1` **本来就是原版（v10b 0.5680 线）的配置**
—— 曾经怀疑过"是否该回退到 ref 的 LayerNorm + GELU"，核对后确认不需要：
4ch 对照线用的同样是 rms+swiglu 且能正常出字形，norm/激活不是问题所在。

### 初步结果（起跑 20 分钟）

| step | seen | strict | 备注 |
|---|---|---|---|
| 1000 | 0.3605 | 0.3075 | |
| **2000** | **0.4385** | **0.4009** | **≈ 12ch 线 42,500 步的水平** |
| 2750 | —（Diff 0.3858） | | 用户确认：**黑白的，形状在学** ✓ |

## 4. 教训

1. **"参考实现用了 X"不等于"我们用 X 也有效"**。搬配置前必须问：参考实现有没有我们已有的
   替代通路？我们的容量/数据量/扩散类型是否可比？我们有**自己的实测证据**时，不能被"对齐权威"压过去。
2. **辅助目标不是免费的**：多任务目标会与主任务竞争梯度。加之前先问"这个信号是不是已经从条件侧给了"。
3. **ssim 会撒谎**：大面积背景匹配会掩盖"主体没生成出来"。**每个 eval 点都要看图**。
4. **改数据表示（如减常数）会引入新的隐式不变量**（这里：推理必须加回）。这类不变量要么
   写成显式开关并在启动时断言，要么就不要引入。
5. **未注册的配置键会被静默丢弃** —— 这是第二次栽在这上面（见 [56]）。新增 config 项后，
   第一件事是确认它出现在 `resolved_config.json` 里。
