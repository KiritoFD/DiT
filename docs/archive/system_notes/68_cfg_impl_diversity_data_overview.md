## 1. 双轴 CFG：已实现并验证

### 1.1 为什么必须做

`forward_with_cfg` 里 `g2 = torch.cat([g, g])` —— 两半给**同一个 g**，所以

```
eps_cond − eps_uncond = f(真实书家, g) − f(null, g)
```

**g 项完全抵消。** 后果：**任何"只由 g 驱动"的通路（xattn / glyph_embedder）
对 CFG 的贡献恒为 0** —— 这正是 doc 54 "xattn strict ≈ 0" 的机制解释。

### 1.2 实现（`dit.py`）

`forward_with_2axis_cfg` 原先**是错的且零调用者**（死代码）：glyph 轴定义在 `y_char` 上，
且 `g4 = cat([g,g,g,g])` 让 g 在 4 个 pass 里完全相同 → 对 `no_char_cond=True` 的架构
glyph 轴是 no-op，g 仍然抵消。**已改为变化 g 本身**：

```
pass1 full    : (y_callig, g)     -> eps_full
pass2 style   : (y_callig, g=0)   -> eps_style     只有风格
pass3 content : (null,     g)     -> eps_content   只有内容
pass4 uncond  : (null,     g=0)   -> eps_uncond

eps = eps_uncond
    + cfg_glyph  · (eps_content − eps_uncond)                   内容轴
    + cfg_callig · (eps_style   − eps_uncond)                   风格轴
    + w_inter    · (eps_full − eps_content − eps_style + eps_uncond)  交互项
```

- `forward_with_cfg` 新增 `cfg_glyph` 参数：**给了就委托双轴，默认 None 保持向后兼容**
- `inference.sample_latents` 用**模型属性** `cfg_glyph_scale` / `cfg_w_inter` 透传（不改签名）
- 新 CLI：`--cfg-glyph-scale` / `--cfg-w-inter`

### 1.3 ⚠ 前提：`glyph_drop_prob > 0`

`g=0` 必须是**训练时见过的条件**。该 drop 的实现是 `g = g * keep`（整张样本置零），
代码注释里明确写着"**与 CFG 兼容：丢弃时该样本等价于 uncond-g 分支**"。

**但所有 v12 config 的 `glyph_drop_prob` 都是 `0.0`** → 内容轴同样未训练，
与 callig null 行是同一类问题。已加启动警告：
设了 `cfg_glyph` 但 `glyph_drop_prob=0` 时明确告警。

**→ 重训时必须把 `glyph_drop_prob` 设为 > 0（建议 0.1），否则双轴 CFG 永远用不了。**

### 1.4 验证

| 检查 | 结果 |
|---|---|
| C1 向后兼容（`cfg_glyph=None` 走经典 2 路） | ✓ shape 正确 |
| C2 代数恒等式 `2axis(1,1,1) == full` | ✓（见下） |
| C3 内容轴单独生效 | ✓ |
| C4 `g=None` 不崩 | ✓ |
| C5 12ch 场景 `rest` 通道保持 full 值 | ✓ |

⚠ **C2 初看 FAIL（差 1.293e-3）**。做了对照实验才确认那是**fp32 batch 归约噪声**：
把**完全相同**的样本拼成 batch=12 跑一次、单独跑一次，差异**恰好也是 1.293e-3**
（相对 2.6e-4）。**不是逻辑错。**

⚠ **写验证脚本本身的坑**：DiT 的 `final_layer` 是 zero-init → **输出恒为 0**，
不打破它，测出来的全是"0 和 0 的差"。第一版测试因此给出两个假 FAIL。

## 2. 生成多样性

### 2.0 ⚠ 先分清两个独立概念（易混）

| | 固定什么 | 变什么 | 回答的问题 |
|---|---|---|---|
| **intra = 输出多样性** | 书家+字+书体 | 随机种子 | **同一个字写两遍，像不像？** |
| inter_callig | 噪声+字 | 书家 | 条件的**作用**有多大 |
| inter_char | 噪声+书家 | 字 | 条件的**作用**有多大 |

**"输出多样性"只看 intra。** inter 是"条件可控性"，是**另一个维度**，
两者互不蕴含：可以"多样但条件无效"，也可以"条件很强但输出单一"。

### 2.0.1 多样性不是越高越好，且**必须有参照系**

- **太低** → 模式塌缩：换种子给同一张图，模型在背答案
- **太高** → 约束不住：输出乱飘
- **合适** → 像人写同一个字两遍：不会像素级一样，但永远认得出来

**参照系 = 真迹的自然差异**：同一书家、同一字、**同一书体**的多张真迹，两两差异。

⚠ **踩坑**：一开始只按 (书家,字) 分组 → **老数据 41% / HCSU 23% 的"多图组合"其实跨书体**
（文徵明写过楷书「一」也写过行书「一」）→ 测的是"楷 vs 行"的差异，不是"写两遍"。
**必须加书体约束，用 (书家,字,书体) 三元组。**

### 2.0.2 ⚠⚠ 但"真迹差异"与"换种子差异"**本质上不可比** —— 上面的判定作废

（用户指出，正确。）真迹差异包含**四类**成分：

| 成分 | 例子 |
|---|---|
| ① 书写状态变化 | 不同时间/心境/笔锋状态写的同一个字 |
| ② 工具材料变化 | 不同笔、墨、纸 |
| ③ **采集变化** | 不同扫描仪/光照/分辨率/裁切/二值化 |
| ④ 作品语境 | 不同作品里同一个字，前后文影响笔势 |

模型换种子**只包含一类**：模型对"给定条件下还剩哪些不确定"的**后验方差**。

**关键在 ③**：采集变化**模型根本不该也不能复现** —— 给同一个条件，模型没有理由
输出不同分辨率的扫描噪声。所以：

```
真迹差异 = 真实风格变化 + 采集噪声
模型 intra = 模型建模到的那部分不确定
```

→ **真迹差异是模型输出多样性的「上界」，不是「目标值」。**

**佐证**：老数据（不同作品/扫描）0.3903 与 HCSU（多为同页近重复）0.1729
**差 2.3 倍** —— 同一批"真迹"内部就有这么大分歧，说明这个数主要反映
**采集条件**，不是书写风格。

**→ 因此 `intra` 的绝对值没有"合格线"，只能做相对比较。**
上一版"48% → 不合格"的判定**撤回**。

### 2.0.3 有效的判据组合

| 判据 | 门槛 | 为什么 |
|---|---|---|
| `intra > 0` 且不太小 | 噪声必须被使用 | **`intra ≈ 0` = 采样塌缩**，模型退化成确定性映射，扩散过程是假的 |
| `ratio_style` / `ratio_char` ≫ 1 | 条件必须主导噪声 | 否则"风格控制"是假的 |
| `ssim_to_gt` / LPIPS 好 | 输出得像真迹 | 这是任务本身 |

**且：对"给定 书家+字+骨架"这个任务，"多样性低"本身不一定是缺点。**
条件已相当具体，剩下未定的只有笔触粗细/墨色/细微结构。
**低方差 + 高精度，对生成工具反而是好事** —— 除非目标是"建模这个书家的风格分布"
（例如做数据增强）。**判据取决于任务定位，需要先明确。**

### 2.0.4 【结果】大规模 intra + cfg 0.7 vs 1.0

30 个条件（strict 集）× 4 个种子 = 120 张/份，**180 对 intra**：

| | **cfg=0.7** | **cfg=1.0** | 差异 |
|---|---|---|---|
| **intra（div_ssim）** | **0.3169** | **0.3113** | −1.8% |
| div_mask_iou | 0.5938 | 0.5728 | −3.5% |
| ssim_to_gt | 0.5862 | 0.5869 | +0.1% |

**三条结论**：

1. **cfg 对结果几乎无影响**（intra 差 1.8%，ssim_to_gt 差 0.1%）。
   机制解释：uncond 分支未训练 + `null_embed` 停在初始化（std=0.02）
   → `0.3·uncond + 0.7·cond ≈ cond`，插值近似 no-op。
   **这从经验上证实了「问题 A 的实际数值影响确实很小」** ——
   机制上是错的（应修），但**数值上不值得为它返工**。

2. ⚠ **"cfg=0.7 人为压低多样性"的预测是错的** —— 换 cfg=1.0 后 intra 反而略降
   （0.3169 → 0.3113）。**撤回该预测。**

3. **小样本偏差很大**：16 对时得 0.1878，180 对时得 0.3169。
   → **多样性这类指标必须用大样本**（≥100 对）。

**另一个观察**：`ssim_to_gt = 0.586`，而样本两两 SSIM = `1−0.317 = 0.683`。
即**样本之间比样本与 GT 更相像** —— 说明模型输出**聚在一起、整体偏离 GT**，
这是**系统性偏差**，不只是方差。

### 2.0.5 【文献标准】多样性该怎么判

**（1）标准框架是"一对"指标，不是一个**

| | 定义 | 主流指标 |
|---|---|---|
| **Fidelity（保真度）** | 生成样本是否逼真（落在真实分布内） | Improved Precision、Density、α-precision |
| **Diversity（多样性）** | 生成分布是否覆盖真实分布的全部模式 | Improved Recall、Coverage、β-recall |

Kynkäänniemi 2019 / Naeem 2020 / Alaa 2022 等六对指标。**FID/IS 这类单一标量
已被认为不够** —— 无法区分"质量"和"覆盖"。

**（2）★ 关键 norm：没有模型能达到真实数据的多样性**

Vendi Score 论文实测（Stacked MNIST，1000 个模式）：

| | NoM（模式数） | **VS（有效多样数）** |
|---|---|---|
| 原始数据集 | 1000 | **943.7** |
| PresGAN | 1000 | 866.6 |
| Self-cond GAN | 1000 | 746.7 |

**两个 GAN 都覆盖了全部 1000 个模式，VS 仍低于原始数据集。**
论文原话：**"没有模型能达到其训练原始数据集的多样性分数"**。

→ **"低于真迹"是常态，不是失败。** 这是文献层面的确认（我此前拿真迹当合格线是错的）。

**（3）真正的失败模式是 mode collapse，用 Vendi Score 检测**

`VS = exp(−Σ λᵢ log λᵢ)`，λ 是归一化相似度矩阵 `K/n` 的特征值。

- **范围 [1, n]**：**VS=1 → 所有样本完全相同（完全坍塌）**；VS=n → 两两完全不同
- **可解释为"有效不同元素数"** —— 有绝对解读基准，可用比值/百分比比较
- **不需要参考数据集** → **正好绕开"真迹不可比"的问题**
- 代价：reference-free 意味着"采样纯噪声也能得高分" → **必须与质量指标配合用**

**（4）⚠ 但对"条件生成"，VS 不该接近 n**

我们的任务是"给定 书家+字+骨架"生成。4 个样本应当**都是同一个字、同一种风格**的
合理变体 —— 它们**本来就该像**。所以 **VS 显著低于 n 是正常且期望的**。
该看的是 **VS 明显 > 1（没坍塌）**，不是 VS 接近 n。

**（5）没有"黄金指标"**：ICML 2025 position paper（arXiv 2505.22450）系统检验了
6 对共 12 个 fidelity/diversity 指标，**没有一个通过全部 sanity check**，
且明确指出不存在可放心使用的单一指标 → **只能做相对比较 + 坍塌检测**。

### 2.0.6 【实测】Vendi Score：**我们的模型没有坍塌，多样性是健康的**

从已有海报（30 条件 × 4 生成 + GT）算 VS，相似度核用 SSIM：

| | **VS（有效变体数）** | 上界 | 归一化 | **坍塌条件数** |
|---|---|---|---|---|
| v12 cfg=0.7 | **2.233** | 4 | 0.558 | **0 / 30** |
| v12 cfg=1.0 | 2.210 | 4 | 0.552 | **0 / 30** |
| v12_d8（K=3） | 2.084 | 3 | 0.695 | 0 / 4 |

**判读**：
- **`0/30` 条件坍塌** —— 没有任何一个条件出现"4 张几乎一样"。
  **模型在采样时确实用到了噪声，不是查表。**
- 有效不同变体数 **2.23 / 4** —— 4 张里有约 2.2 张"等效不同"。
  对条件生成这是**健康的**：有真实变化，又保持同字同风格。
- **→ 此前"多样性不合格"的判定彻底撤回。结论是：多样性健康，无坍塌。**

### 2.0.7 ★ CFG 文献明确"用多样性换保真度" —— 反过来确认了我们的 CFG 失效

CFG 原论文（Ho & Salimans 2022）原话：

> "increasing classifier-free guidance strength has the expected effect of
> **decreasing sample variety and increasing individual sample fidelity**"

实测（ImageNet 64×64，p_uncond=0.1）：

| w | FID | IS |
|---|---|---|
| 0.0 | 1.80 | 53.7 |
| 0.1 | 1.55 | 66.1 |
| 0.3 | 3.03 | 92.8 |
| 1.0 | 12.6 | 170.1 |
| 4.0 | 26.2 | 260.2 |

**w 从 0→4，FID 涨 14.6 倍** —— 多样性损失是巨大且单调的。

**→ 这给了一个独立诊断**：正常工作的 CFG，cfg 提高应**明显降低多样性**。

**我们实测：cfg 0.7 → VS 2.233，cfg 1.0 → VS 2.210（几乎不变）**
→ **从"CFG 应有的行为"这一侧，独立确认了我们的 CFG 是失效的**
（与代码侧的分析相互印证：uncond 分支未训练 + `null_embed` 停在初始化）。

### 2.0.8 【参照数据】真迹 intra（仅作背景）

| 真迹 intra（1−SSIM） | med | mean | p10 | p90 |
|---|---|---|---|---|
| **老数据**（v12 训练集） | 0.3946 | **0.3903** | 0.2421 | 0.5264 |
| HCSU | 0.1285 | 0.1729 | 0.0423 | 0.3645 |

两个数据集的"自然差异"**差得很远**：老数据来自不同作品/扫描，同一个字在不同版本差别大；
HCSU 的多图组合**很多是同页近重复**（p10=0.042，几乎一样）。

**模型 intra**（固定条件换噪声，训练集 CSV，16 对）：

| | intra | 相对老数据参照 |
|---|---|---|
| **v12 S/2 (37M)** | **0.1878** | **48%** ← **低于 p10(0.2421)** |
| v12_d8 XS/2 (27M) | 0.2519 | 65% |

**判定：v12 的输出多样性偏低，有向单一模式塌缩的倾向**
（写同一个字两遍，比真人写同一个字两遍明显更相像）。
⚠ 样本偏小（16 对、k=2、cfg=0.7），方向可信但数值该用更大样本复核。

### 2.0.3 意外发现：多样性与精度是**权衡**的

| | intra（多样性） | ssim_to_gt（精度） |
|---|---|---|
| v12 S/2 | 0.1878 低 | **0.6757** 高 |
| v12_d8 XS/2 | **0.2519** 高 | 0.6487 低 |

**d8 反而更多样、但更不准。** → **"容量小就更塌缩"的直觉是错的**：
小模型是**更飘**（约束不住），不是更塌缩。这与它 ratio 更低（1.42 vs 1.83）一致。

### 2.1 指标设计（inter 部分）

只测 intra（同条件换噪声）不够 —— 它高只说明"输出有随机变化"，**不说明条件真的起作用**。

| 指标 | 设计 | 含义 |
|---|---|---|
| `intra` | **固定条件**，变噪声 | 噪声驱动的方差 |
| `inter_callig` | **固定噪声**，变书家 | 风格条件的作用强度 |
| `inter_char` | **固定噪声**，变字 | 内容条件的作用强度 |
| `ratio_style` | `inter_callig / intra` | ★ 风格信噪比 |

**关键：inter 必须固定噪声。** 若每个样本换噪声，测到的是"噪声方差 + 条件效应"，
ratio 会虚高。

### 2.2 ⚠⚠ 修掉 `tools/eval_diversity.py` 的三个静默 bug

这三个都会让数字**看起来正常但完全无意义**：

| # | Bug | 后果 |
|---|---|---|
| **D1** | 原 `build_model` 漏了 v12 新增字段（`glyph_vec_cond` 等），而加载用 `strict=False` | v12 的 `cond_fusion.0.weight` ckpt 是 `[256]`（callig128+glyph_vec128）而重建给 `[128]` → **静默加载随机 cond_fusion** |
| **D2** | inter 阶段用**原始 calligrapher_id**（49~9001），未过词表映射，而 `num_classes=52` | 全部越界 → 兜底成 null → **4 个书家输出像素级相同，`inter_callig` 假性为 0** |
| **D3** | inter 用训练集 CSV，却配 `shards_std_eval` | 16/16 miss → **`g=ZERO`，字条件静默失效** |

**修法**：D1 复用 `cfg_sweep.build_model_from_args` + **`strict=True`** 当护栏；
D2 走 `cmap` 映射并打印越界警告；D3 按 CSV 自动选配套 shards + 打印"全零"计数。

另修两个崩溃：inter 用全 CSV 行号索引只有 `n_cond` 行的 eval cache（全越界）；
`--skip-intra` 时 `poster_rows` 为空导致 poster 越界。

### 2.3 【结果】v12 (S/2) vs v12_d8 (XS/2)

修完 D1~D3 后，固定噪声、同数据同口径（`--inter-char 4 --inter-callig 4`，训练集 CSV）：

| 指标 | **v12 S/2 (37M)** | **v12_d8 XS/2 (27M)** |
|---|---|---|
| `intra`（固定条件，变噪声） | **0.1878** | 0.2519 |
| `inter_callig`（固定噪声，变书家） | **0.3447** | 0.3576 |
| `inter_char`（固定噪声，变字） | **0.3258** | 0.3674 |
| **`ratio_style`** | **1.83** | 1.42 |
| **`ratio_char`** | **1.73** | 1.46 |

（数值是 `1 − SSIM`，越大越"不同"）

**四条结论**：

1. **条件确实起作用，但信噪比只有 ~1.8。**
   条件驱动的输出差异只有噪声驱动的 **1.8 倍**。理想情况下条件应远大于噪声（5~10×）。
   → **输出的很大一部分方差是"随机噪声"，不是条件控制的。**

2. **⚠ `inter_callig ≈ inter_char`（0.3447 vs 0.3258）—— 换书家和换字造成的差异几乎一样大。**
   对书法生成，理想是**内容 ≫ 风格**（字必须认得出来）。
   两者相等说明 **风格被过度表达 / 内容约束偏弱**。
   而且两个模型都这样 → **是共性问题，不是容量问题。**

3. **XS/2 的 `intra` 高 34%（0.2519 vs 0.1878），inter 却差不多** → `ratio` 从 1.83 掉到 1.42。
   → **小模型的输出更"飘"、条件控制更弱**。这给 d8 strict 更差提供了机制解释：
   不是"学不会"，是**条件信噪比更低**。

4. 两个模型的 `inter_char` 都没比 `inter_callig` 高多少 → **内容条件偏弱是共性**。

### 2.4 ⚠ 一个重要认知：`strict` 评测集测不了风格可控性

`strict` 评测集按设计是"**每个字只配一个书家**"（unseen 组合）——
**它天然无法测"换书家时输出动不动"**。

→ inter 阶段必须用**训练集** CSV。这是**可控性测试**（条件是否真的起作用），
不是泛化测试，用训练数据完全正当。

### 关键洞察

1. **HCSU 比老数据均衡得多**（书家 Gini 0.221 vs 0.388，熵 0.978 vs 0.933）。
   合并后被老数据的极端值拉回 0.395。
2. **字的长尾极重**：`min=1 med=4 max=86` —— **一半以上的字只有 ≤4 张**。
3. **每 (书家,字) 平均只有 1.4 张** → "**one-shot per pair**" 形态。
   这意味着模型很难从"这个字"学到风格，只能从"这个书家的其他字"泛化。
4. **33/48 书家跨多个书体** → 风格与书体纠缠，解耦更难。
5. **HCSU 的 12 位新书家平均 466 张 / 字均 1.1~1.6 张**（见 doc 66 §6.4）。
