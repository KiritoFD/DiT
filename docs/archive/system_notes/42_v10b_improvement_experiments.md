# 42 — v10b 改进实验设计（基于 41 号梯度诊断）

> 2026-09-07。诊断结论（41 号）：
> **① REPA 劫持**：w0.1 的 REPA 梯度平方和占全模型 158%（余弦 vs MSE 量纲错配）
> **② callig 链弱梯度**：rel 0.0013，比 glyph 低 6 倍
> 本文件 4 个实验直接针对这两个瓶颈，按信息量/成本排序。

---

## 实验 1：REPA 权重校准（针对劫持，最高优先）✅

**假设**：REPA 余弦 loss（0~1 量纲）与 velocity MSE（小量纲）梯度不可比，
w=0.1 实际主导优化。把 REPA 梯度校准到主任务 ~10% 水平，主干回归 velocity 拟合。

**改动**（config 微调 + repa.py 小改）：
- `w_repa`: 0.1 → **0.02**（梯度占比 158%→~32%，仍保留结构对齐）
- repa.py：REPA loss 输出前除以其自身梯度量纲标量（可选，先试纯权重）
- 其余配方全不变（batch 320 / compile / lr 1.5e-4 / 150k / 早停）

**预期**：base SSIM 0.8404 → **0.847+**（追平 v10a），loss 曲线更平滑
**成本**：~8h 全量新训，改动 = config 一行 + 可选 repa.py 一行

---

## 实验 2：callig 风格链增强（针对弱梯度）✅

**假设**：callig_chain rel=0.0013 更新太慢，风格条件学不动。
书家 1013 类只有 128 维 embedding + 单层 proj，容量与梯度双受限。

**改动**（config）：
- `callig_embed_dim`: 128 → **256**
- `callig_proj`: 单 Linear → **两层 MLP**（需 dit.py 小改，或复用 char_proj 的 mlp 结构）
- `callig_scale` 初值 1.0 → **1.5**（上调风格权重，抵消弱梯度）

**预期**：风格保真提升（SSIM 可能微升），书家区分度提升
**成本**：~8h 新训，改动 = config + dit.py callig_proj 结构

---

## 实验 3：REPA 关闭对照（验证劫持假说）✅

**假设**：REPA 主导训练是 base 上限的主因；去掉 REPA 后 velocity 拟合纯粹化。

**改动**（config）：
- `w_repa`: 0.1 → **0**（完全关闭）
- 其余全不变

**预期**：
- 若 base 显著提升 → 坐实"REPA 劫持"，实验 1 的校准方向正确
- 若 base 下降 → REPA 仍有正面作用，实验 1 改为梯度归一而非降权
**成本**：~8h 新训，改动 = config 一行。**与实验 1 构成关键 A/B 三角**
（w=0.02 vs w=0 vs w=0.1）

---

## 实验 4：REPA 浅层化（若实验 1/3 显示 REPA 有害但不可弃）✅

**假设**：REPA 对齐 block8（深层）侵入语义层；只对齐浅层（block2/4）保留
结构先验但不过度干预。

**改动**（config）：
- `repa_layers`: (8,) → **(2, 4)** 或 (4,)
- `w_repa`: 0.1 → 0.05（浅层对齐权重可稍高）
- 其余全不变

**预期**：介于实验 1 与 3 之间，若浅层对齐仍有效且不劫持 → 最优结构先验
**成本**：~8h 新训，改动 = config 两行

---

## 实验优先级与组合

```
优先级: 1 > 3 > 2 > 4
1 (w=0.02) 与 3 (w=0) 必须同时跑 → 三角对照定 REPA 真实价值
2 (callig 增强) 独立变量，可与 1/3 最优者组合 (实验 5 = 1+2)
4 是 1/3 结论后的保底方案
```

**执行建议**：GPU 单卡，先跑实验 3（w=0，最干净对照，若 base 暴涨则 1 有戏），
再跑实验 1（w=0.02），两者定 REPA 曲线；随后 2（callig）。三个各 8h，共 ~24h。

## 验收标准

- base SSIM > 0.8476（v10a 记录）→ 实验成功
- 遵循度（n=30 GPU 矩阵）≥ 0.570 且不降 → 骨架通路未被破坏
- REPA 梯度占比 < 50% → 劫持解除（用 debug_v10b_gradients.py 复测）
