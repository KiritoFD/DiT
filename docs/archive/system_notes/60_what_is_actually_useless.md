# 60. 哪些东西是"根本没用"的 —— 按证据强度分级

> 日期：2026-09-15
> 相关：[48](48_cleanup_and_next_experiments.md)、[54](54_results_and_insights_20260913.md)、
> [55](55_base_sp2_launch_20260914.md)、[59](59_12ch_and_white_zero_retrospective.md)
>
> **本文的纪律**：只把**有实测对照**的东西判为"没用"。证据不足的一律标注"不确定"，
> 因为**把没验证的东西当成已证伪**，和把没验证的东西当成有效，是同一类错误 ——
> 后者我们已经犯过（见 §4）。

---

## 0. 判定标准

| 级别 | 含义 |
|---|---|
| **已证无用** | 有同预算/同配方的对照实验，指标无差异或负差异 |
| **已证有害** | 对照实验显示指标下降 |
| **不确定** | 只有单臂结果，或对照不同预算/不同步数，**不能下结论** |

⚠ **"没达到显著" ≠ "没用"**。n=10 的 seen、n=50 的 strict，±0.01 的差异本来就在噪声内；
在 80k 步"持平"也不代表 400k 步仍然持平（见 xattn）。

## 3. 12ch 与白底归零为什么"没用"（机制）

### 12ch

1. **ref 用 12ch 是因为它没别的路**：ref 只有 label 条件，结构只能进目标通道；
   我们有 **g 骨架条件**，结构已经从条件侧给了 → 12ch 是**重复投入**。
2. **梯度稀释**：等权下 image 只拿 1/3 损失权重（见 §1）。
3. **CFG 作用域 bug**：作用域由 `image_channels` 控制，而配置里是 `None` → 回退 `in_channels`，
   **CFG 对全部 12 通道做引导**；aux 分布与 image 不同却被同一 `cfg_scale` 放大 → 轨迹跑飞。
   4ch 没有这个通道，所以它一直正常。

### 白底归零（wz）

**理论收益成立**：白底区 `v = ε − 0 = ε`，恰好是噪声本身，这部分不用学。

**但**：
- 代价实测为分布左偏（mean −0.33）、尾部变重（`|x|>2` 4.1% → 12.1%）、aux std 减半（1.2 → 0.57）。
- **VAE 零向量 ≠ 白**：`decode(0) = [129,110,89]`（灰黄棕），所以推理必须加回 —— 那次事故正源于此。
- **ref 有完整实现（`custom_zero`）却全部 `.sh` 都是 0** —— 作者有构想但始终未启用，
  这是"大概率没收益"的间接证据。

## 4. ⚠ 我犯过的两个错误（记录在案）

### 错误 1：把"80k 步持平"当成"xattn 没用"，然后自己打脸

48/54 号把 xattn 列为弃用，依据是：

> sp(adaLN4) 0.5179@77.5k ≈ c41x(xattn12) 0.518@80k

但我随后又把配方改成了 **`xattn12`** —— 因为当前最高分的那条线
（`v10b_stdskel_fame3_c41x_cos_e`, strict **0.5680**）用的正是 xattn12。

**这两件事不能同时成立**。真实状态是：

- **理论上**：xattn 是内容寻址（每个 query 动态聚合全部 256 骨架 token），表达力**严格强于**
  adaLN 的固定 1:1 位置调制；对书法的非刚性形变本应更有利。
- **实践上**：只有 **80k 步**的短期对照（持平、+33% 算力），
  **没有任何"同预算、同数据、长训"的 adaLN vs xattn 对照**。
  而 xattn 参数更多，80k 持平**恰恰可能是它还没训够**。

**→ xattn 应判为"不确定"，不是"没用"。已按此修正。**

### 错误 2：把 ref 的"组合泛化"美化成泛化

ref 的 `LabelEmbedder` 确实是三表因子分解（书家 × 字体 × 字），能组合出未见三元组。
但**这不是真正的泛化** —— 泛化是能处理**没见过的字 / 没见过的书家**，而 ref 的字身份是离散 ID，
**ID 不存在的字写不出来**（闭集）。

我们的字身份是**标准字形的 latent**，只要 std skel 能渲染就能作为条件输入 → **开集**，
这才是真泛化。**两边的取舍是：我们用"开集"换了"标准字形信息量不足"的瓶颈。**

## 5. 不确定（**不能**下结论）

| 组件 | 现状 |
|---|---|
| **xattn vs adaLN** | 只有 80k 短期对照（持平）；当前最佳线是 xattn12。缺长训同预算对照 |
| **REPA（w=0.03）** | 历史最优线都带它；但 41 号实测会劫持梯度（158%）。权重敏感，缺 `w=0` 对照 |
| **自条件（self-cond）** | 55 号已实现，纯推理侧，未 A/B 验证 |
| **分维度条件 dropout** | ref 用了 `charactor-x 0.08 / font-x 0.08 / calligrapher-x 0.16`；我们没有这个粒度，未验证 |
| **白底归零** | 判为"无用/未证"，但严格说缺一个"wz vs 非 wz"的同配方 30k 对照 |

## 6. 一条纪律

**新增组件时，先问"这个信号是不是已经从别处给了"** —— 12ch、style token、`callig_spatial`
本质上都是同一个错误的三种形态：往一个已经提供了该信号的系统里，再塞一遍同样的信息。

**反过来也成立**：不要因为一次短期对照没效果就判死刑（xattn 的教训）。
对照必须是**同预算、同数据、同配方、跑到平台**的，否则只是噪声比较。
