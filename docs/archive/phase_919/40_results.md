| `diversity_v12_d8` | v12_d8@100k | 0.7 | 3 | 0.3735 | 0.9267 | 0.9221 | **2.48** | 2.47 |

**基线参考区间：`ratio_style ≈ 1.4–2.5`，理想值 5–10** —— 即
**条件驱动的输出差异只比噪声驱动大 1.4–2.5 倍，风格控制是"假的"**。

⚠ **v12_d8 的 ratio 更高（2.48）不是好事**：它的 intra 也涨到 0.3735（噪声影响更大），
而且 `inter_callig ≈ inter_char`（0.927 vs 0.922）→ **换书家与换字造成的差异完全一样大**，
对书法任务（内容必须 ≫ 风格）是**更差**。

⚠ **另一个诡异点（doc 68 §2.0.4 记录）**：`intra` 在 **16 对**时得 0.1878，
在 **180 对**时得 0.3169 —— **小样本严重低估多样性**。
→ **多样性指标必须 ≥100 对**。

### 2.2 cfg 对多样性几乎无影响（机制解释）

| | cfg=0.7 | cfg=1.0 | Δ |
|---|---|---|---|
| `intra`（180 对） | 0.3169 | 0.3113 | **−1.8%** |
| `div_mask_iou` | 0.5938 | 0.5728 | −3.5% |
| `ssim_to_gt` | 0.5862 | 0.5869 | +0.1% |

**机制**：uncond 分支未训练（bug，见 `20_model.md` §2.4）+ `null_embed` 停在初始化（std=0.02）
→ `0.3·uncond + 0.7·cond ≈ cond` → **插值近似 no-op**。
→ **机制上是错的，数值上影响很小** —— 不值得为它返工历史 run，但**新 run 必须修**。

### 2.3 系统性偏差（重要观察）

```
ssim_to_gt = 0.586      样本两两 SSIM = 1 − 0.317 = 0.683
```

**样本之间比样本与 GT 更相像** → 模型输出**聚在一起、整体偏离 GT**，
这是**系统性偏差**（不是方差问题）。

### 2.4 判据（doc 68 §2.0.3）

| 判据 | 门槛 | 为什么 |
|---|---|---|
| `intra > 0` 且不太小 | 噪声必须被使用 | `intra ≈ 0` = **采样塌缩**，扩散过程是假的 |
| **`ratio_style` / `ratio_char` ≫ 1** | 条件必须主导噪声 | 否则"风格控制"是假的 |
| `ssim_to_gt` / LPIPS | 好 | 任务本身 |

⚠ **文献 norm（doc 68 §2.0.5）**：Vendi Score 论文实测"**没有模型能达到其训练原始数据集的多样性分数**"
（原始 943.7 vs PresGAN 866.6 / Self-cond GAN 746.7）→ **"低于真迹"是常态，不是失败**。
真正的失败模式是 mode collapse，要用 Vendi Score 检测。

⚠ **`intra` 的绝对值没有合格线**（doc 68 §2.0.2）：真迹差异 = 真实风格变化 + **采集噪声**
（老数据 0.3903 vs HCSU 0.1729 差 2.3 倍，主要反映采集条件）
→ **真迹差异是"上界"不是"目标值"**，只能做相对比较。

## 3. 逐书家分析（**定位 style 模块瓶颈的关键证据**）

来源：`assets/diversity_v13_155k_percalig.csv` + `diversity_inter_by_callig_v13_155k_percalig.csv`
（`logs/_div2.log`），并被 `src/utils/callig_script_map.py` 文档串引用。

### 3.1 书家间的 strict 差异极大

| 书家 | 训练样本数 | strict ssim |
|---|---|---|
| 苏轼 | **3,131**（最多） | **0.3485**（最差） |
| … | … | … |
| 李邕 | 1,168 | **0.6300**（最好） |

```
r(该书家训练样本数, strict ssim) = −0.62
```

### 3.2 这个负相关说明什么

**反直觉但关键**：样本**越多**的书家，strict **越差**。

| 解释 | 机制 |
|---|---|
| **风格多模态** | 苏轼存世作品跨**早/中/晚期**、楷/行/草，风格差异极大 |
| **单向量装不下** | 45 行 × 1 个 128 维冻结向量 → 3149 张图被迫平均成一个点 |
| → 条件信息量不足 | 模型只能学"朝大概方向走"，无法区分苏轼的哪一路面貌 |
| **样本少的书家反而好** | 风格统一 → 单向量够用 → 泛化好 |

→ 这是 **"style 模块是瓶颈"最硬的证据**：不是参数量问题（缩深度反而更差），
而是**条件标签的粒度/容量不足**。

### 3.3 结构性数据

| 指标 | 值 |
|---|---|
| 跨多书体的书家 | **32/45（71%）** |
| 87 个 (书家×书体) 对 | 中位 **508 张/对** |
| 稀疏对（<50 张） | **15 对**（min=1）→ 用书家级质心回退 |

### 3.4 由此推出的 v14 设计

```
把 45 书家 → 87 个 (书家×书体) 对，让同一人的不同书体各得一个向量
  → 直接解耦"书体模态"
```

**结构体检**（`_review/compare_tables.py` / `tools/`）：

| | 45 表 | 87 表 | 判据 |
|---|---|---|---|
| pairwise cos | 0.0204 | **0.0135** | 塌缩基线 0.323（远低于 → 未塌缩） |
| 有效秩 | 34.4/45 = **76%** | 77.2/87 = **89%** | 越高越好 |
| 熵 | — | 更高 | — |

⚠ **结构更好 ≠ 效果更好**（v14 strict/seen **无显著差异**）——
**这正说明"表结构"不是唯一瓶颈，注入/训练协议也要一起动**（→ full-ft）。
