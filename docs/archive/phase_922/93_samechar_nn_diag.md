# 922 / 93 — 训练集「同字最像」诊断：8 个 run 的横向对照

> 起因：用户要求在 poster 下加一行 = 训练集里**同字**、与 strict 推理结果 SSIM 最高的那张 GT，
> 然后问「这个最近拟合 SSIM 是多少、在上升吗、是否说明模型有大问题、能否对历史模型做同样诊断」。

## 口径

对每个 run 的**最后一个 step**，只用**旧集/修复集共有的 229 列**（两集行序一致，仅 20 条 `character` 不同）：

| 量 | 含义 |
|---|---|
| `own_gt` | `ssim(生成, 本列自己的 GT)` —— 对目标的拟合 |
| `nn` | 同字训练候选里 SSIM 的**最大值** —— "最像谁" |
| `mean_c` | 同字训练候选的 SSIM **均值** —— 随机挑一张同字样本的期望 |
| `mean_错字` | **别的字**的候选均值 —— 无信息参考 |
| `own-mean_c` | 配对差 + t（同一个字，目标 vs 随机同字样本）|
| 同书家 / 基线 | 有同书家候选的列里，最近邻命中同书家的比例 / 随机基线；比值 = **富集** |

⚠ 两个必须先做的对照（否则会误读）：
1. `gap = nn − mean_c` **天然为正**（max ≥ mean）。所以不能靠它证明判别力 —— 要看 `mean_错字` 的绝对量。
2. "只有 4.4% 的列最近邻是同书家"这个数被"**只有 20.1% 的列有同书家候选**"限制住了。
   真正该看的是**条件命中率**，不是全体命中率。

## 修正后的总结论

1. **不能说"E0 最好"** —— 匹配 step 后各 run 在富集上没有可分辨差异。
2. **也不能说"我们的改动是反方向的"** —— 目标特异性上 gq 反而略优，其余与 E0 相当。
3. **能说的是：我们所有的改动都没能解决风格保真度** —— 富集上限 ~1.9×，包括 E0。
4. ★ **真正的诊断是"轴选错了"**：
   - `mean_c − mean_错字` = **+0.036**（认字 ✓）
   - `own_gt − mean_c` = **+0.012**（认目标，只有认字的 1/3）
   - 富集 **~1.1–1.9×**（认书家，弱）
   → 过去所有改动（注入方式/门控/低秩/交叉注意力/条件增强）都在改**骨架条件怎么进网络**，
     而骨架条件本来就工作正常（+0.036）。**瓶颈在风格/实例特异性那一侧。**
   → 而旧判据（strict ssim）被字形结构主导，**量不到风格** —— 这解释了为什么"风格注入"的实验
     全都"无效"：**不是改动无效，是尺子量不出来。**

## 下一步（建议）

1. **把该指标纳入常规 eval**（成本 16s/run，已实现）→ 每个 run 都报富集 + own−mean_c。
2. **用新尺子重审历史**：重点复查 E1（style LN）在 20k–40k 富集偏高的线索。
3. **不要再把 strict ssim 当主判据**（和 frag 一样，它量不到风格）。
4. **直接攻风格保真度**（而不是继续改骨架注入）：
   - 风格条件的表达：`factorized_cat` + adaLN 可能把风格压成**全局偏置**，无法表达局部笔法
     → 试局部风格（spatial/fiLM 已有雏形）、或风格 token 化（K>1）
   - **给风格加直接监督**（现在 loss 只有 velocity MSE + REPA，**没有任何一项约束"像不像这个书家"**）：
     · 对比学习：拉近同书家同字、推远异书家（= 这个指标的监督化版本）
     · 或把"同字同书家最近邻"当可微辅助 loss
5. **方法论**：**任何跨 run 结论都必须匹配 step** —— 我这条就是靠单点比较得出"E0 最好"，
   被匹配表推翻的。这类错误在本项目里已出现多次（断笔比也是"停在 40k 的假阴性"）。

### 1. NN SSIM 在上升 —— 但它主要是"模型整体变好"的副产品

gq 的 `nn`：0.5827(5k) → 0.5927(40k) → 0.6009(65k) → **0.6030(70k)**，单调上升。
同期 `own_gt` 也在涨（0.5360→0.5505）。两者同向，所以 `nn` 上升**不能**单独读成"越来越像训练集"。

### 2. 模型**不是坏了**，但"目标/风格特异性"很弱
三个层次的分离度（gq @70k）：

| 对比 | 差值 | 读法 |
|---|---|---|
| `mean_c − mean_错字` | **+0.0360** | 模型确实**认字** ✓（同字 >> 异字）|
| `own_gt − mean_c` | **+0.0118** (t=+2.87) | 确实**偏向自己的目标** ✓，但幅度只有认字的 1/3 |
| 同书家富集 | **1.48×** | 风格信号存在但弱 |

→ **输出被"通用字形结构"主导，目标书家/实例的特异性只占很小一块。**
→ 这与项目里长期的"几何控制失效"结论方向一致，**不构成新的崩溃性故障**，但它把问题量化了：
   认字能力 (+0.036) 远强于 认人/认目标能力 (+0.012)。

## 已知口径限制
- SSIM 被字形结构主导，同字候选之间差异本就小 → 这是**粗筛级**证据，不等于"完全没学到风格"。
- 同字候选 >12 时按等间隔抽 12；改 `MAXC` 会改变 NN 的选取空间（也可能改变富集倍数）。
- 11/249 列训练集里**没有同字样本**，这些列在最近邻分析里被剔除（v1 就是因为没剔除，
  一个 nan 把整列均值污染成 nan —— 教训：**逐列过滤，别用 `mean`**）。
