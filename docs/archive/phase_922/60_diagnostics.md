## 1. D1 — `tools/probe_style_visibility.py`

### 1.1 为什么重写

`tools/probe_condition_injection.py` 是 v3/v11 时代的，它**自己重算**条件链路
（`model.char_proj(e_char)` 等），在 v13/v15/v17 上会直接崩或给错数字：

1. 假设 `factorized_add` + `char_proj`；v13 起是 `factorized_cat` + `no_char_cond=True`
   → `model.char_proj is None` → AttributeError
2. 没有 `glyph_vec_cond`（g 的池化向量也是条件操作数）
3. 不认识 v15 的 `MultiStyleEmbedder` 与 v17 的 S2（`e_style = E_callig + α·E_pair`）

新脚本**不重算数学**，改为在真实前向里挂 hook 抓 `t_emb` / `y_emb` / 每层 `c`，
然后**在 hook 之外**重算 `mod(c)` 与 `mod(c − y_emb)`
（在 hook 里调用被 hook 的模块会无限递归）。
→ 对**任何** fusion 模式 / 任何风格表形态都成立。

### 1.2 测什么

```
1) H1 幅度      ‖t_emb‖ / ‖y_emb‖ / 比值 / cos(t_emb, y_emb)
2) 可见性 Δ     ‖mod(c) − mod(c − y_emb)‖ / ‖mod(c)‖
                逐层（12 个 block）+ 逐组（shift/scale/gate × msa/mlp）+ final_layer
3) 轴对照       换书家引起的 Δy_emb 与 Δmod
```

### 1.3 怎么读

| 指标 | 健康 | 病态 | 病态的修法 |
|---|---|---|---|
| `ratio_y_over_t` | 0.3 ~ 3 | **< 0.3 = 淹没** | 放大 `callig_scale`；或把风格送进**独立于 t 的**调制通路 |
| `delta_mod_*`（风格轴） | 与内容轴同量级 | **< 0.05 = 风格几乎不进入调制** | 同上 |
| `delta_mod_layer_imbalance` | 接近 1 | ≫ 1 = 某些层几乎不参与 | 改 `glyph_inject_layers` 的层位 |

> **如果 D1 显示风格被淹没 —— S2 的三条新通路也白搭**（它们都建立在同一个
> 风格向量上）。这时应该先修调制通路，而不是上更复杂的注入机制。

### 1.4 ⚠ 退化守卫（必须知道）

`adaLN_modulation[-1]` 是 **zero-init**（adaLN-Zero）→ **未训练/刚初始化的模型上
`mod(c) ≡ 0`**，于是 `Δ = 0/0` 被 clamp 成 0，看起来像"风格完全不可见"。

这是**初始化特性，不是模型缺陷**（实测踩到，与 S2 冒烟测试是同一个坑）。
脚本会显式报 `⚠⚠ 退化：mod(c) ≡ 0` 并声明"下面的 Δ 不可读"。
**所以 D1 必须用真实训练过的 ckpt 跑。**

```bash
python tools/probe_style_visibility.py --self-test          # 只验证代码路径（随机模型）
python tools/probe_style_visibility.py \
    --ckpt assets/results/v13_base_50k/<ts>/checkpoints/0155000.pt \
    --config src/train/configs/v13_base_50k.json --n 32 \
    --out assets/d1_v13base_155k.json
```

## 2. T2 — `tools/probe_style_separability.py`

### 2.1 两个必须做对的地方（否则指标会骗人）

**① 必须"留字"交叉验证。**
如果同一批字在不同折里都出现，分类器可以靠"认出这是哪个字 → 反查书家"拿高分 ——
那测的是**字**，不是**风格**。
→ 默认 `--group-by char`：测试折里的字在训练折里**从没出现过**。
`--group-by none`（随机 CV）偏乐观，只作对照。

**② 必须同时报 GT 天花板。**
已知：DINO CLS 的 pair 质心间余弦 **0.956** —— DINO 对书家**本来就不敏感**。
所以"生成图 DINO 探针只有 8%"可能不是模型的问题，而是**特征空间天花板低**。
脚本对**同一批 GT 图**跑完全相同的流程给出天花板，
**只有"生成 / GT"的比值才有意义**。

### 2.2 两类特征

| 特征 | 维度 | 说明 |
|---|---|---|
| `dino` | 384 | DINOv2 ViT-S/14 CLS（ImageNet norm，与 `extract_dino_cls_50k.py` 同口径） |
| `style` | **29** | 手工笔画统计：墨占比 / 墨色 5 分位 + std / 笔画宽度（距离变换）mean+median+std+p90 / 包围盒 3 项 / 墨心偏移 2 项 / 边缘锐度 / 横纵游程 / 3×3 密度 / 腐蚀比 |

`style` 无天花板问题，且**可解释**（"墨色变了吗、笔画变粗了吗"）。

### 2.3 分类器（都不依赖 sklearn）

* `centroid`：最近质心（零训练，最稳，先看它）
* `logreg`：torch 手写逻辑回归 + Adam（看线性可分性上限）

外加**置换检验**（打乱标签重跑）得到经验随机水平，比 `1/n_classes` 更保守。

### 2.4 怎么读

```
判据：lift（相对置换均值）显著 > 0，且 **生成 / GT ≥ 0.5** 才算"风格真的进了像素"
```

```bash
# 从 batch_eval --save-samples 的产物跑（目录里是 g*.png + gt*.png）
python tools/probe_style_separability.py \
    --from-samples assets/ink_eval/v13_base_50k/strict \
    --eval-csv assets/eval_v13_strict.csv \
    --out assets/t2_v13base_strict.json

python tools/probe_style_separability.py --self-test   # 合成图自检
```

⚠ 目录里 `g*.png` 的**数字序**必须与 eval csv 的**行序**对应（`batch_eval` 的产物满足）。
脚本用 `g(\d+)\.png$` 锚定结尾匹配（`gt0.png` 不会被 `g(\d+)` 误匹配）。

## 3. D3 — 风格差异的空间分布

**问题**：固定噪声 + 固定字，只换书家，差异是**均匀铺满全图**（→ 风格是全局的，
adaLN 就够），还是**集中在起笔/收笔/转折/波磔**（→ 需要局部通路）？

**做法**（复用已有件）：

```python
# 1) 用 eval cache 固定噪声与 g
# 2) 只改 y_callig（同一个字、同一个 g）
# 3) 采样两张图 -> decode -> 差异图 D = |imgA - imgB|
# 4) 用 GT 的墨迹 mask 把 D 分成"笔画内 / 背景"
#    判据: mean(D | 笔画内) / mean(D | 背景)
#          ~1   -> 差异均匀（风格是全局的）
#          >>1  -> 差异集中在笔画（风格有空间结构）
# 5) 笔画内再按"到笔画骨架的距离"分环，看差异是集中在中心还是边缘（起收笔）
```

⚠ 注意：这个比值会被**白底占比 ~90%** 影响，所以必须**分区域算**，不能算全图均值
（与墨迹域指标的教训同源）。

## 4. T0 / T1 — 表与笔画

**T0（表有没有在动）**：比较 `E_callig` / `E_pair` 的**终值 vs 初始化**的余弦与范数变化。
冻结表（v13）不动是设计；可训表（v15）若几乎不动 = 梯度到不了。
⚠ 已知会"假不动"的两个原因：AdamW 的 weight decay 绕过 grad hook（`--train-only-new-callig` 已修）、
以及 zero-init 的一步延迟。

**T1（笔画统计量）**：直接复用 T2 的 `style` 特征 ——
把"同一字、不同书家"分成组，算**组间方差 / 组内方差**。
比 `ratio_style` 更可解释：**如果连笔画粗细和墨色都没变，风格就是没进去。**

## R1. D1 结果 —— 「淹没假说」被推翻

**7 个真实 ckpt，全部 `degenerate=false`**（`mod(c) ≠ 0`，指标可读）。

| ckpt | y/t | dmod | 层不平衡 | Δy_emb | 退化 |
|---|---|---|---|---|---|
| v13_base_155k | 0.7653 | **0.6433** | 1.9808 | 0.5693 | 否 |
| v15a_150k | 0.5359 | 0.5660 | **3.2452** | 0.2838 | 否 |
| v13_12ch_225k | 0.6975 | 0.5261 | 1.9657 | 0.5451 | 否 |
| v15b_supcon_70k | 0.5703 | 0.3994 | 1.5114 | 0.7982 | 否 |
| v14_s2_160k | 0.4112 | 0.2574 | 1.5044 | 0.6570 | 否 |
| v13_wd01_125k | 0.4535 | 0.1279 | 2.0039 | 0.7880 | 否 |
| v15c_fixed_210k | 0.3443 | **0.0499** | 1.9631 | 0.7379 | 否 |

### 结论 1：H1（风格被 timestep 淹没）**证伪**

判据是 `ratio_y_over_t < 0.3` 才算淹没。实测 **7/7 全部落在 0.34–0.77**，
而且 `cos(t_emb, y_emb)` 全部接近 0（≈0.045，v13_base）—— **两个向量近乎正交**。

> **风格与 timestep 在表示空间里互不干扰，幅度也同一量级。问题不在幅度，也不在淹没。**

这条直接推翻了 `30_injection.md` 里的前置假设
「若 D1 显示淹没 —— S2 的三条新通路也白搭」。**不是淹没**，所以 S2 的前提成立。

### 结论 2：真正的问题在**可见性**，且差异巨大（13 倍）

`dmod = ‖mod(c) − mod(c − y_emb)‖ / ‖mod(c)‖`，衡量"把风格向量拿掉，adaLN 调制量变多少"。

* **v13_base 0.6433** —— 风格贡献了 adaLN 调制量的 64%，非常健康
* **v15c_fixed 0.0499** —— 只有 5%，**恰好卡在判据下限 0.05**
* 跨度 **0.05 → 0.64，13 倍**

这个指标**成功区分了 ckpt 质量**，且排序与已知的 strict/墨迹域评测**一致**：
v13_base（最好）> v13_12ch > v15a > v15b_supcon > v14_s2 > v13_wd01 > v15c_fixed。

> **v15 系的风格可见性系统性低于 v13 系** —— 这正是它们"零增益"的机制解释。
> 风格确实被编码了（§R1 结论 1），但**送进 adaLN 的那一份太弱**。

### 结论 3：`Δy_emb` 与 `dmod` **负相关** —— 表不是问题，读表的人才是

把 B 表单独看：

| ckpt | y/t | Δy_emb（换书家引起的风格向量变化） | dmod |
|---|---|---|---|
| v15c_fixed | 0.3443 | **0.7379（最大）** | **0.0499（最小）** |
| v13_wd01 | 0.4535 | 0.7880 | 0.1279 |
| v13_base | 0.7653 | 0.5693 | **0.6433（最大）** |

**v15c 的风格向量变化最大（0.74），但转化到 adaLN 调制量的比例最低（0.05）。**
说明：**风格表本身在变、变得还更剧烈，但 adaLN 通路"读不动"它** ——
不是没编码，是调制层的增益/尺度太小。

> **修法指向明确**：不是重做表，是**放大风格到 adaLN 的读数**，
> 或（S2 的路线）**新开一条不经 adaLN 的通路**（B1/B2/B3）。

### 结论 4：层不平衡 —— v15a 是异类

`delta_mod_layer_imbalance = max/min`（逐层）：

* v13 系 ≈ **1.97–2.00**（基线水平）
* v14_s2 / v15b_supcon ≈ **1.50**（**最均匀**）
* **v15a 3.2452** —— 最不均匀，某些层几乎不参与风格调制

v15a 同时 `Δy_emb` 最低（0.2838）**且**层不平衡最严重 —— 两个病叠在一起，
与实际"v15a 零增益"完全吻合。

### 结论 5：`ratio_style`（1.21–2.48）**确实在骗人** —— 风格其实进去了

按判据「生成/GT ≥ 0.5」：

* **v13_base**：线性 **0.811 / 0.612**（手工 + DINO 双特征）→ **通过**
* **v13_12ch_post**：线性 **0.959 / 0.514** → **通过，且是最好的**
* **v13_styletok**：手工线性 0.809 → 通过
* **v15 全系**：手工线性 0.30–0.41、DINO 线性 **0.22–0.34** → **全部不通过**

> **DINO 线性（`acc_logreg`）是最干净的判据**（DINO 对书家本来就不敏感，
> 天花板只有 0.22，所以 0.61 已经是天花板高度的 61%）。
> 按这一列：**v13_base 0.612 / v13_12ch 0.514 达标；v15a–v15c 全部 0.22–0.34 不达标。**

这解释了为什么 `ratio_style` 在 1.21–2.48 却感觉"风格没进去"：
**`ratio_style` 测的是"同书家不同样本的离散度"，不是"跨书家的可分性"**。
前者会被随机性抬高，后者才是风格是否真的进了像素。

### 结论 6：`centroid` 在生成图上不可靠（被 41 类小样本 + 白底偏置坑了）

* **v15c_fixed 手工质心 = 0.0723，÷GT = 1.002** —— 看起来"完美"，
  但它的 DINO 线性只有 **0.110**（全表最低）。
* 原因：最近质心对**类内方差**敏感。v15c 是"墨迹最糊"的 ckpt（D1 里 dmod 也最低），
  笔画统计量的**类内方差反而变小** → 质心分类器被"糊成一团"骗了。
* **所以质心列不能单独用。必须 `centroid` 与 `logreg` 一起看，且优先信 `logreg`。**

### 结论 7：两个诊断**互相印证**（风格确实弱，但不是全废）

对齐 6 个 ckpt，算 D1 的 `dmod` 与 T2 各指标的相关：

| 对照 | Pearson r |
|---|---|
| `dmod` ~ T2 手工质心 | **−0.608**（负！被 v15c 污染） |
| `dmod` ~ T2 手工线性 | +0.512 |
| `dmod` ~ T2 DINO 质心 | +0.318 |
| **`dmod` ~ T2 DINO 线性** | **+0.719** ← 最强正相关 |

> **`dmod`（风格对 adaLN 的可见性）与 `DINO 线性可分性` 强正相关（r=+0.72）。**
> 两个独立方法（hook 抓内部调制量 vs 从像素反推书家）指向**同一个排序** ——
> 说明这个"风格弱"的结论是**真的**，不是某个指标的口径问题。

## R3. 汇总判断

| 问题 | 答案 |
|---|---|
| 风格被 timestep 淹没了吗？ | **没有**。7/7 的 `y/t ∈ 0.34–0.77`，`cos(t,y)≈0`。H1 证伪。 |
| 风格编码进表了吗？ | **进了**。v15c 的 `Δy_emb=0.74`（最大）。 |
| 那为什么零增益？ | **adaLN 通路读不动**：v15c `dmod=0.0499`，只有 v13_base 的 1/13。 |
| 风格进像素了吗？ | **v13 系进了**（DINO 线性 0.51–0.61），**v15 系没进**（0.22–0.34）。 |
| `ratio_style` 可信吗？ | **不可信**，它测离散度不是可分性 —— 这正是"误判"的来源。 |

### 对 S2 路线的直接影响

### R4.2 ★ 三个坑（本轮才发现，必须写进任何未来引用 D3 的地方）

**坑 1：噪声地板的 `in/bg` 同样 ≫ 1.5。**
噪声地板（同书家、同骨架、只换噪声）的 `in/bg` = **2.55 / 3.03 / 2.41 / 2.48**，
和"换书家"的 `in/bg`（2.50 / 2.28 / 1.90 / 2.10）**完全同量级**。

> ⇒ "差异集中在笔画内" 是**骨架约束的必然结果**（骨架外本来就是白底，噪声动不了），
> **不能作为"风格有空间结构"的证据**。原 §3 的判据（`in/bg >>1 → 值得上局部通路`）**作废**。

**坑 2：地板只采 1 次时是单样本估计，方差极大。**
同一个 ckpt 两次跑，`s/n` 给出 **1.59** 和 **0.98** 两个差异巨大的值。
⇒ 必须 `--n-floor-rep 4` 并报 `noise_D_global_std`，用**扣 σ 下界**做判据。

**坑 3：`in/bg` 与"风格强弱"无关。**
v13_wd01 的 `in/bg` 是 2.28（最低），但它的下界也最负（−0.281）。
两个指标完全不对应。

### R4.3 结论

**六个 run 的严格下界全部为负**（−0.117 ~ −0.362）：

> **换书家造成的像素差异，完全落在"换一个噪声种子"造成的波动范围内。**
> 即：**书家条件没有进入像素**。

逐字对照更直观 —— 风格 D 与噪声 D **几乎一一对应**：

| 字 | 风格 D | 噪声 D |
|---|---|---|
| （v13_base）+0.281 | 0.281 | 0.221 |
| +0.283 | 0.283 | 0.184 |
| +0.380 | 0.380 | 0.302 |

**`script-mode=same` 对照（消掉书体混杂）也一样是负的**（−0.362）：
说明"换书家"里**没有任何一部分**来自书体差异的额外贡献 —— 连书体也没进像素。

### R4.4 对 S2 的直接推论

1. **B2/B3（局部通路）的动机被削弱** —— 原动机是"差异集中在笔画内 → 需要局部通路"，
   但坑 1 证明这个观察没有区分力。
2. **但这不等于"不需要局部通路"** —— 它只说明**当前注入方式整体失败**
   （全局的都进不去，局部更无从谈起）。B2/B3 仍是**待验证的新出口**，只是
   **不能再用 `in/bg` 作为"该上哪个"的依据**。
3. **D3 的正确定位**：它是**训练后的验收指标**（判断新通路是否真的把风格送进像素），
   不是**训练前的选型依据**。

## R5. D6 结果 —— 条件因果性（★ 定位真凶）

> 工具：`tools/probe_cond_causality.py`；脚本：`_sync_work/run_d6.sh`
> 动机：D3 的分辨力不足，无法区分
> **(a) 模型没学会书家** vs **(b) 学会了但幅度极小**。

### R5.1 设计

同一张图、同一噪声、同一骨架，只改书家 id，做三路对照：

| 对照 | 改动 | 含义 |
|---|---|---|
| `D_style` | 换成另一个**真实**书家 | 书家条件的表达力 |
| `D_null` | 换成 **null id**（表末尾） | "有/无条件"的表达力 |
| `D_noise` | 换噪声种子 | 生成随机性地板 |

判据：
```
ratio_null  = D_style / D_null    >>1 = 真在区分书家；~1 = 只知道"有/无"；<1 = 条件被忽略
ratio_noise = D_style / D_noise   >1.5 = 书家效应可从随机性中辨识
```
外加 **t 扫描**：单步前向看条件在各 timestep 的作用幅度，定位注入通路是否"活着"。

### R5.2 ★ 修复的 3 个 bug（否则数字全错）

1. **书家 id 没重映射**：strict csv 的 `calligrapher_id` 是**原始 id**（461=柳公权），
   而模型表是 **45 人压缩表**（0..44）。直接喂原始 id → `make_eval_cache` 报
   "308/9016 不在词表中"；若放行则会**静默用错书家**。
   → 加 `callig_id_map_50k.json` 的 `id_map` 就地重映射（249/249 命中）。
2. **重映射后不能把 map 再传给 `make_eval_cache`**：值已是索引，再查原始表会误报
   "不在词表中"。→ 传 `callig_id_map=None`。
3. **索引空间混淆**：`picked` 存的是 `rows_all` 的**全局**下标，而 cache 只含
   `len(picked)` 行 → `IndexError`。→ 改为局部索引。

### R5.3b ★ 关键发现：`D_null` 复现恒为 0

新增的 **null 复现对照**（同样条件采两次）在所有字上给出 `D_null_rep = 0.00000`：

> **给定相同噪声 + 相同骨架，模型对相同条件的输出是逐像素确定性的。**

这有两个重要推论：

1. **生成过程本身没有随机性残留**（Heun 2 阶 + 固定噪声 = 确定性映射），
   所以 `D_style` / `D_null` / `D_noise` 三者的差异**全部来自条件或噪声**，没有额外噪声源污染。
   ⇒ D6 的信号是干净的。
2. **`D_null ≈ 0`（`丹` / `以`）不是 bug，而是"null 与真实书家产出完全相同"**
   —— 这是**最强的"风格未生效"证据**：换掉书家条件，模型输出的图**一个像素都没变**。

### R5.4 ★ 最终结论：C 类失效已确认

综合 D1–D6：

```
A 类（表不可分）       ✗ 排除 —— D5: effR90 57–74, cosμ≈0
B 类（adaLN 读不动）   ✓ 确认 —— D1: v15c dmod=0.0499 (v13 的 1/13)
C 类（出口增益太小）   ✓ 确认 —— D3 下界为负 + D6 ratio_null 中位 1.46
通路完全断掉           ✗ 排除 —— D6 t 扫描: t=0.5–0.9 作用 5–7.8%
```

> **真凶 = C 类：书家条件对输出有真实、确定性的作用（`D_null_rep=0` 证明无随机噪声干扰），
> 但作用幅度仅略高于"换一个噪声种子"（1.46× / 1.80×）。**
>
> 这不是"没学会"，而是**注入出口的增益被压得太低**。
