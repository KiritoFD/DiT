# 922 / 91 — 骨架查询层：两层、限幅、先看 5000 步

> 2026-09-24。中程监督已停。本文只定下一次实验怎么做，不改任务，不换骨干。

---

## 1. 为什么是这一步

断笔不是白点。115k 的中程监督实验里：

| 指标 | 50k | 115k |
|---|---|---|
| strict ssim | 0.538 | 0.550 |
| ink-ssim | 0.378 | 0.382 |
| 断笔比 `frag` | **1.16** | **1.76** |
| 笔画内白点 `hole` | 0.055 | 0.059 |

白点比全程贴着真迹（真迹自己约 0.056）。断笔比在 50k 之后变差，像素指标不动。中程损失降到 0.08 也不再影响这项。

E0 在 100k、学习率已收到 `5e-5` 时 strict 是 0.553。这次在 115k、学习率还有 `3e-4` 时 strict 是 0.550，ink-ssim 低于 v13 的 0.387。中程监督没有好处，不需要跑完 250k。

换骨干也不对症：

- 深度 12 改成 8，strict 掉 0.026。变短没有变好。
- 骨架不是只在输入加一次，已经有 4 层逐层注入。U-ViT 的长跳线接回去的仍是 32×32 latent，补不回比一个格子更细的连续性。
- 风格单独做一条流也没用。adaLN 上 `dmod` 放大到 1.12 之后，换书家的像素差没有变大。风格向量没有位置。

要独立出来的是骨架。画布当 Query，256 个带位置的骨架 token 当 Key 和 Value。风格只改「这一笔看哪一段」，不进入 Key 和 Value 的内容。

## 2. 模块

用现有的 `LocalStyleGlyphAdapter`，不新写一类。

```text
Q = 当前层特征 + 位置
K, V = 骨架 token + 同一份位置
风格 → 只缩放 Q 和 K
输出 = 当前特征 + 0.1 * Attention
```

位置两边都加。旧的 cross-attention 只给 K、V 加位置，Query 没有坐标，空间查询会退化成内容查询。

插两层，第 2 层和第 6 层。窗口 5，每个位置只看周围大约 25 个骨架 token。12 层全插不做。v15 每层都插，成本高 33%，墨迹指标最差。

全局 adaLN 和原来的三路骨架注入保持不动。这一层是加，不是换。

## 3. 数值约束

上一轮在 1621 步变成 NaN。损失从 1350 步的 0.405 跳到 1450 步的 1.74，然后溢出。第二轮把学习率降到 `1e-4`、投影初始标准差降到 0.02，第 2 层的输出仍达到残差流的 0.60，900 步时损失停在 2.07，梯度变成 0。只在出口乘 0.1 挡不住，因为 softmax 在出口之前就已经炸了。

三处都要限：

| 位置 | 做法 |
|---|---|
| Q、K 的投影 | 初始标准差 0.02。`_basic_init` 会把构造时的初始化冲掉，必须在它之后再设一次 |
| Q、K 的风格缩放 | 缩放夹到 `[-1, 1]`，偏置也夹到 `[-1, 1]`。否则窗口里 25 个 token 的 logits 没有上界 |
| 出口 | 固定乘 **0.1**，不用可学习的门。可学习门在 800 步时仍把残差改掉一半 |

`out_proj` 和风格投影的最后一层保持 zero-init。第 0 步这两层的输出是 0，和没加它们的模型相同。

## 4. 一次只改这一处

配置从 E0 复制。

| 项 | 值 |
|---|---|
| `local_ca_layers` | 2 |
| `local_ca_at` | `2,6` |
| `local_ca_q` | `x` |
| `local_ca_window` | 5 |
| `local_ca_heads` | 4 |
| `local_ca_rank` | 64 |
| 学习率 | 峰值 `1e-4`，warmup 200，`max_steps` 先 5000 |
| 其余 | 与 E0 相同。不开三层风格表，不开时间门，不开中程监督 |

5000 步以内出现 NaN 就停，不跳过、不续跑。NaN 之后存下来的 checkpoint 不能用，上一轮 5k 和 10k 的权重就是这样废的。

## 5. 怎么判定

5000 步看三项。缺一项就不算做完。

| 指标 | 现在 | 这一步要看到 |
|---|---|---|
| 损失 | 上一轮 1600 步 NaN | 5000 步内没有 NaN，损失不在中途跳到 2 以上 |
| 断笔比 `frag`（strict） | 中程监督 115k 为 1.76，50k 时最好 1.16 | **低于 1.2** |
| t=0.1 换书家的速度场差 | E0、斜坡门、硬门都在 0.020–0.023 | **离开 0.02** |

strict ssim 只守门。相对同一步的 E0 低过 0.02，就是字身份被这两层带坏了，停。

ssim 和 ink-ssim 不作为这一步的成功标准。它们在中程监督里一直涨，断笔比同时变差。

## 6. 不做

| 不做 | 原因 |
|---|---|
| U-ViT、换骨干 | 测到的不是深层稀释。断笔在 32×32 latent 里，长跳线补不回更细的连续性 |
| 风格单独一条残差流 | 风格没有位置。幅度已经放大过，像素差不涨 |
| 12 层都插 | v15 的成本高 33%，墨迹指标最差 |
| 中程监督一起开 | 刚证明没有好处，而且会和这一层的效果混在一起 |
| 把 0.1 的出口倍率改成可学习 | 上一轮就是这样在 800 步失控的 |
| NaN 后继续跑 | 训练循环会跳过 NaN 步，看起来还在跑，权重已经坏了 |

5000 步这三项都没有动，就停在两层。不加到 12 层，也不换骨干。
