## 2. 问题定义：三层漏斗

风格要影响像素，必须连续通过三关。任何一关断掉，下游指标都表现为"风格无效"，但修法完全不同。

```
[A] 编码：风格表本身可分吗？        → D5 探针
[B] 注入：adaLN 能"看见"风格吗？    → D1 探针
[C] 出口：风格差异真的落到像素了吗？ → D3 / D6 / T2 探针
```

**归因裁决（2026-09-22 晚，D1–D6 全跑完后）**：

```
A 表不可分          ✗ D5 排除（effR90 57–74, cosμ≈0）
B adaLN 读不动      ✓ D1 确认（v15c dmod=0.0499）
C 出口增益太小      ✓ D3 下界负 + D6 ratio_null 1.46   ← ★ 真凶
通路完全断掉        ✗ D6 t 扫描排除（t=0.5→7.4%, 0.7→7.8%, 0.9→5.4%）
```

### 3.2 D1 — 风格在 adaLN 里有多"可见"（7 个真实 ckpt）

方法：**不重算数学**，在真实前向挂 hook 抓 `t_emb / y_emb / 每层 c`，在 hook 之外重算 `mod(c)` 与 `mod(c−y_emb)`。对任何 fusion 模式都成立。
（旧工具 `probe_condition_injection.py` 自己重算条件链路，在 v13/v15/v17 上直接崩或给错数字，已废弃。）

| run | ‖t_emb‖ | ‖y_emb‖ | cos(t,y) | **ratio_y/t** | **dmod 均值** | dmod min–max | 层不平衡 | degenerate |
|---|---|---|---|---|---|---|---|---|
| v13_base_155k | 29.10 | 22.27 | 0.0449 | **0.765** | **0.6433** | 0.454–0.900 | 1.98 | False |
| v15a_150k | 38.70 | 20.74 | 0.1626 | 0.536 | **0.5660** | 0.256–0.832 | **3.25** ←最差 | False |
| v13_12ch_225k | 32.39 | 22.59 | 0.0397 | 0.698 | 0.5261 | 0.374–0.735 | 1.97 | False |
| v15b_supcon_70k | 35.74 | 20.38 | −0.2382 | 0.570 | 0.3994 | 0.323–0.488 | 1.51 | False |
| v14_s2_160k | 48.94 | 20.12 | −0.2253 | 0.411 | 0.2574 | 0.215–0.324 | 1.50 | False |
| v13_wd01_125k | 33.35 | 15.13 | −0.0910 | 0.454 | 0.1279 | 0.089–0.177 | 2.00 | False |
| v15c_fixed_210k | 46.75 | 16.10 | −0.2241 | **0.344** | **0.0499** | 0.035–0.068 | 1.96 | False |

**三条结论**：

1. **H1「风格被 timestep 淹没」证伪**。7/7 的 `ratio_y/t ∈ 0.34–0.77`（判据 <0.3 才算淹没），`cos(t,y) ≈ 0.045`（正交）。**风格与 timestep 幅度同量级、互不干扰，问题不在幅度。**
2. **★ 关键悖论**：v15c 的 `Δy_emb = 0.7379`（**最大**，表动得最剧烈）却 `dmod = 0.0499`（**最小**，通路最读不动）→ **表在动，但 adaLN 读不动**。真问题是**可见性**，不是编码。
3. **`dmod` 跨度 13 倍**（0.050 → 0.643），且与已知的 strict / 墨迹域评测排序一致 → 指标可信。v15a 层不平衡 3.25 + Δy_emb 最低 0.2838 → 两病叠加，与"v15a 零增益"吻合。

⚠ **退化守卫**：adaLN-Zero 的 `adaLN_modulation[-1]` 是 zero-init，未训练模型上 `mod(c)≡0`，`Δ=0/0` 被 clamp 成 0，看起来像"风格完全不可见"。脚本会显式报 `⚠⚠ 退化，Δ 不可读`——**这是第 3 次踩同一个坑**（S2 冒烟、梯度测试各一次）。

### 3.3 T2 — 生成图的风格可分性（8 个 run）

口径：n=249 / **41 个书家**（不是 45）/ **留字交叉验证**（group_by=char）/ 随机基线 **0.0244**。

### 4.1 风格编码链（历史，v13 → v15，全部失败）

**根因链（四次失败不是同一个原因）**：

```
v14 失败 → 标签粒度不是瓶颈（45→87 无效）
v15 失败 → 不是容量问题，是"表没区分度"（DINO 质心余弦 0.956）
v13/v14 的"健康几何" → 是标签驱动的（DINO 锚定因提取 bug 从未生效）
```

**逐书家分析（style 是瓶颈的最硬证据）**：

| 书家 | 训练样本 | strict |
|---|---|---|
| 苏轼 | **3,131**（最多） | **0.3485**（最差） |
| 李邕 | 1,168（风格统一） | **0.6300**（最好） |

```
r(该书家训练样本数, strict) = −0.62
```

### 4.2 few-shot 新书家（两轮，全部失败）

**第一轮（K=10, lr=1e-3, 1.5k 步）**：

| 书家 | 基线(不训) | 训练 1.5k 步后 |
|---|---|---|
| 徐渭 | 0.4163 | **0.3968** ✗ 变差 |
| 沈周 | 0.4187 | 0.4244 → 0.3924 → **0.3881** ✗ 持续下降 |
| 怀素 / 伊秉绶 | 0.4442 / 0.1958 | （run 失败，无 eval） |

失败原因（按顺序撞到）：
1. ★★ **EMA 掩盖了训练** —— `ema_decay=0.9999, interval=4`，1.5k 步只有 375 次 EMA 更新 → `0.9999^375 = 0.963` → **EMA 只反映约 3.7% 的更新**。评测默认用 EMA → 训练看不见。解法：`use_ema=False`。
2. **均值初始化量级不对** —— 预训练表各行范数 med=11.0 / mean=8.9，而**均值向量范数只有 2.06** → 起点就是分布外（小 5 倍）。
3. **LR 1e-3 太高 + 1.5k 步 = 15k epochs 过 10 张图** → embedding 漂移出分布（新行范数涨到 2.0，旧书家 ~11）。

**第二轮（K=50, lr=1e-4, 200 步）**：

| 书家 | 基线 | 训练后 2 次 eval | 趋势 |
|---|---|---|---|
| 怀素 | 0.4599 | 0.4392 → 0.4381 | **平** |
| 伊秉绶 | 0.1820 | 0.1916 → 0.1915 | **平** |
| 徐渭 | 0.4289 | 0.4136 → 0.4130 | **平** |
| 沈周 | 0.4282 | 0.4155 → 0.4151 | **平** |

**★ 综合结论：单向量 + 冻结主干，学不会一个新书家。**

```
K=10, lr=1e-3, 1.5k步 → embedding 动了，结果变差
K=50, lr=1e-4, 200步  → embedding 几乎没动，结果平的
=> 动少了没变化，动多了变差，没有甜点区 ✓
=> 一个 128 维向量无法捕获新书家的风格 ✓
=> 与 r=−0.62（样本多→风格跨度大→装不下）互相印证 ✓
```

⚠ 这**不是**"多 style token 无效"的证明（那需要解冻/从零训），它只否定了"只调一行向量"这一种做法。

**可直写性上界**（零梯度直写）：模型自己训出来的行 0.6342 > 手写 DINO 质心 0.5229 > 87 行均值 0.5107 → **零梯度直写只追回训好行的约 10%**。50 张已饱和（50→100→200 张零增益）→ 剩余差距不是数据量问题，是"冻结主干 + 只有一行可训"的设定上限。

## 7. 工程踩坑清单（本方向专属，重启时先读）

### 7.1 会静默失效的（最危险）

| # | 坑 | 后果 |
|---|---|---|
| 1 | **`_basic_init` 冲掉所有 zero-init** | `initialize_weights()` 对每个 `nn.Linear` 做 `xavier_uniform_`，必须在**末尾再设一次** |
| 2 | ★ **`W_up` 不能用 zero-init** | `W_up=0 → ∂L/∂W_up ≡ 0`，**打开主干 gate 也救不回来**，参数永远不动 → 用 `STYLE_ADA_INIT_STD=0.002` |
| 3 | ★ **零初始化模型做梯度测试得"全零"假象** | 未训练时 `adaLN[-1]` 与 `final_layer.linear.weight` 全 0 → 输出结构性恒 0 → 极易把"接通了"误判成"没接通" → 测梯度前必须 `activate_backbone()` |
| 4 | **adaLN-Zero 模型 step 0 输出恒为 0** | 任何"改条件应改输出"的测试在初始化时必然 Δ=0（**同一个坑的第 3 次出现**：S2 冒烟 / D1 探针 / 梯度测试） |
| 5 | ★ **构造期维度 ≠ 运行期维度** | `c_style = e_callig` 维度由运行时开关决定（`xl_highdim` 下是 384 不是 128）→ `RuntimeError` → 3 处懒适配 |
| 6 | **`condition_fusion` 4 条互斥分支漏接** | 参数量正常 / 前向不报错 / **指标与 baseline 逐位相同** → 必跑 `test_style_wiring.py` |
| 7 | **`cli.py` 的 `parse_known_args()` 漏传 argv** | 只有真命令行启动才读得到 `--config`；程序化 `parse_args(['--config',p])` **静默拿不到**，全退回默认值、不报错 |
| 8 | **`batch_eval` 把 ckpt args 强制转 dict** | 所有架构参数被忽略（v13 seen 0.5697→0.7590） |
| 9 | **`model_io.build_model_from_args` 漏补 S2 字段** | 独立评测静默构造旧架构，S2 权重变 unexpected key |
| 10 | **`--train-only-new-callig` mask bug** | MultiStyleEmbedder 表不含 null 行 → mask 算成空 → **0 参数可训，训练完全空转** |
| 11 | **加性 β 必须乘 keep** | 否则污染 drop-g / uncond 分支（乘性 γ 不用） |
| 12 | **`y_callig` 在设了 `callig_script_map` 时装的是 pair_id(87)** | hier 模式主效应表只有 45 行 → 越界/静默串书家，必须用 `y_callig_raw` |

## 8. 遗留与下一步

### 8.1 ★ 本次实验最大的证据缺口

- `ratio_null` 是否从 1.46 提升？
- T2 `DINO线性 ÷ GT` 是否改善？

### 8.2 若重启，建议顺序

1. **补探针**（D1+T2 在 E1@40k 上）→ 判定是真无效还是判据无效
2. 换判据为主：T2 `DINO线性 ÷ GT`（≥0.5）+ `ink_ssim`，strict 降级
3. 若 `dmod` 未达标 → **改动 3**：`x` 的直接风格加法（绕开 `glyph_scale=0.4` 的二次衰减）
4. 再不行 → **改动 4**：`t_emb` 也加 LN
5. E2（改动 1+2，rank64）只在改动 1 被证明有效后才值得起

### 8.3 当前方向（已切换）

风格注入于 2026-09-23 停止，GPU 转给**中程结构监督**：

- 载体：GT 图派生的 **20px 实例粗骨架**（宽度由残差探针 + GT 笔画宽度分布 p50=19.4px 双证据确定）
