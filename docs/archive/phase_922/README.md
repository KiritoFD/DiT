### 现状

在**中文书法单字生成**（DiT + Flow Matching，36M 参数，从零训练）上：

- **strict（未见 (书体,书家,字) 三元组，n=249）最好成绩 ssim ≈ 0.573 / ink_ssim ≈ 0.390**
  （`v13_12ch_post`）；主线基线 `v13_base_50k` 0.5711。
- **像素级 ssim 已饱和**：容量翻倍、深度减半、12ch、wd 调整、xattn、多风格表 —— 全都没突破 0.58。
- **仅有的两个大杠杆**：① 数据质量（top6→fame，**+0.087**）② 实例级骨架条件（**+0.30**，
  但 GT 骨架推理期拿不到，是**上界不是可用手段**）。
- **风格可控性是明确短板**：`ratio_style` ≈ **1.2–2.5**（理想 5–10）= 换书家 ≈ 换噪声。
- 09-22 新增**墨迹域指标**（`ink_ssim`/`ink_iou`）—— 全图 ssim 被 ~90% 白底抬高，
  「升 vs 陞」这种**完全不同的字**也能拿 0.61。**排序没变，但差距被放大 3.6 倍。**

### 两个问题的结论（详细论证在 20 / 30）

| 问题 | 结论 |
|---|---|
| **表要三层分级吗？** | **要，但要的是"语义分解"不是"标签细分"。** v14 的 45→87 是标签细分，零增益是预期的；三层分级的价值在于**可分解**：书体走"调制骨架"、书家走 adaLN 全局笔法、pair 作**残差**（可置零回退）。真正的判据不是 strict ssim（会零增益），而是 **few-shot 新书家的上限**与 `ratio_style`。 |
| **adaLN 换 cross-attn 吗？** | **不换。** adaLN 与 xattn 承载的语义不同（风格=全局 vs 内容=空间），风格主要是全局属性，adaLN 语义正确且成本为零。实测三种注入方式的效应量 **≤0.008（噪声级）**，而 xattn 成本 **+33%** 且独立口径下**最差**。要做的是**加**一条廉价的"风格调制骨架"（FiLM on g_tok，zero-init 可回退），不是换。 |

## ✅ 诊断结果（2026-09-22 已跑完，真实 ckpt）

> 7 个 ckpt 跑 D1、8 个 run 跑 T2。完整分析见 [`60_diagnostics.md`](60_diagnostics.md) §R1–R3。

### D1 —— 「淹没假说」**证伪**

| ckpt | y/t | dmod | 层不平衡 |
|---|---|---|---|
| v13_base_155k | 0.7653 | **0.6433** | 1.98 |
| v15a_150k | 0.5359 | 0.5660 | **3.25** |
| v13_12ch_225k | 0.6975 | 0.5261 | 1.97 |
| v15b_supcon_70k | 0.5703 | 0.3994 | 1.51 |
| v14_s2_160k | 0.4112 | 0.2574 | 1.50 |
| v13_wd01_125k | 0.4535 | 0.1279 | 2.00 |
| v15c_fixed_210k | 0.3443 | **0.0499** | 1.96 |

1. **风格没被淹没** —— 7/7 的 `y/t ∈ 0.34–0.77`（判据 <0.3），且 `cos(t_emb,y_emb)≈0`（正交）。
   **问题不在幅度。**
2. **真问题是"可见性"** —— `dmod` 跨度 **0.05 → 0.64（13 倍）**。
   v15c 的风格向量**变化最大**（`Δy_emb=0.74`）却**转化率最低**（`dmod=0.05`）
   → **不是没编码，是 adaLN 读不动。**
3. `dmod` 的排序与已知 strict/墨迹域评测**一致** → 指标可信。
4. v13 系 ≈2.0 层不平衡；v15a **3.25**（最差，且 Δy_emb 最低）—— 两个病叠加。

5. **`ratio_style`（1.21–2.48）确实在骗人** —— 它测的是"同书家离散度"不是"跨书家可分性"。
   按 DINO 线性（最干净的判据）：**v13 系 0.51–0.61 达标，v15 系 0.22–0.34 全部不达标。**
6. **`centroid` 在生成图上不可靠** —— v15c 手工质心 ÷GT=1.002 却 DINO线性 0.110
   （被"糊成一团 → 类内方差变小"骗了）。**必须优先信 `logreg`。**
7. **两个诊断互相印证** —— `dmod ~ DINO线性` **Pearson r = +0.719**。
   内部调制量与像素级可分性指向同一排序，结论**不是口径问题**。

### 对 S2 的影响

* **S2 动机成立** —— 表在动、但 adaLN 读不动，新开一条独立通路是对的方向。
* **S2 训练时必须监控新模块的 `dmod`** —— 否则会重演 v15c 的 0.05。
* **层位有讲究** —— v15a 层不平衡 3.25 最差，建议加跑 **T3**：用 D1 的 `per_layer`
  找 `dmod` 最低的两层，作为 `--local-ca-at` 的候选。
* **主指标换掉** —— `ratio_style` 降级为辅助；**主指标 = T2 `DINO线性 ÷ GT`（目标 ≥0.5）**；
  strict ssim（0.573，已饱和）弃用。

### ⚠ 比这两个问题更靠前的两件事

1. **表的向量从哪来还没解决** —— DINO CLS 对书家**几乎不区分**（pair 质心间余弦 **0.956**），
   用 DINO 建的表行间余弦 **0.860**（几乎共线）。SupCon（纯 pair 标签）能做出余弦 **0.0019** 的表，
   但 `v15b_supcon` 的最终值还没跑齐。**在"表里有信息"之前讨论表结构/注入方式，都是在噪声上做设计。**
2. **口径必须先统一** —— 训练内 eval 与独立 `batch_eval` 差 **0.126**（未查清）；
   CFG 评测下所有"只由 g 驱动"的通路**结构性抵消**（doc 67），
   历史"xattn 无用"的结论是这个口径的产物，不一定是 xattn 本身没用。

## 读数字前的三条铁律

1. **strict 必须 n ≥ 249**，n=50 低 0.004~0.016 且**偏差不是常数** → 跨 n 比较无效。
2. **不同 cfg / k 的指标不可相减**（v12 的 ratio 1.83 与 v13 的 1.42 不是涨跌）。
3. **独立口径 vs 训练内口径不可混**：同一 ckpt 差 0.126（v15c_fixed 实测）。
