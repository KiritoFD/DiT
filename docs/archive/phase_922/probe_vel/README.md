# 换书家速度场差（`signal_tracing.py --probe-t`）—— 5 个 ckpt 扫描

口径：`‖vA−vB‖/‖vA‖`，A/B 为**同字同书体、不同书家**（12 组），固定同一个 `x_t` 与同一个 `g`，
只换 `y_callig`。probe 模式**只做前向、不采样** → CPU 可跑（约 2–4 分钟/ckpt），不占 GPU。

| t | E0@60k | E0@80k | **E0@100k** | inj3@25k（旧数据） | inj3-fixed@40k |
|---|---|---|---|---|---|
| **0.10** | 0.0264 | 0.0246 | **0.0223** | 0.0208 | 0.0227 |
| 0.30 | 0.0286 | 0.0320 | 0.0326 | 0.0182 | 0.0221 |
| 0.50 | 0.0638 | 0.1056 | **0.1826** | 0.0278 | 0.0364 |
| 0.70 | 0.1285 | 0.1960 | 0.2614 | 0.0543 | 0.0702 |
| 0.90 | 0.1992 | 0.2676 | **0.3266** | 0.1020 | 0.1226 |

---

## 结论 1 ★ t=0.1 **结构性地卡在 ~0.02**，且不随训练增长

E0 自己从 60k → 80k → 100k，其余 t 都在涨（t=0.5 涨了近 3 倍），
而 **t=0.1 从 0.0264 略降到 0.0223**。inj3@25k / inj3-fixed@40k 也是 0.021 / 0.023。

→ 这个量在 t=0.1 处**饱和在 0.02**，与步数无关、与已试过的机制（gate / lowrank / inj3）都无关。
→ 若目标是「把 t=0.1 拉上去」，**目前没有任何一条路做到，连 baseline 自己都不涨**。
→ **该判据在 t=0.1 上分辨力为零**，用它判定机制有效/无效会得到假阴性。

## 结论 2 ★ t≥0.5 **强依赖步数** —— 跨 step 比较是错的

E0 的 t=0.5：60k = 0.064 → 80k = 0.106 → 100k = 0.183（近 3 倍）。
所以「E0@100k 0.183 vs inj3-fixed@40k 0.036」这类比较**毫无意义**。
**任何 t≥0.5 的结论必须同 step 比。**

⚠ 当前障碍：E0 的 25k/40k ckpt 已被 `ckpt_keep=8` 轮转删除（现存 60k–100k），
所以 inj3 那侧的同 step 对照要等 inj3-fixed 跑到 60k+ 才能做。

## 结论 3 ★ 书家条件主要在**高 t**（去噪早期）起作用

t=0.9 时换书家能改变速度场 **33%**；t=0.1 时只改变 **2%**。
→ **风格是早期注入的，不是收尾时加的。**

这解释了为什么所有「出口侧 / 后程」的风格注入改动都无效：
`gate`（后程把骨架压到 0.15）、`lowrank_spatial`、E1 的 `style_gain` ——
**它们改的都不是风格真正起作用的地方。**
