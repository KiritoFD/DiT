# CHAED审美基线：未通过，不进入正式排名

本次完成的是**官方CHAED可用子集 + 冻结HWD VGG特征 + Ridge回归**，不是原论文的22维全局/10维部件特征ANN，也不是TabNet复现。未把它冒充正式书法审美分数。

## 数据和验证

官方标注表包含1000条、100字；实际公开ZIP包含990张图，缺失GB3632的全部10张。已逐项核对ZIP与标注，不存在可直接修复的同名图片；本基线明确使用990张/99字，不重映射缺失标签。覆盖见`coverage.json`。

官方说明采用同字奇数图片训练、偶数图片测试。本次基线改为更严格的5折字符分组外层验证；内层4折仍按字符分组，训练集内拟合StandardScaler和选择Ridge强度。评分尺度0–100。它回答未见字符上的回归能力，不复用论文的测试成绩。

| 项目 | 留出MAE↓ | 留出PCC↑ | 留出SRCC↑ |
|---|---:|---:|---:|
| HWD特征+Ridge | 17.9686 | 0.0713 | 0.4045 |
| 仅预测训练均值 | 18.3218 | -0.0401 | -0.0389 |

MAE仅降低约0.35分。不同折不稳定：其中一折MAE22.48、PCC0.0178。合并PCC远低于多数单折PCC，不能选择性只展示较好的折或SRCC。回归预测没有裁剪，保留不稳定的域外输出。

## 历史书法迁移校准

固定24张真迹，比较原图与自动扰动。下表为原图预测分数高于扰动图的比例；它不是人工审美准确率。

| 对照 | 原图获更高分 |
|---|---:|
| 擦除横向区域 | 54.17% |
| 笔画增粗 | 45.83% |
| 高斯模糊 | 45.83% |
| 纯白图 | 75.00% |

未表现出可靠偏好，不对48端继续扩展该失败评分器，也不发布它给模型排的名次。4090上9个面板的探索性输出保留在`assets/eval_chaed_20261029/4090/`，明确标记exploratory_only。

## 结论与未完成边界

这个负结果只否定当前HWD特征线性审美回归基线，不否定CHAED标签、结构特征或TabNet方法。原CHAED部件特征依赖部件分割资料，不能拿训练集手工部件标注直接用于没有对应标注的生成图。正式CHAED/TabNet完整复现尚未完成，审美主指标继续留空。

实现：`tools/eval_unpaired/hwd/aesthetic.py`。权重与数据由4090自行下载；全程CPU、两线程、低进程优先级，未修改生成器或占用训练GPU。
