## 读法：谁在哪一列领先

- **SSIM** 最佳：`S0` = 0.6027（其后 S8、S0@85k）
- **LPIPS** 最佳：`S0` = 0.3395（其后 S4、K + D1dec）
- **Ink-IoU** 最佳：`S4` = 0.2951（其后 S3、S6）
- **碎片比** 最佳：`S1` = 2.2650（其后 S4、K + D1dec）
- **骨架IoU** 最佳：`K (A@43429)` = 0.0258（其后 K + D1dec@500、S4）
- **OCR top1** 最佳：`D3 + D1dec` = 78.8900（其后 D3 (起点错)、K + D1dec@500）
- **direction** 最佳：`K + D1dec@500` = 0.5571（其后 K + D1dec@2000、K + D1dec@1500）

> 注意：S0 / S4 在 SSIM、LPIPS、Ink-IoU 上领先，但它们**从未测过 OCR 与 writer direction**（S 组没有 T3）。因此不能据此说 S0 全面优于 K —— 只能说 K 是唯一同时有内容指标与书家条件指标的节点。补齐 S0/S4 的 T3 是当前最该做的一步（每臂约 10 分钟）。
