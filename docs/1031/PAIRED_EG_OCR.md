## 口径

- **E-G**：`tools/eval_unpaired/domain/statistics.py::verification` 的 pooled ROC AUC。
  同书体、排除同字、K=64 参考、逐 writer 取 64 张，pooled 汇总。
- **参考库**：3461 张训练参考特征（`assets/metrics_index/ref_features.npz`），
  远端 121 面板与本地 53 个历史面板**使用同一份**。
- **OCR**：`tools/f_20261101/eval_arm.py::ocr_and_ink`，Duguang 识别器，同一张生成图。
- **身份核验**：面板 `gt{i}.png` 与协议 CSV 逐张最近邻，必须构成 `0..186` 恒等映射。
- **口径可信度**：旧冻结缓存复现 S4 = 84.908（发布值 84.91）。

## 四条结论

1. **v80 是跨三张图最稳的模型族**：E-G×OCR 上 86.7/73.8，SSIM×LPIPS 上 0.6192/0.3805（双第一）。
2. **CFG 提高 E-G 但压低 OCR**：1.2→1.6 使 E-G 涨 3.2pp（86.74→89.93），OCR 反而从 66.28 降到 65.12。
   两个指标确实在对抗。
3. **两轴不重合**：全图最高 E-G 是 CFG1.6（89.93），最高 OCR 是 ExpA@70k（80.23），
   没有模型同时占据两轴顶点 —— 评估必须双轴并列，不能合成单一分数。
4. **后训练验证闭环**：D1 错误起点 E-G 55.41 → D1b 正确起点 75.94（+20.5pp），OCR 不变；
   D1b 生成器 368/368 与 K 逐位相同。
