# 证据矩阵：哪些实验能直接比较，哪些数字仅能归档

> 截止 2026-10-31，仓库主分支 `fc7985232833` + [阶段总结](README.md)。本页是所有后续理论与模型选择的**证据约束**。只摘录已经写在仓库文档中的测量，不把远端尚未入库的 CSV/PNG 视为本次已重新计算。

## 1. 核心研究问题与四条实验轴

目标：在 STD 图 `g`、书体 `s`、Writer ID `w` 下生成合法、可信、有相应书家特征的单字图 `x`。四个目标为：
- **内容正确性 C**：字符可读、笔画与部件结构合法；OCR Top-1/Top-5、人工缺笔/误字、结构指标。
- **Writer 忠实度 W**：同书体跨字真迹与生成的身份关系；E-G AUC/EER/mAP、同噪声 Writer-swap。
- **感知与细节 Q**：LPIPS、SSIM、Ink-IoU、宽度、断裂、飞白和异常率。
- **泛化 G**：Seen、只组合未见、Writer 内未见字符、全部阶段未见字符、来源/作品未见必须分开。

**不构造一列“总分”**。因不同目标本来可能发生 Pareto 权衡，且风格分类器和单 GT 相似度不是互相独立的真值。

## 4. J 组：匹配5k的图像监督/Decoder对照

来自同一个 **Deep-Sym4@85k** 起点；即使训练只5k，也**不是5k冷启动**。

| arm | 监督/Decoder | SSIM↑ | LPIPS↓ | IoU↑ | Writer Micro Top1↑ |
|---|---|---:|---:|---:|---:|
| J0 | FM、冻结Decoder | .6149 | .3220 | .3437 | **64.17%** |
| J1 | 冻结Decoder+图像Loss | .6149 | .3222 | .3428 | 60.96% |
| J2 | 解冻Decoder+图像Loss+GT重建 | **.6198** | .3150 | **.3447** | 63.64% |
| J3 | 解冻Decoder+图像Loss、无GT重建 | .6193 | **.3147** | .3433 | 62.03% |

J2−J0 ΔSSIM **+.0049**，95%CI **[+.0039,+.0060]**；J1≈J0。结论是**图像域适配有价值**，但 J2 与 J3 之间没有清晰优势，且独立 Writer 没有同步提升。训练配对和样本 bootstrap 也不能排除新训练 seed 波动。

J5/J6/J7 的 h187 OCR **82.56/81.98/81.40%** 基于更成熟的 Deep85 前置，不可与 S50k 的 OCR 简单归因于 Decoder。训练 panel original vs decoder_swap 同为96.15%，该 panel 已接近 OCR 饱和，只能证明未检测到变化。[1028完整对照](../1028/CONCLUSION_AND_NEXT_PHASE_20261028.md)、[1031 OCR记录](../../1031.md)。

## 6. 不可混用的五种量

| 名称碰撞 | 正确处理 |
|---|---|
| `S0@85k SSIM .5963`（serial）与 `.6081`（eval_p125） | 同一PNG、**SSIM实现参数不同**，按评测工具版本保留两列，不求平均 |
| LPIPS-Alex vs LPIPS-VGG | 网络不同，不能通过简单数值转换 |
| `P2@120k`、`P3A@125k` | 早期计划别名；真实累计 **70k、75k**，保留名称但显示实际步 |
| `eval200fix`、`heldout`、`validation_val100` | 目录名不是数据集身份；CSV哈希、样本索引、GT哈希为准 |
| E-G real AUC95.98、S5 gen AUC87.98/89.99、Writer Top1 63 | 三者数据/统计任务不同，不能相减称“书法差多少” |

**不完备或冲突**：`1030p125.md` 早期说 val100“全部在Top10训练集内”，而 `docs/1030/eval_style_v2/FINAL_REPORT.md` 审计写 **48 seen /50 unseen**（其余需看有效查询/映射）。在未核对**同一份CSV SHA + 全阶段训练字集合**以前不选任何一个真值；所有 seen/unseen 结论由重新构造的三层 manifest 决定。

## 7. 原始结构化数据的追加审计（优先于口头总结）

新增 [06直接CSV复核](06_RAW_DATA_RECONCILIATION.md) 从 **616条** `points_all.csv` 记录明确核出：v68原生@200k SSIM **.614868**（107统一复评约**.6169**）、v70相对v68在5k **+.01164**、65k **−.02977**，v72相对v68同50k **+.02984**。这进一步要求我们把STD骨架失败描述为“**早期有优势、随后相对平台/掉队**”，不允许宣告STD起步就不适合。

此外，`p125_metrics_full_4090.csv` 的同名P0/P1/P2 SSIM为 **.5642/.5729/.5965**，而原生serial值为 **.5573/.5636/.5857**；表头仅15列却有5行含18列且S0两seed重复。因此未经修正该CSV**不能作为无损、唯一的统一指标数据库**，尤其不能将SSIM绝对值直接横向拼接。

## 8. 用此矩阵作研究决策的规则

一个结论要写为“结构因果增益”，必须明确：固定了什么、真实变化了什么、实验输出是否来自同一逐图样本和随机种子、是否跨越损失实现/训练 LR 错误，以及效果的不确定性。此前有数字而缺任一约束的，只能叫“观察”或“候选”，不能叫已证结构规律。

下一步以 [严格评测/勘误](04_EVALUATION_AND_ERRATA.md) 为证据门槛，以 [后训练优先队列](05_NEXT_EXPERIMENTS.md) 为执行计划；理论可解释性见 [math/01](../math/01_CONDITIONAL_FLOW_AND_TIME.md)。
