# P0.5：拓扑 Loss 的额外收益**未能证明**（含一次自我更正）

**日期：** 2026-11-02  
**脚本：** `tools/d_20261101/p05_invert.py`  
**数据：** `assets/d_20261101/p05/p05.json`  
**回答的问题：** 拓扑 Loss 是否比普通图像重建提供了**额外的、可利用的**修复梯度？

## 结论（先说最重要的）

**未能证明。** 修正一个符号错误后，B（重建 + soft-clDice + 墨量）相对 A（纯重建）
的优势从「巨大」缩到**与噪声不可区分**。

| 组 | 变体 | frag 起点 | frag 终点 | 过度破碎率 | |Δz| |
|---|---|---|---|---|---|
| worst20 | A（L1+LPIPS）| 9.088 | **2.611** | 1.00→0.75 | 0.546 |
| worst20 | B（+clDice）| 9.088 | **2.275** | 1.00→0.65 | 0.555 |
| random20 | A | 1.090 | **1.567** | 0.20→0.30 | 0.543 |
| random20 | B | 1.090 | **1.707** | 0.20→0.35 | 0.583 |

逐字胜负：worst20 中 B 胜 **13/20**，random20 中 B 胜 **10/20**（另有 4 个持平）。
worst20 的逐字 Δfrag(B−A) 均值 **−0.336，标准差 1.494** ——
**均值远小于标准差，判定为噪声**。

**在随机字上 B 甚至比 A 更差**（1.707 vs 1.567）。

## ⚠️ 自我更正：之前那版结论是错的

本文档的**前一版**报告了 B 把 worst20 的 frag 从 9.088 打到 **1.076**、
random20 从 1.090 打到 **0.994**，并据此断言「拓扑项提供了重建项没有的修复梯度」。

**那个结果是符号错误造成的假象。** 原代码写成：

```python
pw = torch.sigmoid(-(img.mean(1, keepdim=True)) * 6.0)   # 错
```

墨迹是**暗**的（通道均值接近 0），正确写法应是 `sigmoid(+k*(0 − mean))`。
写成负号后，`sigmoid(-0*6)=0.5` 落在墨上、`sigmoid(-1*6)≈0.002` 落在背景上，
**墨迹概率被整体反相**。于是变体 B 实际在优化：

> 「让**背景**去匹配 GT 的**笔画**掩码」

这会把笔画擦掉、把连通块数压到接近 1 —— 看起来像「完美修复断笔」，
实际是**把字擦没了**。同时墨量约束项 `|ink_p − ink_t|` 也在朝错误方向推。

**教训：** 墨迹极性（暗=墨）在本仓库反复出错（`topology_split` 的首次单元测试、
本脚本、`ts_window_audit.py` 三次都栽在这里）。
凡是把图像转成「墨概率」的地方，**必须先用一个已知的笔画像素断言 mask 非空**，
否则整个指标会静默归零或反相。

## 修正后仍然成立的部分

1. **A 会主动制造破碎。** random20 上 A 把 frag 从 1.090 推到 **1.567**、
   过度破碎率 0.20→0.35。纯重建目标对「连通」没有偏好 —— **这个观察在修正后依然成立**，
   因为 A 完全没有拓扑项（符号错误只影响 B）。
2. **B 的墨量约束也来自错误方向**，修正后它不再有那种异常优势，说明
   原结论里「B 的 L1→GT 更低」也不可采信。
3. **梯度方向存在的证据不成立。** 需要重做。

## 对 P1 的影响（结论变了）

- **P1（生成器 + 结构 Loss）的必要性证据减弱。** 本实验原本要回答
  「拓扑项是否有独立价值」，现在**没有答案**。
- 原本建议「GARU 暂不启动、先跑 P0.5」—— P0.5 **跑完了但没给出支持**。
  现在的状态是：**A/B 都只能把 worst20 从 9.09 降到 ~2.3–2.6，
  且两者差异在噪声内。** 也就是说**在 latent inversion 这个设定下，
  拓扑项没有表现出独立价值**。
- 这不等于「P1 不该做」，而是「**P1 的前提尚未建立**」。
  若要继续，需要一个**信号更强的对照**：加大 inversion 步数/学习率使 A 逼近收敛，
  再看 B 是否仍无优势；或直接在训练里做小规模 A/B（成本更高）。

## 修订后的 P0.5 建议

在投入 P1 之前，把本实验做扎实（成本仍然远低于训练）：

1. 修好极性后**重跑并加大预算**（如 600 步、lr 0.1），确认 A 已接近收敛下界；
2. 加入**第三个变体 C = A + 仅墨量约束**，分离「拓扑」与「墨量」两种信号；
3. 逐字报告 `over_frac` / `merged_frac`（已有 `topology_split`），
   并**同时报告被擦除的比例**（`ink_after/ink_gt`）——本轮的教训是
   「frag 变好」可能是「字被擦掉」的伪装；
4. 验收必须含 **OCR 与 E-G**，不能只看拓扑。

## 本实验的设计边界（依然适用）

1. 这是 **latent inversion，不是训练**。即使 B 有效也不能直接推及训练。
2. `soft_clDice` 是**简化实现**（soft erosion 迭代近似中线），非标准 clDice。
3. **n=40（20+20）、150 步**，只够看方向性，不够给效果量级 ——
   本轮恰恰证明「方向性」也会被 bug 伪造。
