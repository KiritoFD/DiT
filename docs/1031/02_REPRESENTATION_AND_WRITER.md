# 条件表示：STD、Writer-ID、局部特征与风格保真

> 问题：书家的稳定风格信息存在哪里？为什么有些注入方式提高 Writer 判别，却不能同时提高字符内容与画质？本页只使用严格留字表征诊断、S 组匹配消融和独立 E-G 评测，不混入同名但不同结构的 P75。

## 1. 现实条件：字符差异远大于同书家的可识别残差

[10月25日 DINO 结构诊断](../../ANALYSIS/style_structure_diagnosis_20261025.md) 在10书家、1,609共享字、17,569张图上开展；其 105字×6书家的平衡子集采用 DINOv2-B CLS 特征分解：

| 特征分量 | 特征平方能量 | 解释 |
|---|---:|---|
| 字符主效应 | **93.9%** | 字符几何决定通用特征的大部分变化 |
| Writer 全局均值 | **0.5%** | 共享书家偏移在这个特征空间很弱 |
| Writer×字残差 | **5.6%** | 逐字写法有差异，但不一定能用 STD 几何类别预测 |

这些百分比是**DINO CLS 的 ANOVA 分解**，不属于 RGB 图的能量守恒或生成 latent 的固定比率。

严格留字 Writer 识别：DINO CLS + 线性探针 **43.6%**（10类随机10%），再加入局部 patch **45.5%**。K-shot Writer 均值原型 K1 **12.6%**、K8 **18.1%**、K32 **24.0%**，全量 logistic **42.6%**。原型重复8字集间余弦 **.973** 说明方向较稳，**不说明小K判别就足够**。

判别谱报告 `d_eff95≈7`，指该十类别线性判别分数的有效方向数；不是“书家风格本质只有七维”。原实验 Writer×STD 双线性 K=2..16 留字 `ΔR²=3.2e−8`、字形类条件化负/零增益，说明**当前输入/预测器没有学到有泛化价值的字形类别交互**；不能据此证明书家真实写法不存在与具体字相关的选择。

## 2. 两种不同但互补的风格观测

| 网络 / 数据 | 目标 | 实际结果 | 不该得出的结论 |
|---|---|---|---|
| DINOv2-B 特征，严格留字 | 10类Writer线性识别 | Top1 43.6%；局部特征45.5% | “只有43% Writer信息”的自然上限 |
| **E-G** 冻结ResNet18，1008真迹跨字查询 | Writer正负对AUC | **95.98%**，EER **7.44%**，mAP **93.09%** | “95.98%十分类正确” |
| E-G 20维墨量/宽度/布局低阶探针 | 是否简单捷径 | AUC **49.35%** | 排除所有复杂扫描/作品来源捷径 |
| E-G 去低阶线性可解释残差 | 剩余Writer信息 | AUC **93.11%** | E-G 就是完整、无偏的书风审美真值 |
| HWD官方特征，真迹 | 跨字Writer AUC | 约 **51–54%** | HWD是可靠独立Writer复核器 |
| CHAED标签+HWD-Ridge | 字符留出审美回归 | MAE **17.97** vs均值 **18.32**，PCC **.071** | 已完成正式 CHAED/TabNet 或可排生成画质名次 |

后两项阴性只否定**本次特征/校准方案**。来源：[eval_style_v2](../1030/eval_style_v2/FINAL_REPORT.md)、[HWD](../1029/hwd/REPORT.md)、[CHAED](../1029/chaed/REPORT.md)。

## 3. S 组最稳妥的解释：不是更多空间参数，而是表征×注入的交互

S 的结构定义以 [`docs/1028`](../1028/CONCLUSION_AND_NEXT_PHASE_20261028.md) `3 的训练合同为准：

- **S0**：Writer Vector + Global AdaGN。SSIM **.6027** / LPIPS **.3395**，图像保真强，但旧 E-G AUC **82.13**。
- **S1**：与 S0 只改 Spatial AdaGN；SSIM **.5866**（−.0162，有配对CI），宽度比 **1.234**；说明空间自由度本身可能使输出偏粗、粘连。
- **S4**：LocalCNN Writer 表征 + Spatial AdaGN；Ink-IoU **.2951**、宽度/结构较 S1 改善，旧 E-G AUC **84.91**。
- **S5**：Local Attention Writer 表征 + Cross-Attention；旧 E-G **87.98**、新 v2 协议 **89.99**，但 SSIM **.5975**、LPIPS **.3425**，并非内容/画质都第一。

按 S 的98共字、Writer宏AUC配对：S5−S0 **+5.73pp [1.65,9.84]**，S5−S4 **+2.92pp [−.33,6.22]**。后者跨0，应保留 S4 作为**局部 CNN 的等预算对照**。旧 v2报告里部分文字误把 S5 称“Stroke×Spatial AdaGN”，与 1028 真实矩阵映射不一致；**以实际 checkpoint resolved config 为最终身份**。

逐字 S5−S0 的4分格（98共字）：32风格↑且SSIM不退、18风格↑而SSIM降、33风格↓且SSIM不退、15两者都退。**18/98 并非 OCR 已证明写错字的比例**；该格子以单GT SSIM 为内容代理，受合法异形惩罚影响。对于未见字，效果更分化：来源报告给出未见字 A/B/C/D 12/14/14/10，但其 seen/unseen 定义尚和 P75 的另一份统计冲突，必须先复核名单。

## 4. Why Writer-ID 当前更合理，reference-image 何时再考虑

我们现在研究的是**10位已知目标书家**，训练时有大量不同字的真迹，并非零样本新书家生成。可训练 Writer-ID 在训练时跨大量字符整合信息；取另2张参考书法图做临时条件，容易把“参考字的具体结构”误当作“目标字的Writer残差”。

已有 Qwen/LoRA 的**两张同书家异字参考注入是负收益**，不足以一般性否定未来的大K、可训练参考聚合。DINO 均值原型 K32仍不饱和，并且Writer×字残差有实际存在；对固定Writer数据，**先训练Writer-ID，后研究新Writer泛化**更省计算且消融干净。

**关键解释修正**：Writer×字残差 5.6%≠“可预测的 Writer×STD 几何条件”。王羲之逐字草化选择可能是词汇/语义式历史习惯，并非仅由标准字的局部骨架决定。盲目用字形分组做动态Writer调制可能增加难以泛化的参数。

## 5. 下一步的三个因果诊断（先测后训）

### E-W1：固定同一个 latent，测试正确/错误/null Writer（GPU前向，无重生成）

针对 S0/S4/S5 现成 EMA，沿真实GT latent生成 `z_t=(1−t)z_0+tε`。在**完全相同的 `z_t`、STD、Script、t、ε** 下只替换 Writer ID，计算：
- `ΔL_wrong(t) = L_FM(w_wrong)-L_FM(w_true)`；
- `ΔL_null(t) = L_FM(w_null)-L_FM(w_true)`；
- `A(t)=‖v(z_t;w_true)-v(z_t;w_wrong)‖` 及与 `z_b-z_a` 的方向关系（方向比较仅限同char/script且有真实Writer a,b配对时）。

选用现有 [容量审计](../../exp.md) 里的 **t=.10/.25/.40/.60/.80/.95**；每个 t 同噪声多seed。数据先按Writer×书体×字符可比性配平、书体内置换Writer，必要时按不同来源作品做额外分层。**不允许更换 z_t** 后声称是 Writer 的单变量因果差。

预测：如果 S5 的 E-G 优势来自真正的 Writer 条件使用，它在部分中间 t 的 `ΔL_wrong` 应当较 S0 更大、且在同噪声 Writer-swap 中有正确书家方向；若只有输出图 E-G 更高、正确/错误条件 risk 未差或方向错，则怀疑统计捷径或末端视觉匹配。

### E-W2：同字、同噪声完整 Writer-swap（必须真实采样）

固定 `(char, STD, Script, ε)`，分别指定至少两位 Writer；选覆盖多个Writer的共字，产出：
1. OCR 对两个输出都识别为原字符的比例（Content Stability）；
2. E-G 真迹差异方向余弦；
3. E-G 生成差异与真迹幅度比；
4. 错Writer/随机Writer条件的负控制；未见字独立报。

已有 J组的关系几何方向约 **.85**、幅度约 **.66–.75**（该组面板，非通用常数）。S组 val100 slot较稀疏，RDM部分置换后不坍缩，因此**没有共字swap就不能宣称改善全Writer关系几何**。[关系诊断](../1030/eval_style_v2/FINAL_REPORT.md)。

### E-W3：减少网络复杂度前先审计“是不是学到了 Writer”

- 记录 Writer token 在各层的非零范数、梯度占比；检查 null 对照是否静默短路。
- 核对 `num_writers` / Writer remap / 样本 dropout 与训练日志。
- 比较 S4/S5 上层/中层/下层的条件置零响应（相同 t、同样本），看损失和swap的变化。
- 若局部注入只提高训练 Writer AUC 却使未见字 OCR 下降，再设计内容稳定性的正则或训练时序，而**不是继续加 Writer×Glyph 模块**。

**特别的身份审计**：[`1030p125.md`](../../1030p125.md) 记载 P125 方案称“S5 LocalAttention+XAttn”，实际一处 spec 使用 `R2(LocalCNN)×I2(CrossAttn)`，另一处提到 `I3`；不能将此P75直接当 S5 结构迁移。下一步从 **checkpoint内配置和实际模型权重**恢复身份，不以任务命名推断模型结构。
