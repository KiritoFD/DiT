## 一、摘要：目前可以确认什么

1. **书法生成不是单 GT 的像素重建**，至少需要分别评价字符可读性、书家身份、墨迹/结构质量和未见字泛化。仅用 SSIM/LPIPS 会错把可识别性退化、背景匹配或风格错误当作好结果。（强证据）
2. **标准字形的空间条件是开集接口，而不是开集成绩保证。** 闭集字表能取得更高的配对指标，但在词表外没有可用字符嵌入；STD-only 能接收新字，却仍存在真实未见字的内容失败。（强证据）
3. **结构信息的合理位置更可能是条件侧，而非额外生成目标。** 12ch 等权辅助目标在当前实现中出现梯度竞争；同预算 MoYi 4ch 不逊于12ch。但不能宣布 12ch 在所有模型中无用。（较强证据）
4. **复杂 Writer 注入没有普适收益。** S0 简单 Writer Vector+Global AdaGN 是内容强基线；局部 Writer 表征的 S4/S5 在 E-G 身份维度有收益，且有明显的逐字/逐书家异质性，S5 对 S4 仍未稳健胜出。（较强证据）
5. **VAE/Decoder 是真实的图像质量杠杆，但不是风格建模的全部。** J2/J3 相对 J0 的 SSIM/LPIPS 改善是同起点对照；OCR/独立 Writer 没有同步证明改善。（较强证据）
6. **P75 预训练的正迁移仍未证实。** P75 实际 P0=50k，不是125k；Top10 有条件曝光约19.1k Batch 等效步。新审计发现旧 P75 Style LR 两组实际是 `1e-4`、不等于 spec。（强事实约束）
7. **后训练值得继续，但不得先归因。** 4090 上 A 延长首个 +5k 节点的 val100 SSIM `0.5857→0.5914`，同时有新 LR 与 cosine restart；B/C 未完成。（阶段性判断）

### 证据等级

- **A（直接）**：同起点、同数据、同协议的对照，或 bug/梯度/模型装载的直接测量。
- **B（观察）**：可信数值但包含多变量、训练预算不齐、单 seed、小样本或跨协议。
- **C（假说）**：从数学或特征诊断推导的机制，仍待反事实实验。
- **X（阴性）**：当前实现/预算下未晋级，不代表该技术一般无效。

## 二、实验任务和协议：哪些分数能够比较

模型输入目标字的标准字形 `g`、书体 `s`、书家 ID `w`，输出单字书法图像。目标是学到 `p(x\mid g,s,w)`，不是逐像素复刻唯一 GT；同书家同字允许不同合法写法。完整数学定义见 [math](../math/README.md)。

| 协议 | 样本 / 实现 | 最大陷阱 |
|---|---|---|
| **Moyi legacy Strict** | [106moyi](../106moyi/README.md) | 与统一187的 SSIM、LPIPS 不能直接混 |
| **107 的统一187** | 187张、ODE、CFG1、DiT Heun50、LPIPS-Alex | 对比 Moyi Euler50 时 **100 NFE vs 50 NFE**；同时仅 **112/187 组合未见** |
| **旧 in-memory eval187** | [108 ledger](../108/03_metrics_ledger.md)，CFG1、ODE | 不能当成 SDE/CFG0.8 或另一 SSIM 实现 |
| **S-val100** | S0–S8 与 P75，名为 heldout 的旧目录也可能是 val100 | 100样本混合 seen/unseen；Writer 有效 query 约98 |
| **J / S@85k heldout187** | 原187与新187、3个噪声 seed 需明确 | 同名面板有繁简异体和样本顺序差异，须用 `eval_stdskel_batch.csv` 配对 |
| **E-G / OCR** | 冻结 Writer 验证与读光单字识别 | AUC≠分类Top1；OCR 词表覆盖、GT识别正确率、有效N 必报 |

经验同条件真迹对的平均 SSIM **0.6503**（另一均匀抽对口径 **0.6235**）是重复书写相似度参考，**不是生成图 SSIM 的硬上界**。[107 勘误](../107/03_evidence_grade_and_errata.md)。

## 三、跨时代实验脉络：正负结果和原因

| 历史线 | 代表节点/结果 | 取得的知识与限制 | 评级 |
|---|---|---|---|
| v1–v9，DDPM+char表 | 常见字 seen 可拟合，OOV 无有效 ID | 字表记忆≠开放词表；早期生成与评估均不成熟 | B |
| v10b STD骨架 | 390k 历史Strict约0.5058 | 连续空间字形接口能生成新字，但 seen–strict 差距大 | B |
| v11/v12/13，FM、清洗、4ch | v13旧Strict约0.5713 | 数据极性、条件路由和训练动力学都重要；多变量迭代不做单项归因 | B |
| **MoYi 12ch vs 4ch** | 同50k旧Strict：12ch SSIM **0.5935**/LPIPS **0.3724**；4ch **0.5949/0.3678**；4ch80k **0.6085/0.3489** | 同步数4ch基本打平/略胜；80k胜出同时多训30k，不能叫单变量的大幅提升 | A/B |
| v14，Writer×Script细分 | 87个组合槽 | 书体/书家稀疏，直接离散组合加重长尾 | B |
| v21/v23，SkelNet | Joint LN 条件方差比曾约38×；Split LN改幅；两阶段形变未晋级 | 条件尺度、级联误差真实存在；不等于所有可学习形变有害 | A/B |
| v54/v66/v68，三表+路由/增强/C2OT | v68 统一187 **0.6169**（Sp/2 59.1M）；v66 **0.5976**；MoYi4ch80k **0.5986**、12ch50k **0.5764** | 闭集高配对 SSIM；v68 对 MoYi NFE 不等，C2OT/增广/路由独立贡献未实证 | B |
| DiT 容量阶梯 | B/2 aug40k旧Strict **0.6039**/LPIPS **0.3292** | 更大容量+其他训练变化有收益，但不能得出简单参数规律 | B |
| v70，纯 std-skel回迁 | 65k in-mem SSIM **0.5535**、后期平台 | 此一骨架条件配方不理想，不否定后续 STD-soft 路线 | A/B |
| v71–v80，Calli-VAE/采样 | v72@50k in-mem **0.5999** vs v68同50k **0.5701**；@65k **0.6034 vs 0.5833** | VAE/数据合同改变可大幅改善早期收敛；noaug/VAE 同时变化不能归因 VAE 单项 | B |
| v81–v84，开集STD-soft | v83-A@90k SSIM **0.6055**/Ink-IoU **0.2990**；训练未见字符13张 IoU **0.1586** | std-soft 信号有效，但 v83-A 同时有 char table；v84才是纯STD；未见字样本和作品来源混杂 | A/B |
| v85–v89，Writer监督 | v89训练 CE **99.77%**，严格留字符 **30.07%**，留来源 **13.64%** | Writer 分类器自身极易过拟合/依赖来源；不能只看训练教师分数 | A |
| U-Net/DiC/Deep-Sym4 | Deep85 是J训练起点；114M未自然克服内容/风格平台 | 模型尺寸不能替代有效条件、训练数据和识别验收 | B |

| J0–J7，Decoder | J2/J3图像质量提升；J5–J7额外条件几乎不区分 | Decoder能改外观细节，未证明能独立修复结字与书家身份 | A/B |
