# A/C/B 收敛对照：纯重建（A）已经足够，拓扑项无独立贡献

**日期：** 2026-11-02  
**脚本：** `tools/d_20261101/abc_invert.py`  
**数据：** `assets/d_20261101/p1abc/abc.json`（20 worst + 20 random，同样本同初始化同优化器，相对收敛判据）  
**回答的问题：** 逐项拆开 —— 收益来自普通重建、墨量校正、还是拓扑项？

## 结论

**A（纯 L1+LPIPS+latent 正则）已经拿到几乎全部收益；
墨量校正（C）主动有害；拓扑项（B）相对 A 无可测的独立贡献。**

| 组 | 变体 | frag | **墨量保留** | excess | round-trip |
|---|---|---|---|---|---|
| worst20 | **A** 纯重建 | 9.088 → **1.688** | **0.999** | 0.55 | 0.0061 |
| worst20 | C +墨量 | 9.088 → 6.286 | 0.847 | 0.90 | 0.0084 |
| worst20 | **B** +clDice | 9.088 → **1.612** | 0.941 | 0.30 | 0.0209 |
| random20 | **A** | 1.090 → **1.199** | **0.998** | 0.05 | 0.0061 |
| random20 | C | 1.090 → **3.405** | 0.808 | 0.75 | 0.0081 |
| random20 | B | 1.090 → 1.344 | 0.945 | 0.15 | 0.0182 |

逐字配对（这是唯一能判断「独立贡献」的比较）：

| 比较 | worst20 | random20 |
|---|---|---|
| **B vs A**（拓扑的独立价值）| −0.076 ± 1.359，11/20 | +0.144 ± 1.141，11/20 |
| B vs C | −4.674 ± 4.912，17/20 | −2.062 ± 3.511，19/20 |
| C vs A | +4.599 ± 4.569，**C 仅胜 2/20** | +2.206 ± 2.993，**C 仅胜 2/20** |

## 三个要点

1. **A 就足够了。** 纯重建把 worst20 从 9.088 降到 **1.688**，
   而且**墨量保留 0.999**（几乎无损）、**round-trip 仅 0.0061**（最稳定）。
   这正是用户先前的判断：「A 若能修复大量断笔，就不必急着引入复杂结构损失。」**成立。**

2. **B vs A 是噪声**（−0.076 ± 1.359、11/20）。
   → **拓扑项相对纯重建没有可测的独立贡献。** 这修正了本文档早先「B 有巨大优势」的说法
   （那个数字是极性 bug 造成的，见 P05 的自我更正）。

3. **墨量校正（C）有害，且有害机制已被墨量保留率直接测到。**
   C 把墨量保留率压到 **0.847 / 0.808**，同时 frag 在随机字上从 1.090 **恶化到 3.405**、
   `component_excess` 升到 0.75。**它靠削墨来「改善」块数，结果既没修好也丢了笔画。**
   这验证了旧 SkelNet 的教训「提高墨迹召回 / 墨量约束可能造成过墨或欠墨」。

4. **B 的 round-trip 是 A 的 3.4 倍**（0.0209 vs 0.0061），墨量保留也低于 A（0.941 vs 0.999）。
   → clDice 换来的那点 frag 改善，代价是**更偏离正常 latent 流形**且**丢掉 6% 墨量**。
   即便 frag 数字好看，这个交换也不划算。

## 对 P1 的意义（结论明确）

- **λ 应基于纯 L1 + LPIPS 的图像损失，不要加墨量约束，不要加 clDice。**
  这与 P1 已实现的 \`simple_image=True\`（纯 L1）方向一致。
- **A 的墨量保留 0.999、round-trip 0.0061** 说明「纯重建」是一条**不破坏既有字**的路，
  这正是 P1 需要的性质 —— 用户提醒的「random20 恶化到 1.567 是否以牺牲正常字为代价」，
  在本轮 A 上**没有发生**（random20 仅 1.090→1.199，墨量 0.998）。
  ⚠️ 早先报的 random20 1.090→1.567 也来自极性 bug，**该数字作废**。

## ⚠️ 边界

1. 仍是 **latent inversion，不是训练**。A 有效 ≠ U-Net 学得会。
   这是 P1 要回答的，必须实跑。
2. **n=40（20+20）**，逐字标准差 1.1–1.4。B vs A 的 −0.076 远在噪声内；
   但 **C vs A 的 +4.6 且 C 仅胜 2/20** 是明确信号，不是噪声。
3. **未评 OCR 与 E-G**（需 OCR 栈，另跑）。tail 上「frag 变好」不等于书写质量变好。
4. 收敛判据是**相对改进 < 1e-4**，各臂实际步数 464–517，未跑满 600，
   即三臂在可比的收敛点上停止。
