# Muon 优化器试验记录（09-04/09-05，判定失败）

## 背景
为基模预训练测试 Muon（矩阵 NS 正交化 + AdamW 混合）替代 AdamW，
预期 LLM 上的 1.3-1.5× 样本效率收益。

## 实现
- `src/optim/muon.py`：SVD 极分解正交化（默认，精确 ~1e-7）或 NS5 迭代
- train.py 加 `--optimizer muon` / `--muon-lr`（矩阵组独立 lr，向量/embedding 组 AdamW）
- 冒烟 config：batch64, flow, OT, 同 v8a 配方仅换优化器

## 结果（同 config 同 batch 仅优化器不同）

### 2000 步冒烟
| step | Muon (lr=0.02) | AdamW (lr=3e-4) |
|---|---|---|
| 200 | 1.363 | **0.647** |
| 1000 | 0.505 | **0.450** |
| 2000 | 0.436 | **0.404** |

### 5000 步
| 段 | Muon (lr=0.02) | AdamW (lr=3e-4) |
|---|---|---|
| 首步 | 19,241,244（爆炸）| 1.108 |
| 3000-4000 | 0.4176 | **0.3946** |
| 4000-5000 | 0.4042 | **0.3849** |
| 5000 步末 | 0.3944 | **0.3759** |

## 判定
- **收敛正常、零 NaN**（可行性 OK）
- **但同等步数下收敛始终慢于 AdamW**（5k 尾段 +5% loss，2k +8.7%）
- 首步数值爆炸（1924 万）暴露 NS 正交化冷启动不稳
- Muon 理论优势（更长训练后期稳）在 5k 内未体现；预训练成本高（1134 epochs），看不到优势不值得赌
- **结论：Muon 不优于 AdamW，弃用**（代码保留存档）

## 教训
- DigT 扩散模型上 Muon 无先例；LLM 上的收益不迁移
- 小规模冒烟（2k/5k 步 batch64）足以否决；不必全量预训练验证
