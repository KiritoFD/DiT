# VAE 与相关改动技术附录

证据截止：2026 年 10 月 13 日 13:42，上海时间。覆盖近期 V68 到 V84 的 VAE、潜码合同、条件表示、SDE、REPA、增广和评测工程改动。远端数据只读核对，不启动采样，不启停训练，不修改现有运行。

## 结论

这轮最扎实的进展是两件事：**物理配方 VAE 的重建质量确实改善了；训练和评测之间的合同正在被补齐。** 两者应分开记账。VAE 的重建收益没有等幅转化成 DiT 生成收益；部分曾被解释为“模型白化”“SDE 不工作”的现象，实际混入了缺条件、解码元数据或采样器版本问题。

当前建议保留 V80 的物理 VAE 路线作为质量基线；V83-A 作为已能稳定生成的 hybrid 条件路线；V84-A 用于回答去掉字表后还剩多少能力。不能把 V83-A 的成绩直接记作 std-soft 单独的成绩，更不能宣布开集问题已解决。

主要判断如下。

1. **VAE 重建改善成立。** 同批 187 张验收，旧 DINO 配方到物理配方：PSNR 30.56→34.04 dB，SSIM 0.9852→0.9949，顶带份额比 0.783→0.901，记录的重建 LPIPS 0.1281→0.0135。GAN 的独立贡献尚未证明。
2. **V80 已完成 200k，190k 是选定代表点。** 同 PNG、同 LPIPS-alex 口径，相比 V68 ODE，SSIM 接近，LPIPS 和 Ink IoU 更好；但这是多项变化后的结果对照，不是单独换 VAE 的因果效应。
3. **V83-A 的整体白化判断应撤回。** 55k 修复评测后近白图 33/187→1/187；后续有效评测已到 105k，近白为 2/187。仍有失败样本，但不是整条模型路线塌白。
4. **纯 std 路线还没有无代价替代字表。** 同为 70k、batch288，V84-A 比 V83-A 的 SSIM 低 0.04285、LPIPS-vgg 高 0.03597、Ink IoU 低 0.04214。它没有整体白化，而是字形和感知质量仍落后。
5. **SDE 不宜作为统一默认增强。** V80 65k 的预留验证没有支持额外 SDE 收益；已经验证的推理收益主要来自 CFG 1.5，而非加噪声。该配方不能直接外推到 190k。
6. **REPA 消融结论需要降级。** 原 A0 海报的统计标签有误；A0 与历史 V68 的采样器版本也存在重要疑点。现有小差值不能证明“REPA 无用”或“显著有用”。

## 2 VAE 路线的变化与有效成果

### 2.1 从语义重建转向像素与纹理重建

早期 Calli-VAE 用 L1、极小 KL、DINO struct/style，没有 LPIPS 和判别器。它的像素往返分数比 SD 好，但高频保留较差，且后验明显更宽。之后尝试 DoG 和直接 topband；训练高频指标曾与离线定义不一致，早期“高频已恢复”的判断不能保留。

物理配方从干净 SD-VAE 初始化，使用 L1 + LPIPS-VGG + Laplacian 边缘 + topband + 极小 KL，并配置局部 PatchGAN；不加载 DINO。架构仍是 4 通道、8 倍下采样。**对本项目，它是当前更有证据支持的重建基线；不能上升成“任何 VAE 都不能使用语义特征”的普遍定理。**

### 2.2 往返验收

| 指标，N187 | 旧 DINO 配方 | 物理配方 | 变化 |
|---|---:|---:|---:|
| L1 ↓ | 0.01085 | 0.00756 | −30.3% |
| PSNR ↑ | 30.56 dB | 34.04 dB | +3.48 dB |
| SSIM ↑ | 0.9852 | 0.9949 | +0.0097 |
| 顶带份额 / GT ↑ | 0.783 | 0.901 | +0.118 |
| 重建 LPIPS ↓ | 0.1281 | 0.0135 | −89.5% |
| 墨量 / GT | 1.001 | 1.000 | 总墨量稳定 |
| 后验相对宽度 | 0.3914 | 0.2769 | 变窄，但非近确定性后验 |

这些数值来自远端 [acceptance 原始快照](recent_vae_20261013/vae_acceptance.json)。该 JSON 没有明确写 LPIPS backbone；配方文档记作 VGG。重建 LPIPS 不拿来与生成 LPIPS 直接比较，后续验收制品应补上完整实现身份。

SD 的既有参照为 PSNR 26.80、SSIM 0.9738、顶带份额比 0.816。物理 VAE 的高频仍不是无损：径向谱最高一带的重建/GT 能量比约 0.800。这个**能量比**与表中的**顶带份额比**不是同一个量，不能混成矛盾读数。

两条归因限制必须保留。第一，配方同时换了初始化、多个 loss 和训练过程，不能把全部收益分给“去 DINO”一项。第二，日志记录自适应 GAN 权重很小，缺少匹配的无 GAN 消融；“GAN 配置存在”不等于“GAN 已证明有效”。

早期验收阈值 L1≤0.005 连既有基线也没有满足，物理 VAE 的 0.00756 也不满足。因此不能写“所有验收项全过”；阈值需要按用途重新标定并单独记录，不能临时移动门槛。

### 2.3 重建天花板与生成能力仍有距离

历史观察中，V72 的 HF/GT 约 0.622，对应 VAE 往返 0.783；V76 约 0.629，对应往返 0.828。这些比例说明压缩器改善不自动变成生成改善，但不同 step、采样和高频定义不得混用来算单变量收益。

V79 相对修正尺度后的 V78，匹配 5k–45k 曲线记录平均 LPIPS-vgg 改善约 0.0543、SSIM 改善约 0.0048，支持继续保留物理 VAE 路线。不过 VAE 制品、标定常数和部分训练设置一起变化，这仍是路线级证据，不能精确拆分到某个 loss。

### 2.4 尚未转化为主线收益的相关尝试

| 尝试 | 已有证据 | 当前定位 |
|---|---|---|
| V74，sample 目标改为 mode | 既有匹配记录的 23 个评测点均落后，SSIM 约 −0.008、LPIPS 约 +0.032 | 不支持“去掉后验噪声就能恢复生成或 SDE 收益”；不排除所有后验几何影响 |

## 3 潜码合同修复比换一个缩放常数更重要

统一合同是：

```text
z_raw    = posterior.sample() 或明确登记的 mode()
z_stored = (z_raw - shift) * sf
x_rec    = decode(z_stored / sf + shift)
```

每个 VAE/编码制品分别标定；不能继续抄 SD 的 sf=0.18215。旧 Calli 的 raw std 约 1.1，却被再乘 0.18215，存盘 std 只有约 0.20。V78 修正 scale/shift；物理 VAE 的生产 shards 用 512 张标定得到：

```text
raw_std = 1.1848665229478177
shift   = -0.03341800242750449
sf      = 0.8439769211405432
encode_mode = sample
```

这不同于 187 张往返验收给出的 sf_fit=0.829769、mean=−0.02539，原因是标定样本不同。**运行应服从实际 shards 的 provenance，而不是从重建表另抄一个常数。** 本次快照同时保存了生产 provenance。

近期已查明并修复的合同问题：

| 问题 | 后果 | 正确处理 |
|---|---|---|
| 沿用 SD sf | 改变数据端幅度与路径 SNR | 编码时实测标定；冻结 sf/shift |
| V80 的 CLI 未注册 shift | shard 正确，但 checkpoint 缺元数据、解码漏加回 | 旧 checkpoint 按 provenance 补解码，不冒充训练 x0 错误 |
| VAE 缓存只按 device | 同进程换 VAE 仍拿旧 decoder | 缓存键含制品路径与行为参数 |
| 对共享 decoder 就地打 shift 补丁 | 多次取用时污染旧对象 | 非侵入包装；包装 `.eval()` 不能返回裸 base 丢失 shift |
| 把旧 `calli_decode_noise` 搬到新 VAE | 注入不匹配的后验噪声 | 绑定具体 VAE 和后验测量，不能通用复用 |
| 16ch 仍硬切图像前 4ch | latent/decoder 接口失配 | 图像通道由合同明确给出 |

V80 65k 的实际解码审计表明，补 shift 的 SSIM 变化只有约 −0.000023，LPIPS-alex 约 +0.000068。它是必要的合同修复，**不是涨点，也不是 SDE 收益不足的主解释**。

### 三个需要修正的旧数学表述

**单位尺度是工程标定，不是 flow matching 的成立条件。** 数据端不必是高斯，也不必严格单位方差；单个全局 sf/shift 更不等于逐维白化。它改变优化尺度、SNR 和辅助项的有效强度，但不使合法的独立高斯插值公式失效。

**“std 小 5 倍，所以整个 FM loss 小 25–28 倍”不成立。** 独立配对、噪声零均值时，目标为 `epsilon-x0`，每维目标二阶矩是 `1+E[x0²]`，包含未缩小的噪声项。数据分量及某些误差可以受平方尺度影响，但不能由此直接推导整个训练 loss 或 REPA 比重必然乘 28；应量实际 loss 和梯度。

**KL 不是对全局尺度不敏感。** 标准高斯 KL 显式含 μ² 和 σ²；极小 KL 权重可能不足以约束尺度漂移，但不是数学上完全不约束。换尺度后也应实测梯度裁剪发生率，不把 clip 必须按比例放大当普遍定律。

本轮采用新 VAE→重编码→DiT 从头训练，以隔离数据制品变化。warm-start 可以作为单独迁移方案研究，但不能混入“只换 VAE”的干净对照。

接口详情见 [latent 合同](../vae_latent_contract.md)、[VAE 配方与验收](../vae_training_recipe.md)。其中较早的绝对化解释以上述限定为准。

### 4.2 数学修复与实测结果分开

在线性路径 `x_t=(1-t)x0+t epsilon`、`epsilon` 与 `x0` 条件独立时，score 为：

```text
s(x,t) = -[x + (1-t)v(x,t)] / t
corrected drift，按代码 t:1→0：
b = v + gamma²(1-t)[x + (1-t)v]
noise variance rate = 2 gamma² t(1-t)
```

旧式只做 `v*(1+gamma²*t)`，缺少状态项，不保持这条精确边缘分布。C2OT 改变训练数据与噪声的联合配对，即便噪声边缘仍是高斯，这个 score 推导也不再有保证。推理时关 OT 不能把旧 checkpoint 改造成独立配对训练。

因此，V68 的旧采样工程收益真实存在，但不能要求 V80 的 corrected SDE 必须复制它。精确场同边缘也不代表近似模型上不能通过 sampler 获益；只是没有必然收益保证。

V80 50k 三条 SDE 路径曾观察到 frag 小幅下降：均值 −0.07197，样本 bootstrap 区间约 [−0.14787,−0.00219]；SSIM +0.000576 的区间跨零。这是固定噪声与三个路径 seed 下的探索性结果，不是全面 free lunch。

更严格的 65k 调参使用 80 张选参、107 张预留、三个 seed、同 100 NFE。预留集上：

| 干预 | ΔSSIM | ΔLPIPS-alex | ΔLPIPS-vgg | ΔInk IoU |
|---|---:|---:|---:|---:|
| ODE CFG1.5 − CFG1 | −0.000828 | −0.003896 | −0.002455 | +0.010620 |
| CFG1.5 下 SDE γ0.5 − ODE | −0.000022 | −0.000005 | −0.000119 | −0.000039 |

CFG 的感知和墨迹改善有配对证据，但墨量增大、SSIM 均值小降。SDE 的额外指标区间均跨零，中段时间窗也没在选参集胜出。**当前已验证的可选配方是 65k 的 CFG1.5 + ODE，不是默认 γ0.5。** 190k 尚无对应多 seed 验证。

来源：[65k 推理调参](2026-10-12-v80-65k-inference-tuning.md)、[SDE 数学与历史证据](2026-10-12-v68-v70-sde-role-and-free-lunch.md)。

## 5 std-soft 与字表的路线分离

### 5.1 实际实现与字体选择

std-soft 绕开图像 VAE：TTF 固定字号在 512 尺寸渲染→BOX 降采样到 64→Gaussian blur→独立 CNN 映射为 16×16 空间 token→加到图像 token。输入 ink=1、背景=0；训练 sigma 在 0.4–1.0，评测固定 0.65。当前没有先 skeletonize 再膨胀的处理，后者仍是独立设计选项，不是已经验证的收益。

实际首选字体：楷体 `simkai.ttf`、行体 `STXINGKA.TTF`、隶体 `SIMLI.TTF`；按字符 cmap 使用显式 fallback，记录在 index。方正王羲之行书是待实际授权制品通过覆盖审计后的候选，**不是当前已用字体**。8451 个字形键覆盖三书体，不等于覆盖任意 Unicode 字符。

条件编码改为 `F(g)-F(0)`，不 detach 零分支，消除零输入响应；随后把整批零输入编码改为单张编码后广播。后者是计算复用优化，不是新建模能力；速度收益需量真实完整 step，不能由少了一次批量 CNN 就宣布训练加速比例。

### 5.2 V83-A 的白化首先是评测错误

旧评测底层不支持 std-soft，空骨架路径返回 `g=None`；训练带 g，评测不带 g，且实际 γ=0.5 而注释声称 ODE。55k 在新目录恢复 g、使用 γ=0 后：

| 指标 | 旧无效评测 | 正确评测 |
|---|---:|---:|
| SSIM | 0.577117 | 0.577116 |
| LPIPS-vgg | 0.407139 | 0.355603 |
| Ink IoU | 0.093678 | 0.276847 |
| frag | 6.9234 | 2.5453 |
| 近白图 | 33/187 | 1/187 |

SSIM 几乎不变，正说明白底匹配可以掩盖严重缺笔。两项合同修复同时发生，不能把增量全部归给 g 或全部归给 γ。去零响应补丁是否独立解决了 V81 的长期退化，仍需要同协议对照；编码器偏置增长与白化的相关性不是完整因果证明。

有效续训数据在 90k 为 LPIPS 0.33372、Ink IoU 0.29902、墨量比 0.9605、近白 1/187；105k 为 0.33445、0.29462、0.9424、2/187。**到 105k 没有整体白化，90k 左右多指标较稳，但不能断言延长训练必无价值。** 95k 的 Ink IoU 0.299115 略高于 90k，90k 不是该单项的严格峰值。

来源：[评测修复记录](../../ANALYSIS/v83A_eval_contract_fix_20261012.md)、本次远端 JSON 快照。

### 5.3 V84-A 显示字表仍提供有用信息

当前代码正式支持三种内容模式，不再把 hybrid 视为不可声明的例外：

| 模式 | 内容条件 | 对应路线 | 意义 |
|---|---|---|---|
| table | 字符表 | V68、V80、V84-T 配置 | 闭集查表基线 |
| hybrid | 字符表 + std-soft | V83-A | 可用，但两个内容来源不能分离归因 |
| std | 仅 std-soft | V84-A | 移除字符查表依赖，为开集验证提供架构条件 |

V83/V84 保留书家、书体风格条件。V83 的 `freeze_triple_tables=True`：字表被冻结不代表不提供信息；旧报告“字表可训练”的措辞与 run 配置不一致。V84 移除字表内容通路同时改变条件融合参数形状，不能仅当作推理时把一行 embedding 置零。

同为 70k、batch288、20.16M 曝光、SD VAE、同数据、ODE、REPA0.03：

| 路线 | SSIM | LPIPS-vgg | Ink IoU | frag | 软墨量比 | 近白图 |
|---|---:|---:|---:|---:|---:|---:|
| V83-A hybrid | 0.59465 | 0.34301 | 0.28757 | 2.7748 | 1.0230 | 2/187 |
| V84-A std | 0.55180 | 0.37899 | 0.24543 | 2.3595 | 1.2026 | 1/187 |

纯 std 落后且偏过墨；较低 frag 不足以反证质量更好。这个匹配进度对照比“V84 70k 对 V83 105k”更合理，但仍是单次训练、涉及续训及源码版本差异，应作为初步路线证据，而非精确单参数因果估计。

既有 90k 分层审计还提示：38 张 seen、136 张 unseen-combination 的 Ink IoU 约 0.3157/0.3078；13 张 unseen-character 仅 0.1586，近白 1/13。样本少，且分层按所用训练 CSV 定义，不能把“字未在该语料中出现”直接等同于“模型没有任何相关表行信息”。69/187 张与训练同源作品的披露也必须保留。换 GT 不改输出的审计支持无直接 GT 输入，但不是所有泄漏路径都已被穷尽排除。

**std 模式使开集在结构上可行，不等于开集质量已经合格。** 字形换 g 的干预、换书家的干预说明模型使用了这些条件；少数干预样本仍不足以证明泛化能力。

来源：[旧 V83 审计](../v83A_std_soft_report.md)、[条件模式实现](../../src/model/conditioning.py)、[字体配置](../../configs/std_soft_fonts.json)。旧报告的“两模式互斥”“90k Ink IoU 峰值”“26k 训练语料”等过时或冲突表述，以本报告的代码和 run 快照为准。

## 6 REPA 与增广的结论重新分级

A0 相对 V68 配方去掉 REPA，5k–85k 的 17 个匹配评测点描述性平均差值为：

| 指标 | A0 − V68 | A0 更好点数 |
|---|---:|---:|
| SSIM | −0.000090 | 9/17 |
| LPIPS-vgg | +0.000377 | 8/17 |
| Ink IoU | −0.001169 | 5/17 |
| hole | +0.003387 | 5/17 |
| frag | +0.047068 | 6/17 |

这组差值较小，但不证明等效或零效应。原海报按“A0 更好”的单侧检验得到 p=0.975，却标成“A0 显著更差”；改成“更差”方向，5/17 对应 p≈0.0717，未达 0.05，且 17 个连续 checkpoint 不是独立训练重复。hole 也不是单调越小越好，GT 有真实孔洞。

更重要的是协议问题：A0 保存 γ=0.5 + C2OT；48 上当前 sampler 含 corrected drift，文件更新时间 10 月 12 日 13:50，早于 A0 的 15:11 启动；A0 启动源码 manifest 的 sha256 又为空。历史 V68 使用旧漂移。这是较强的版本不一致线索，**因此现有 A0/V68 曲线还不能认作已闭合的 REPA 单变量消融**。应先在同一 ODE 协议重评相应 checkpoint，再讨论效应。

本次只重新整理证据，没有重评生成。来源：[描述性差值及正确检验方向](recent_vae_20261013/repa_descriptive.json)、[A0 sampler 溯源](recent_vae_20261013/A0_sampler_provenance.json)。

A1 morphE 已完成 100k，A2 elastic 到 30k，都是 batch512、noOT、REPA0、SD VAE、ODE。A1 终点 LPIPS-vgg=0.33041、Ink IoU=0.33284；目前不能说 morphE 优于 elastic，也不能把它与 REPA-on 的旧增广臂横比后只归因于增广方式。A 系列与 V 系列保留独立命名，避免历史 V83 撞号。

## 7 相关工程改动与它们解决的问题

| 改动 | 解决的问题 | 证据边界 |
|---|---|---|
| strict checkpoint 重建与加载 | 配置漏字段、随机未加载层仍出分 | 形状检查之外，还需核对行为开关 |
| ContentConfig、ConditionBatch | table/std/hybrid 解释多处漂移、参数语义误传 | 字表/字形的模型逻辑仍需逐调用链验证 |
| 双轴 CFG 透传 S2 条件 | 委托遗漏 y_script、writer/pair 条件 | 不等于双轴 CFG 对当前 checkpoint 已有质量增益 |
| std 条件非空/形状/极性检查 | g=None、旧缓存和空字形被静默评分 | 真实 encoder 前向审计补充“检查过输入却没用”的盲区 |
| eval_id 与产物完整性检查 | 同 step 换模型/CFG/字体仍复用旧结果 | 身份须覆盖全部行为参数和制品；历史结果不会自动变可信 |
| GenerationSample 与离线评分层 | 生成身份与 GT/度量身份混在一起 | 新模块已提供分离接口，不代表全部历史脚本都已迁移 |
| ArtifactWriter | PNG、样本身份和 manifest 不对应 | 保存同源清单，再用显式 GT 配对评分 |
| 真实 src 源码 manifest | 旧 manifest 只哈希已迁走文件，最终为空 | 磁盘 HEAD 不能冒充活进程已导入的源码 |
| 指标不变量与测试收集修复 | 全白 SSIM 误导、测试其实未执行 | collected 数量不等于所有测试通过 |
| std 模式 OOV 映射 | 不依赖字表的路线仍被字符 remap 拦住 | table/hybrid 继续严格，不能静默用 null 冒充已知字 |

10 月 13 日提交记录包含前向黄金对照、严格加载、train/eval 路径检查，以及 CFG1 对 conditional forward 的误差检查。它们的价值是防止重构改变既有预测，不是新增涨点证据。本次报告没有重新运行这些模型检查，也没有据提交文案宣称整套测试全绿。

当前报告基于 HEAD `3a254e0` 和已有工作区；报告开始前 `inference.py`、`in_mem_eval.py`、std 测试等已存在未提交改动。它们保持原样。本次只新增报告和小型数据证据，未把当前磁盘版本冒充远端 V84 的启动版本。

## 8 下一步优先级

**先统一协议，再增加新变量。** 把 v68/A0 的选定 checkpoint 用相同 ODE、相同 VAE 合同、相同 PNG/float 度量重评，是恢复 REPA 归因资格的第一步；这属于后续实验，不在本次整理中执行。

**VAE 继续保留物理基线，但补完整验收身份。** 固定制品 hash、sample/mode、sf/shift、LPIPS backbone 与高频定义；若要分配配方贡献，做匹配的无 GAN 或逐 loss 消融，而不是继续用重建总涨幅代替单项结论。FLUX 16ch 的重建高频潜力可保留为探索方向，但尚不能替代本轮 4ch 下游基线。

**std 方向优先回答未见字，而非仅延长闭集训练。** 保留 hybrid/table/std 三路线；扩大表外字符和跨源作品评测，按字符覆盖、字体 fallback、书家、书体分层。比较 V84 后续时继续匹配曝光预算，关注 Ink IoU、LPIPS、墨量和字符正确性。OCR 评测器必须独立冻结并披露自身误差，不能把它的分类准确率当生成模型成绩。

**推理侧先使用已验证范围内的结论。** V80 65k 的 CFG1.5 + ODE 是已有多指标候选；190k 是否复现收益需要独立验证。SDE 保留研究价值，但当前不是通用默认，不用 V68 旧偏置采样的涨幅作为新模型必须兑现的额度。
