## 三、U-Net vs. DiT 深度架构对比与归因

在 15k/20k 阶段进行的严格配对 Bootstrap 分析揭示了 CNN U-Net 与 Vision Transformer (DiT) 在书法流匹配生成上的核心差异：

```
                +-------------------------------------------------------+
                |                书法字形流匹配生成特性对比               |
+---------------+-------------------------------------------------------+-------------------------------------------------------+
| 维度          | 72M CNN U-Net                                         | 38.8M ~ 74M DiT (ViT-Patch2)                         |
+---------------+-------------------------------------------------------+-------------------------------------------------------+
| 局部归纳偏置   | 强：多尺度卷积局部感受野与跨分辨率 Skip 直连              | 弱：Patch=2 切块，全局 Self-Attention 无局部先验       |
| 笔画连贯性     | 优秀：起笔、行笔、收笔自然呼应，薄笔画召回 +13.5%         | 较弱：易产生笔画粘连、短笔截断或中间断墨              |
| 文字骨架准确性 | 极高：几乎不出现结构性错字，牢固保持汉字间架               | 易漂移：在长笔画或复杂部首中易出现部件错位或异体构造   |
| 风格判别性     | 平滑平均化：对不同书家的个性笔意区分度不够鲜明            | 锐利：风格特征鲜明，书家区分度上限高                  |
| 显存利用效率   | 空间尺度随下采样缩小（32->16->8），显存占用仅 13~14G       | 序列长度固定（$256$ tokens），层数加深显存占用达 22G   |
+---------------+-------------------------------------------------------+-------------------------------------------------------+
```

**为什么 U-Net 字符结构如此扎实，而书家风格却偏向平滑平均？**
1. **全局条件的过早融合**：U100-Base 将时间 $t$、书家 $w$、字体 $s$ 一次性通过 MLP 压缩为一个全局单一向量 $c \in \mathbb{R}^{512}$，全网所有尺度均使用这一个向量进行 AdaGN 调制。
2. **缺乏通道增益调制**：标准 ResBlock 的残差分支直接加到恒等映射上（$y = x + \text{Conv}_2(h)$），条件向量只能影响 GroupNorm 的缩放平移，无法直接抑制或放大特定卷积通道的残差贡献。
3. **空间尺度与语义粒度错配**：书家的“出锋”、“飞白”等属于 32×32 高频细节，而“字形宽窄”、“结体俯仰”属于 8×8 宏观布局。单一条件强制所有尺度接受相同信号，导致网络退化为生成具有统计均值的折中风格。

## 四、DiC 架构升级：原理、实现与无损兼容

为了打破 U-Net 风格表达能力的瓶颈，我们深度实现了 CVPR 2025 论文《*DiC: Rethinking Conv3x3 Designs in Diffusion Models*》中的核心改进。

### 1. 条件残差门控（`residual_cond_gate`）
传统 ResBlock 在残差分支结束时缺乏依赖条件的动态增益控制。DiC 引入逐通道有界残差门控：
$$h = \text{SiLU}(\text{AdaGN}(h_1, c))$$
$$\text{residual} = \text{Conv}_2(h)$$
$$g(c) = 1.0 + 0.5 \tanh(\text{Linear}_{\text{zero}}(\text{SiLU}(c))) \in [0.5, 1.5]$$
$$y = \text{Shortcut}(x) + g(c) \odot \text{residual}$$

- **有界性设计**：通过 $1 + 0.5\tanh(\cdot)$ 将增益约束在 $[0.5, 1.5]$ 之间，杜绝了无界门控引发的训练梯度爆炸；
- **零初始化保护**：门控线性层的权重和偏置均初始化为 0，使得在步 0 时 $\tanh(0)=0 \implies g(c)=1.0$，模型输出与未开启门控时**完全逐位等价**。

### 2. 多尺度解耦条件路由（`stage_specific_cond`）
依据空间分辨率将网络划分为 3 个物理阶段（Stage 0: 32×32，Stage 1: 16×16，Stage 2: 8×8）：
- **Stage 0 (32×32)**：控制笔锋末端、飞白肌理、墨迹渗透等微观纹理；
- **Stage 1 (16×16)**：控制转折连笔、牵丝引带等中观笔势；
- **Stage 2 (8×8 & Middle)**：控制重心高低、结体欹正等宏观骨架。

支持两种注入模式：
1. **Adapter 模式（推荐）**：
   在共享条件基底 $c$ 上学习每阶段独立的轻量残差：
   $$c_i = c + \Delta_i(c), \quad \Delta_i = \text{Linear}_{\text{zero}}(\text{SiLU}(\text{Linear}(c)))$$
   同样零初始化，保证步 0 数值绝对等价。
2. **Independent 模式**：
   为每个 Stage 分配完全独立的时间/书家/字体投影矩阵，实现彻底的参数解耦。

> **CFG 掩码同步约束**：在训练中，Classifier-Free Guidance 的书家条件 dropout 掩码在所有尺度间严格同步，禁止出现浅层 drop 深层保留导致的信息穿越。

### 3. 全网激活函数升级（`act_fn = 'gelu'`）
将全网卷积与 ResBlock 内的激活函数由 SiLU（Swish-1）升级为 GELU（Gaussian Error Linear Unit）。GELU 的曲率在深层特征传递中展现出更优良的梯度流动性，与现代视觉生成模型（DiT / Stable Diffusion 3）保持一致标准。

### 4. 步 0 数值等价性验证（Unit Regression）
在 [tests/test_unet_dic_switches.py](../../tests/test_unet_dic_switches.py) 中进行了严格浮点回归检验：
- `residual_cond_gate` vs. Base：最大绝对误差为 **0.00000000e+00**；
- `stage_specific_cond (adapter)` vs. Base：最大绝对误差为 **0.00000000e+00**；
- 证明从 50k Checkpoint 热启时具备 100% 的数学平滑性，没有任何随机扰动冲击预训练知识。

## 五、计算复杂度与 MFU（Model FLOPs Utilization）权威剖析

### 1. 理论计算量推导（FLOPs per Sample）
通过对 `LatentUNet` 所有卷积、线性投影、GroupNorm 以及 SDPA 注意力层进行精确 Hook 探针统计：
- **模型参数量**：
  - 基础版 U100-Base：72,088,676 (72.09M)
  - 门控版 `DiC_residual_gate`：75,043,556 (75.04M, +2.95M)
  - 适配器版 `DiC_stage_cond_adapter`：72,876,644 (72.88M, +0.79M)
  - 全功能 DiC 版 `DiC_U100_b768`：75,831,524 (75.83M, +3.74M)
- **单样本前向 MACs**：
  - 2D 卷积算子：$11.026 \times 10^9$ MACs
  - 线性变换与 MLP：$0.038 \times 10^9$ MACs
  - SDPA 缩放点积注意力：$0.015 \times 10^9$ MACs
  - **前向合计**：$11.079 \times 10^9$ MACs $\implies \mathbf{FLOPs_{fwd} = 22.158 \text{ GFLOPs / sample}}$
- **单样本训练计算量（前向 + 反向）**：
  按照深度学习算力黄金法则（前向 1 次，反向计算激活值与参数梯度共 2 次）：
  $$\mathbf{FLOPs_{train} = 3 \times FLOPs_{fwd} = 66.473 \text{ GFLOPs / sample}}$$

### 3. 工程洞见：为什么 26%~28% MFU 在 CNN U-Net 中属于顶尖水准？
1. **避免访存带宽墙（Memory-Bound）**：
   不同于 Transformer 纯矩阵乘（GEMM 算力密集，MFU 易做高），CNN U-Net 包含大量的多尺度特征图变换、通道拼接（Skip Concat）、GroupNorm 归一化与逐元素残差相加，天然极易受限于 GPU 显存带宽。
2. **TorchInductor 全网 0-break 深度图融合**：
   在开启 `torch.compile(mode="default")` 后，AOT Autograd 将 GroupNorm + Activation + Bias + Residual 门控完整融合为单核 Triton Kernel，极大地消除了中间张量进出 DRAM 的延迟。
3. **Channels-Last 物理排布与全预加载内存设计**：
   数据输入全线对齐 NHWC 物理内存布局，完美契合 Tensor Core 的 8-channel 对齐计算特性；同时将 7.78 万张 Latent 预加载于 RAM Disk，完全消除了 DataLoader 的 I/O 气泡。
