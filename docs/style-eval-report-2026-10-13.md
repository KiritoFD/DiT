## 2. Style 轴：指标体系与协议

### 2.1 指标（全部**不需要逐字对应的 GT** ✓）

| 指标 | 含义 | 代码 |
|---|---|---|
| **CLIP-S / DINO-S** | 生成图 与 **风格参考图** 的平均余弦相似度（**标准指标** ✓，ViT-L/14）| `metrics.style_similarity` |
| 跨字符书家检索 mAP / Top-1 | 生成字能否从该书家**其他字**的真迹中检索出正确书家 | `metrics.cross_char_retrieval` |
| Style Prototype Margin | Δ = cos(q, μ_target) − max cos(q, μ_rival) | `metrics.prototype_margin` |
| HWD-CN | 生成集合均值 与 真实集合均值 的 L2 距离 | `metrics.hwd_cn` |
| Style-MMD | 多尺度 RBF **无偏** MMD²（比中心距离更能发现"风格单一化"）| `metrics.style_mmd` |
| XCTAcc | 跨字符三元组准确率：sim(同书家异字) > sim(异书家同字) | `metrics.xctacc` |
| **BSD（Brush-Statistics Distance）** | **非神经网络**的可解释笔法距离：笔画宽度/方向×宽度联合分布/墨色边缘/结体/弯曲度 | `brush.bsd` |

### 2.2 三条硬约束（内建为参数，默认全开 ✓）

1. `same_script`：只在**同书体**内比较（否则仅凭书体差异就能猜对书家）
2. `exclude_same_char`：Gallery 与 Query **字符必须不同**
3. `exclude_same_work`：Gallery 与 Query **作品（碑帖）尽量不同**

无法计算的槽位**显式跳过并计数**（每个指标都返回 `n_used / n_skipped`），绝不用别的书体/别的字顶替。

### 2.3 三条参照（缺一不可，否则分数不可解读）

| 参照 | 定义 | 作用 |
|---|---|---|
| **real_real_loo** | **留一法**：每张参考图 vs 该书家写过的**其他字** | 上限 |
| real_other_writer | 把 query 书家**故意错位** | 风格错配地板 |
| **ttf_only** | 直接用**标准字形渲染图**当"生成结果" | 渲染字体下限 |

> ⚠ **重要修正**：上限最初我写成"**按作品留出**的真实 query"，那是要求**跨扫描/版本**泛化，
> 而参考库 55% 来自单一合并源 ⇒ **域偏移**把上限人为压低，导致 5 个完全不同的编码器**一致**出现
> "生成集 mAP > real_real"的反常现象。改为**留一法**后数值才可解读（这是本项目评测建设中最关键的一处修正）。

### 2.4 编码器（**不自训** ✓，用户要求）

采用公开预训练编码器，避免"自训编码器质量不可控"污染结论：

```
dinov2_vitl14 (DINO-S 标准) · clip_vitl14 (CLIP-S 标准) · dinov2_vits14 · dino_vitb16/vits16
mae_vitb16 · clip_vitb32 · clip_vitb16_laion2b · resnet50_a1
```
- 预处理用**每个模型自己的** mean/std/size（timm `resolve_data_config`），用错会得到"有数但无意义"的特征。
- 池化可选 `cls / patch_mean / patch_stats`（后者=均值+标准差，对纹理/笔法更敏感）。
- **背景对照**（`mask_ink=True`：抹掉墨迹只留纸张/版式）是必做前置检验：若识别率仍高，说明编码器在吃纸张/扫描来源而非笔法。

### 2.5 工作流（远端编码参考库一次 → 本地 GPU 评测试输出 ✓）

参考库编码贵、测试输出小 ⇒ 用**可移植嵌入包**（`store.py`）：远端编码一次存 npz（8 MB），
拉回本地后每次评测**只需编码测试输出** ⇒ 6 个 step + 3 条基线 **144 秒**跑完（本地 4070）。
`pack` 往返**逐位一致**（已测）。

## 6. 诚实局限

1. **CLIP-S / DINO-S 区分"哪位书家"的能力较弱**：上限 0.8318/0.8574 与错书家 0.8138/0.8426
   仅差 0.018/0.015 ⇒ 它们主要回答"像不像**目标书家**的真迹"，精准归因需检索 mAP + Bootstrap CI。
2. **XCTAcc < 0.5 在通用编码器上普遍成立**（DINO/CLIP/MAE 0.31–0.34）⇒ 通用语义特征天然
   以"字符身份"为主；它不是"选编码器"的判据，而是"特征是否与内容解耦"的诊断。
3. **历史横比不是严格消融**：v79/v80（physics VAE）与 v83A/v84A（calli VAE + std 条件）在
   VAE/条件/配置上不同 ⇒ 同一评测集 + 同一协议下可比，但不是同架构对照。
4. **moyi 只有 step 50k 的样本**（单点，非趋势）；其 VAE/训练配置与我们不同。
5. **BSD 的宽度口径**是 `2×EDT`（含中心像素，比几何宽度约大 1 像素）；生成/参考同一约定，
   故**分布距离**不受影响，但绝对值不可与其它论文直接比。

## 7. 复现命令

```bash
# ① 参考库编码一次（远端）→ 可移植 pack
python tools/style_eval.py --csv exp-std/csv/train.csv --root . --root data \
    --out <out> --max-ref 9000 --save-bank-pack assets/style_packs/bank_v1.npz \
    --baselines 0 --bsd 0 --device cpu

    --enc dinov2_vitl14 --pool cls \
    --gen step120000=assets/style_eval_src/step0120000 \

#    <out>/style_report.json  （全量，含逐样本）
#    <out>/style_report.md    （对比表）
```

## 8. 建设过程中修掉的自身错误（留档）

| # | 错误 | 后果 | 修正 |
|---|---|---|---|
| 1 | 生成图过滤 `startswith("g")` | 把 `gt*.png`（真值图）也算进生成集（每 step 数到 374 而非 187）⇒ 指标被抬高 | 严格 `^g(\d+)\.png$`，索引与文件名同源 |
| 2 | 上限用"按作品留出" | 域偏移压低上限 ⇒ 5 个编码器一致出现反常排名 | 改**留一法** |
| 3 | `work_id` 取"所在目录名" | 真实 CSV 取到 `imgs`（所有行同一 id）⇒ "排除同作品"完全失效 | 取碑帖层并跳过 `imgs/std` 通名 |
| 4 | 标签映射只按参考库建 | 评测集含库外字符 ⇒ `KeyError` 直接崩 | 自动扩展 + 新增 `unseen_char` 分组上报 |
| 5 | 按 `id(row)` 索引嵌入 | `replace()` 造新对象后映射失效（`KeyError: 2068333614752`） | 改**行索引** |
| 6 | TTF 基线与 `char_head` 绑定 | 用 timm 编码器时 TTF-only 被误跳过（=nan） | 解耦，TTF 只依赖 std 图 |
| 7 | 建模尺寸与前处理尺寸不一致 | `lvd142m` 系列 patch_embed 断言失败 | 统一 224 |
| 8 | 只看到 120k 就下"风格退步"结论 | 误判 Pareto 权衡 | 补到 200k ⇒ 两轴同时最优 |

## 9. 下一步建议

1. **Bootstrap 置信区间**：所有风格指标按书家分层 bootstrap，给出 CI（小书家槽位方差大）。
2. **补齐 moyi 的多 step**（若 48 上还有中间 ckpt）⇒ 让 moyi 也有趋势而非单点。
3. **`--eval-cfg` 扫描**（需重新生成）验证"风格–CFG 强度"关系。
4. **near_blank 的按书家/书体细分**（已确认由**书家**主导：同一墨量箱内褚遂良 83% vs 何绍基 0%）。
5. 将本报告与 `assets/style_eval_local/**` 的结果目录一并归档。
