# 数据噪点调查与去噪尝试（接 28/29）— 2026-09-03

> 全量量化 fame v8 数据集的噪点分布，并尝试去噪。
> **结论：去噪失败，v9 产物已删除；保持使用 v8。**
> 本轮最大产出是**诊断结论**与**正确的安全评估方法**（`skeleton_keep`，见 §5）。

## 0. 结论（TL;DR）

1. **v8 已把小噪点/反相/黑条清干净**（`small_cc_n>0` 34.69%→0.00%），
   但**装裱黑边/边界墨块几乎没动**（`edge_blob>0` 仍 **43.99%**）——这是 v8 的主要残留，
   也是復/楷书上肉眼可见的"脏"的来源。综合噪点率 **44.06%**。
2. **本轮 8 轮去噪算法迭代全部失败**，v9 产物（`final_imgs_fame_v9/`，51321 张）已删除。
   最好的一版（v3.7）让 **5414 张字（10.55%）的笔画骨架断裂/消失**，细笔画字受损率 49%。
3. **根因**：毛刺(1–2px) 与细笔画(2–4px) **尺度连续重叠**，装裱与多部件字形**几何特征重叠**；
   无参考的形态学方法在"去噪"与"保笔画"之间无法两全（见 §4）。
4. **建议：保持 v8**。毛刺是 1px 级特征，经 VAE 8× 下采样对 latent 影响极小；
   而笔画断裂是结构性损伤。v8 笔画 100% 完整。
5. **方法论产出**：`skeleton_keep`（骨架保留率）才是正确的安全指标；
   全图口径的 `ink_delta` 会掩盖笔画级损伤（本次正是被它误导，见 §5.1）。

## 2. 噪点识别方法（多维指标）

### 2.1 指标定义

| 维度 | 指标 | 阈值 | 含义 |
|---|---|---|---|
| **小噪点** | `small_cc_n`, `small_cc_area_ratio` | area < 0.05%N | 与主字不连通的孤立小墨点 |
| **边界墨** | `edge_ink_ratio` | 8px 边带前景占比 | 边缘环带总墨率 |
| **黑条** | `border_bar` | 某边连续 >90% | 实心黑边/装裱条 |
| **贴边大块** ⚠ | `edge_blob_area` | 非主 + 贴边 + ≥1%N | **装裱黑边/边框残片**（v8 漏判） |
| **反相** | `inverted` | ink > 50% | 白字黑底 |
| **灰度脏背景** | `gray_mid_ratio` | 30<v<200 占比 | 未二值化背景（v8 全 0） |
| **高频** | `lap_var` | 拉普拉斯方差 | 笔画本身高频，非噪点指标 |
| **笔画毛刺** | 骨架短分支 / <2px 突起 | — | **与细笔画尺度重叠，无法可靠判定**（见 §4） |
| **笔画损伤** ⭐ | `skeleton_keep` | <0.95 判损伤 | **安全指标，见 §5.1** |

### 2.2 工具
- 扫描：`tools/clean/scan_image_pollution.py`（基础）、`_ot_scratch/scan_v8_noise.py`（扩展：四边 strip / 灰度 / lap_var）
- 笔画级损伤：`_ot_scratch/_eval_stroke_damage.py`（本地小样本）、`_eval_stroke_damage_full.py`（远程全量）

### 2.3 阈值修正（修正 28 号文档的低估）
- 28 号用 `small_a>=0.005` 判噪点，仅 **1.59%** —— **严重低估**
- 推荐 `small_cc_n>3`（原图 14.47% / v8 0%）能抓到大量"小而多"的散点
- 加上 `edge_blob>0`（v8 43.99%）才反映边界污染全貌

## 3. 去噪尝试：8 轮迭代全记录（全部失败）

| 版本 | 方法 | 结果 | 失败原因 |
|---|---|---|---|
| v2 | `binary_opening(3×3)` | 细笔画被整段腐蚀（薛稷/褚遂良） | 结构元 3px > 笔画宽 2–3px |
| v3.0 | 删贴边非主大块 | edge_blob 44%→0%，但 **774 张多部件字被删剩单部件** | 篆/隶分离部件被当装裱 |
| v3.1 | +fill>0.70+横贯>50% | 删墨 0.29%，**211 张丢部件**，且太保守装裱没删掉 | 篆书粗横画也是"实心横贯条" |
| v3.2 | 到主字距离>15px 删 | 楷书"復"彳旁间隔(15–54px)与装裱间隔(17–94px)**完全重叠**，80453 整个左半字被删 | 距离特征同样不可分 |
| v3.3 | 仅单部件字(big_cc==1)删块 | 删墨 0.12%，**64 张丢部件** | 骨架剪枝把短笔画（"点"）剪没了 |
| v3.4 | +短骨架保护(≤12px) | **99.97% 无变化** | disk(1) 膨胀的 marker 把剪掉的毛刺又长回来 |
| v3.5 | marker 不膨胀 | **仍 99.97% 无变化** | **毛刺与笔画连通，geodesic 重建必然恢复毛刺（数学上无解）** |
| v3.6 | 剪枝+有限膨胀 GROW=6 | 有变化，但**笔画边缘普遍收缩 1px**（颜体粗笔画半宽>GROW） | GROW 无法兼顾粗笔画与毛刺 |
| v3.7 | **2×2 opening+closing** | 去毛刺有效，但 **5414 张（10.55%）笔画骨架断裂** | 2px 结构元仍削断 2–4px 细笔画 |

## 4. 为什么失败：两类尺度/特征重叠

### 4.1 形态学结构元的两难
| 结构元 | 去毛刺 | 伤笔画 |
|---|---|---|
| opening 3×3 | 去 ≤2px 毛刺 | **吃 2–3px 细笔画**（v2） |
| opening 2×2 | 去 ≤1px 毛刺 | **削断 2–4px 细笔画骨架**（v3.7，5414 张） |
| 仅 closing | 不去毛刺 | 零损伤（但也零去噪收益） |

毛刺(1–2px) 与细笔画(2–4px) **尺度连续**，不存在"只去毛刺不伤笔画"的结构元。

### 4.2 装裱块 vs 字形部件不可分
篆/隶/草的分离部件、楷书的偏旁（彳）在"贴边、实心、横贯、距主字远"这些特征上，
与装裱黑边**完全重叠**（实测：楷书"復"彳旁间隔 15–54px，装裱间隔 17–94px）。

### 4.3 毛刺与笔画连通 → 重建必然恢复
骨架剪枝只在骨架层面删除分支；`reconstruction` 基于**连通性**做测地膨胀，
毛刺与笔画连通 → 必然被填回（v3.5 实测 99.97% 无变化，数学上无解）。

### 4.4 假象：letterbox 缩放会让"毛刺消失"
早期本地对照图（`assets/noise_v3/`）显示毛刺减少，实为 **LANCZOS 缩放到 240px
再居中**平滑了 1px 毛刺，并非算法效果。全量脚本不做缩放后，该"效果"立即消失。
→ 对照实验必须保持原尺寸、原分辨率，且输出仍为二值。

## 5. 方法论教训（本轮最大产出）

### 5.1 安全指标必须用"笔画级"，不能用"全图级"
- ❌ `ink_delta`（全图墨量变化）**掩盖**笔画级损伤：
  一个 3px×50px 笔画被削成 1px，笔画自身掉 67% 墨，相对全图 8000px 墨仅 −1.25%。
  **v3.7 全图只掉 0.21%，实际 5414 张字被削断笔画** —— "指标绿、实际坏"的典型。
- ✅ **核心安全指标 = `skeleton_keep`（骨架保留率）**：
  `skeletonize(原图)` 的骨架像素中，在去噪后仍为墨的比例。
  **<0.98 报警，<0.95 判定损伤**。辅以 `half_width`（distance_transform 局部半宽）看削细程度。
- 工具：`_ot_scratch/_eval_stroke_damage.py`（本地）、`_eval_stroke_damage_full.py`（远程全量）

### 5.2 不能依赖"读图确认"
本轮多次"视觉确认字形完整"是错的——读图工具对已分析过的图返回缓存结果，
实际未看到新图。**结论必须以量化指标为准，图像只作旁证、不作判据。**

### 5.3 统计量阈值会造成假警报，也可能掩盖真损伤
- 假警报：v3.7 报 `big_cc 丢失 915`、`main_keep<0.95 634`，但这些图 `ink_delta≈0`，
  实为 CC 面积跨过 1%N 统计阈值的边界效应，字形无恙。
- 掩盖真损伤：同一版 `ink_delta` 平均仅 −0.21%，却隐藏了 5414 张的断裂。
- → **单一指标不可信，必须笔画级 + 全图级 + 分组（按笔画粗细）交叉验证。**
