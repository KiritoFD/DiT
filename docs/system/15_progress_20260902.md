## 一、做出了哪些有效改动（全部有实测证据）

### 1. 数据质量：fame 全量清洗（v7 管线，6+ 轮看图迭代）
- **51,822 张全量处理完毕**：切边缘黑条 11,287 张、去赃物、极性归一（含 896+97 张
  反色拓片与 39 张人工标注）。
- 目检验证：赃点/黑条全清、笔画无损（v1 的「删触边组件毁字」「band 误翻」两起
  事故均在看图阶段拦截并修正）。
- 教训沉淀为算法规格与验收指标（见 `14_data_cleaning.md` §7）。

### 2. ControlNet 条件域三定理（本轮最重要的认知收获）
1. **条件域必须匹配**：GT 骨架训练的 ctrl 对标准字库骨架不响应（跟随 IoU 0.33），
   反之亦然（std-skel 训练模型对 GT 骨架 ΔSSIM≈-0.005）。
2. **骨架条件下 CFG>1 有害**：cfg 1.7→0.7，SSIM 0.683→0.752、失败 8%→2%。
3. **冗余条件会被忽略**：char ID 已隐含字形时，模型学会门控掉骨架注入
   ——GT 骨架能训练通是因为它携带实例信息。

### 3. fame-ctrl：SSIM 0.4977 → 0.8045（+0.30，n=500 全集）
- 清洗后数据 + cfg0.7 + injections 存盘修复的三重收益。
- 零样本打通：标准字库骨架 → 任意字书法生成（跟随 IoU 0.82-0.87，
  目检 豈/密/遂 等字形全部正确）。

### 4. 1px 骨架优于 3px（进行中，图A）
- 同期对比：1px@50k SSIM 0.7974 **已超 3px@50k 终值 0.7889**；SkelIoU 0.332 vs 0.321。
- max_steps 已扩至 100k（用户决策），趋势仍在涨。

### 5. 基建修复（数据可信度前提）
- injections 存盘丢失（致命）、eval daemon 路径 bug、eval CSV 组合泄漏、
  极性判据三轮演进、npz/张量转换等工具链问题——全部闭环并有审计记录。
