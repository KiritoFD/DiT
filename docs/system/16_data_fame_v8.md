# 16 · 数据层：fame / V8 数据体系（现行）

> 本文是**现行数据层的权威描述**。mid-clean 时代的管线见 `05_dataset.md`（历史）。
> 上游：MCCD 数据集（`MCCD.7z` 23G / `dataset/` 24G，原始扫描图 62,157+ 张带元数据）。

## 1. 演进链（五代数据集）

```
MCCD 原始 (62k+ 张, 1011 书家, 12 书体)
  → top6 (10,866, s2-s11/s18 时代)          [已弃]
  → 3top30 (s12-s17 时代)                   [已弃]
  → mid_clean (118,776 = 23,597 真实 + 95,179 增广, s19)  [已弃]
  → mid_common (23,597 真实无增广, s20)     [已弃]
  → fame (52,518 = 44 规范书家名家精选)     [s21 时代]
  → **v8 (51,321 训练 + 500 eval, 09-02 11:52 构建)**  ← 现行
```

每一代的教训：
- top6：数据太少，过拟合书家（泛化 SSIM 0.43）；
- mid_clean 增广：**增广不增加信息量**（+11.9 万张无增益）；
- mid_common：去增广、保真实——方向正确，但清洗前数据含噪；
- **v8：在 fame 精选 + 全量清洗 + 极性归一之后构建，是第一代"干净"数据**。

## 2. fame 名家筛选

- 名单：57 提名（合并 赵孟/赵孟頫、郑燮/郑板桥、孫過庭/孙过庭）→ 44 规范书家，
  含 6 位帝王（赵佶/赵构/李世民/乾隆/武则天 等）。
- 规模：52,518 张（16.34% of 全量），2,523 字符组合，
  楷 21,102 / 行 20,331 / 隶 13,288 / 草 / 篆 / 六体。
- 每字样本：中位 2.2 张（名家数据天然稀疏），最少 1 张。

## 3. 清洗管线（v7 算法，`tools/clean/noise_clean_v2.py`）

四步纯传统 CV（无深度学习、无缩放、无裁笔画）：

```
0) 极性归一: 最大黑组件 >55% 图像面积 → 黑底拓片 → 反色
   （判据演进: ink>0.5 → 边带中值 → 黑组件面积+触边数，
     前两者各有盲区——白边稀释 / 浓墨白底字误判，最终数据层翻转+人工标注兜底）
1) 切边条: 从四边连续向内，行/列黑占比 >50% → 白化（上限 25% 防误吞）
   → 对付页边黑条/装订痕（11,287 张受影响）
2) 外框 3px 白化: 残留细框线
3) 去赃物: <80px 孤立连通域删除（非主体组件）
```

**明令禁止**：opening/morphological 平滑（破坏细笔画）、band erase
（切断触边笔画，v6 事故：最上面一笔被切）、任何缩放。

全量执行结果：切条 11,287、去赃物 ~21,022、极性修正 896+97+39（人工标注）、
0 错误。原图备份 `final_imgs_256_v7backup/`（可回滚）。

## 5. 骨架体系

两级骨架从清洗后图像派生：
- **1px**（`skeletonize`）：笔画中心线——**现行 ctrl 条件**（3px 膨胀版已证劣于 1px）；
- **3px**（1px + dilation×3）：已弃用。

骨架 → latent 经 sd-vae-ft-ema encode（`*0.18215`），与主模型 latent 同空间。
ControlNet 条件 = 骨架 latent（4×32×32 f16）。

### 骨架库（推理用）
| 库 | 内容 | 覆盖 |
|---|---|---|
| `skel_bank_train.npz` | 训练集每字一张骨架 latent（14,372 字） | 训练字 zero-shot |
| `skel_bank_std.npz` | 标准字体渲染骨架 latent（238 eval 字） | 楷/行/隶（草/篆/六体无标准字体） |

## 7. 验收指标（新增图入库前必查）

| 指标 | 定义 | 阈值 |
|---|---|---|
| dirt_ratio | <80px 连通域 / 总墨迹 | >1% 告警，>5% 拒收 |
| border_junk_ratio | 边带黑占比（切条前） | >50% 连续 → 切条 |
| polarity | 边带中值 <128 或黑组件 >55% | 违反 → 翻转 |
| main_kept | 清洗后主体 ≥ 清洗前最大组件 95% | 必须 |
| post_residual | 清洗后 sub-80px 残留 | <0.1% |

## 8. 已知残留问题

1. ink≈0.5 的宽白边拓片（~0.1%）判据边界，需人工兜底；
2. 石花纹理与笔画粘连的深纹理拓片，去噪后笔画有残缺（v6 探测案例 江/旗）；
3. `skel_bank_{train,std}.npz` 未同步清洗后变更（推理影响极小）；
4. fame.npz/final_latents_fame 旧目录已删——旧脚本引用需改指 v8 目录。
