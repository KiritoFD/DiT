# 72. 为什么 seen 刷得高、strict 上不去 —— 稀疏还是过拟合？

> 日期：2026-09-18
> 数据：v13 base 155k ckpt + 12ch 后训练前 17.5k 步；strict 250 张全量评测

---

## 0. 结论

| 假设 | 判定 | 证据 |
|---|---|---|
| **过拟合** | **✗ 不成立** | strict 从未下降（0.5103 → 0.5703 单调微升） |
| **数据稀疏是主因** | **✗ 不是主因** | r(该字的书家数, ssim) = **+0.158**，只解释 ~2.5% 方差，且**非单调** |
| **模型已经饱和** | **✓ 是主因** | post-training 里 strict 从 step 2500 的 0.5699 到 17500 的 0.5713，**几乎不动** |

**一句话**：不是过拟合，也不主要是稀疏 —— 是**任务本身在像素级 ssim 上已经到顶**。

---

## 1. 排除过拟合

```
step    seen    strict
 10000  0.5348  0.5216
 50000  0.5602  0.5367
100000  0.6447  0.5450
150000  0.7528  0.5530
155000  0.7580  0.5703   ← 全量 250 张
```

经典过拟合 = **验证指标下降**。strict 一直在**微升**，没有下降 ✗

**但有个陷阱**：`seen` 是 **20 张训练集内的图**（记忆指标），
`strict` 是未见「字×书家」组合（泛化指标）。**直接比是苹果比橘子** ——
0.188 的差距本身就含"记忆 vs 泛化"的定义差异，不是模型缺陷。

---

## 2. 稀疏有多严重（确实严重，但不是主因）

50,786 样本 / 45 书家 / 7,122 字：

```
每书家样本数:     min=99  med=866  max=3131
每书家覆盖字符数: min=99  med=718  max=1978
-> 平均每个书家只覆盖 11.7% 的字        ← 88% 的 (书家,字) 组合无监督

(书家, 字) 对的样本数:
  恰好 1 张: 28,235 对 (75.0%)          ← 中位数就是 1
  恰好 2 张:  6,934 对 (18.4%)
```

**strict 集构造正确**：`(script, callig, char)` 三元组在训练集里 **250/250 全为 0** ✓

**strict 的字被多少书家写过**：
```
≤ 1 个: 32/250 (12.8%)     ≤ 5 个: 91/250 (36.4%)
≤ 2 个: 45/250 (18.0%)     ≤10 个: 142/250 (56.8%)
```

### 但相关性检验推翻了"稀疏主导"

```
该字被多少书家写过 -> strict ssim
  0-1   个 (n=32): 0.5761     ← 反而偏高！
  2-3   个 (n=25): 0.5629
  4-7   个 (n=62): 0.5483     ← 最低
  8-15  个 (n=70): 0.5640
  16-100个 (n=61): 0.6000     ← 最高

Pearson r = +0.158（书家数） / +0.163（总样本数）
```

**若稀疏主导，0-1 个书家的桶应该最差** —— 实际它比 4-7 的桶还高 ✗
**r=0.16 只解释 ~2.5% 的方差**，且**非单调** → 稀疏只有很弱的影响。

## 3. 那瓶颈在哪？看 poster

`assets/results/v13_12ch_post/posters/strict_poster.png`
（第 1 行 = 输入标准字 g，中间 = 各 step 预测，最后一行 = GT）

**观察**：
1. **预测确实是正确的字**（`出短堂禮 静靜` 全部可辨）✓
   → **`g` 条件有效，内容没问题**
2. **预测有笔意、不是干巴巴的印刷体** ✓ → 风格条件也在起作用
3. **⚠ 但从 step 2500 到 17500，预测几乎一模一样** ✗
   → **模型早就饱和了**，多训 15k 步没有变化

## 4. 所以怎么办

### 4.1 立刻可得的结论
**继续在 img 侧堆步数收益极小** —— strict 在 post-training 的 2500 步就饱和。
12ch 后训练的**真正价值在 aux 通道**（canny/skel 从零学，还在快速下降）。

### 4.2 想真正提升 strict，得动这几个杠杆
| 杠杆 | 理由 |
|---|---|
| **提高每 (书家,字) 的样本数** | 75% 的对只有 1 张 —— 风格-内容解耦的信号太弱 |
| **加强书家条件** | 需要 A/B 验证：固定 `g` 换 `y_callig`，看输出变不变 |
| **`no_char_cond=True` 下内容只有 `g` 一条通路** | 模型容易学到"直接抄 g"的捷径（待验证） |
| **xattn 注入** | 配置里 `glyph_inject_mode` 有 `xattn` 备选，比 `adaln` 的空间表达能力更强 |

### 4.3 还没做但应该做的决定性实验
**书家条件的 A/B**：固定 `g` 和噪声，只换 `y_callig`，
比较输出的差异幅度。
- 差异大 → 书家条件有效，瓶颈在数据
- **差异小 → 书家条件被忽略，瓶颈在条件机制** ← 这才是最该查的

## 5. 方法论备注

**这次差点搞错**：我第一眼看 poster 的缩略图，以为"预测就是 `g` 的复制、
书家风格完全没起作用"。放大到 3 倍逐列看才发现预测**确实有笔意**。
