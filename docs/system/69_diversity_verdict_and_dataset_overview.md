## 1. 输出多样性

### 1.1 先把三个指标分清（最易混的地方）

| 指标 | 固定什么 | 变什么 | 回答的问题 |
|---|---|---|---|
| **intra = 输出多样性** | 书家 + 字 + 书体 | 随机种子 | **同一个字写两遍，像不像？** |
| `inter_callig` | 噪声 + 字 | 书家 | 条件的**作用**有多大 |
| `inter_char` | 噪声 + 书家 | 字 | 条件的**作用**有多大 |

**"多样性"只看 `intra`。** `inter_*` 是"条件可控性"，是**另一个维度**，
两者互不蕴含：可以"多样但条件无效"，也可以"条件很强但输出单一"。

### 1.2 为什么"真迹差异"不能当合格线

真迹差异包含**四类**成分：

| 成分 | 例子 |
|---|---|
| ① 书写状态变化 | 不同时间/心境/笔锋状态写的同一个字 |
| ② 工具材料变化 | 不同笔、墨、纸 |
| ③ **采集变化** | 不同扫描仪/光照/分辨率/裁切/二值化 |
| ④ 作品语境 | 不同作品里同一个字，前后文影响笔势 |

模型换种子**只包含一类**：模型对"给定条件下还剩哪些不确定"的**后验方差**。

**关键在 ③**：采集变化**模型根本不该也不能复现** —— 给同一个条件，
模型没有理由输出不同分辨率的扫描噪声。

```
真迹差异 = 真实风格变化 + 采集噪声
模型 intra = 模型建模到的那部分不确定
```

→ **真迹差异是模型输出多样性的「上界」，不是「目标值」。**

**实证佐证**（(书家,字,书体) 三元组内两两 1−SSIM）：

| 真迹 intra | med | mean | p10 | p90 |
|---|---|---|---|---|
| 老数据 | 0.3946 | 0.3903 | 0.2421 | 0.5264 |
| HCSU | 0.1285 | 0.1729 | 0.0423 | 0.3645 |

**同一批"真迹"内部差 2.3 倍** —— 说明这个数主要反映**采集条件**，不是书写风格。

⚠ 计算时的一个坑：只按 (书家,字) 分组会把**跨书体**混进来
（老数据 41% / HCSU 23% 的"多图组合"跨书体，如文徵明写过楷书「一」也写过行书「一」）
→ 测的是"楷 vs 行"不是"写两遍"。**必须加书体约束。**

### 1.3 文献标准（查证结果）

**(a) 标准框架是"一对"指标，不是一个**

| | 定义 | 主流指标 |
|---|---|---|
| **Fidelity（保真度）** | 生成样本是否逼真（落在真实分布内） | Improved Precision、Density、α-precision |
| **Diversity（多样性）** | 生成分布是否覆盖真实分布的全部模式 | Improved Recall、Coverage、β-recall |

Kynkäänniemi 2019 / Naeem 2020 / Alaa 2022 等六对。
**FID / IS 这类单一标量已被认为不够** —— 无法区分"质量"和"覆盖"。

**(b) ★ 没有模型能达到真实数据的多样性**

Vendi Score 论文实测（Stacked MNIST，1000 个模式）：

| | NoM（模式数） | **VS（有效多样数）** |
|---|---|---|
| 原始数据集 | 1000 | **943.7** |
| PresGAN | 1000 | 866.6 |
| Self-cond GAN | 1000 | 746.7 |

**两个 GAN 都覆盖了全部 1000 个模式，VS 仍低于原始数据集。**
论文原话：**"没有模型能达到其训练原始数据集的多样性分数"**。

→ **"低于真迹"是常态，不是失败。**

**(c) 真正的失败模式是 mode collapse，用 Vendi Score 检测**

```
VS = exp(−Σᵢ λᵢ log λᵢ),   λ = eigvals(K/n),   K = 相似度核
```

- **范围 [1, n]**：**VS = 1 → 所有样本完全相同（完全坍塌）**；VS = n → 两两完全不同
- **可解释为"有效不同元素数"** —— 有绝对解读基准，可用比值/百分比比较
- **不需要参考数据集** → 正好绕开"真迹不可比"的问题
- 代价：reference-free 意味着"采样纯噪声也能得高分" → **必须与质量指标配合使用**
- 可视为核矩阵的**有效秩**

**(d) ⚠ 但对条件生成，VS 不该接近 n**

我们给的条件是"书家 + 字 + 骨架"，4 个样本**本来就该像**（同一个字、同一种风格）。
**VS 显著低于 n 是正常且期望的。** 该看的是 **VS 明显 > 1（没坍塌）**。

**(e) 没有黄金指标**

ICML 2025 position paper（arXiv 2505.22450）系统检验了 6 对共 12 个
fidelity/diversity 指标，**没有一个通过全部 sanity check**，明确呼吁
"不应将某个指标的高分解读为生成质量无条件好"。
→ **只能做相对比较 + 坍塌检测。**

### 1.4 【实测】Vendi Score —— 无坍塌

从 30 条件 × 4 生成的海报算 VS（相似度核 = SSIM）：

| | **VS（有效变体数）** | 上界 | 归一化 VS/n | **坍塌条件数** |
|---|---|---|---|---|
| v12 cfg=0.7 | **2.233** | 4 | 0.558 | **0 / 30** |
| v12 cfg=1.0 | 2.210 | 4 | 0.552 | **0 / 30** |
| v12_d8（K=3） | 2.084 | 3 | **0.695** | 0 / 4 |

（均值；v12 cfg=0.7 的 min=1.778 med=2.181 max=2.858）

**判读**：

1. **`0/30` 条件坍塌** —— 没有任何一个条件出现"4 张几乎一样"。
   **模型在采样时确实用到了噪声，不是查表。**
2. 有效不同变体数 **2.23 / 4** —— 4 张里约 2.2 张"等效不同"。
   对条件生成这是**健康的**：有真实变化，又保持同字同风格。
3. d8 的归一化 VS 更高（0.695 vs 0.558）→ 小模型确实更"飘"，
   与它条件信噪比更低（ratio 1.42 vs 1.83）一致。
   ⚠ 但 K 不同（3 vs 4），这个比较是近似的。

### 1.5 判定与适用边界

**判定：多样性合格 —— 按文献可操作的口径（无 mode collapse + 与质量指标配合看），通过。**

**边界（这个结论的适用范围）**：

| 项 | 范围 |
|---|---|
| 模型 | 仅 v12 (S/2) 100k 一个 ckpt（d8 只测了 4 个条件） |
| 条件数 | 30（strict 集） |
| 采样 | 50 步，cfg 0.7 / 1.0，K=4 |
| 相似度核 | SSIM（换 LPIPS 会得到不同的 VS 绝对值） |
| 未测 | 换 HCSU 数据后的模型；12ch / xattn |

**没测但值得测**：`--cfg 2.0/3.0` —— 若模型 CFG 正常，多样性应明显下降；
现在不动（见 §3），这本身是一个**独立的 CFG 失效证据**。

### 1.6 一个比"多样性"更值得追的问题

```
ssim_to_gt            = 0.586    （样本 vs GT）
样本两两 SSIM = 1−0.317 = 0.683    （样本 vs 样本）
```

**样本之间比样本与 GT 更相像** → 模型输出**聚在一起、整体偏离 GT**。
这是**系统性偏差**，不只是方差。**要把质量往上推，这个比多样性值得追得多。**

| | 多图三元组占比 | med | mean | p10 | p90 |

### 2.5 三个结构问题（都需要单独决策）

**(1) 字的长尾极重**

```
合并: 每个字 1 张 (min) / 4 张 (med) / 86 张 (max),  Gini 0.576
```

**一半以上的字只有 ≤4 张。** 对生成模型意味着大量字是"few-shot"，
模型只能从"这个书家的其他字"泛化结构。

**(2) one-shot per pair —— 最严重的结构问题**

| | (书家,字) 组合数 | 平均张/组合 | 重复(>1张)组合占比 |
|---|---|---|---|
| 老数据 | 22,063 | 1.3 | 19.5% |
| HCSU | 20,091 | 1.2 | 21.8% |
| **合并** | 37,801 | **1.4** | **28.5%** |

**平均每个 (书家,字) 只有 1.4 张。** 这意味着模型**几乎无法从"这个字"学到风格**，
只能学"这个书家整体怎么写"。**这是"风格—内容解耦"难做的根本数据原因。**

**(3) 书家跨书体**

| | 跨多书体书家 | 单书体书家 |
|---|---|---|
| 老数据 | 31/36 | 5 |
| HCSU | **15/38** | 23 |
| 合并 | 33/48 | 15 |

**老数据 86% 的书家跨多书体**（HCSU 只有 39%）→ 风格与书体纠缠，
模型难以分离"这是文徵明的风格"还是"这是楷书的特征"。

## 3. 附：CFG 的两个问题（与多样性的关系）

**问题 A（bug）**：`dit.py` 的 drop guard 元组漏了 `factorized_cat`
→ **训练全程零条件 dropout** → uncond 分支用未训练的 `null_embed`
→ cfg=0.7 是在**往随机方向插值**。（已修）

**问题 B（设计选择）**：`g2 = cat([g, g])` 两半给同一个 g
→ **g 在 CFG 差分中完全抵消** → xattn / glyph_embedder 对 CFG 贡献恒为 0。

### ★ 一个漂亮的交叉验证：CFG 失效有两条独立证据

CFG 原论文（Ho & Salimans 2022）原话：

> increasing classifier-free guidance strength has the expected effect of
> **decreasing sample variety and increasing individual sample fidelity**

实测（ImageNet 64×64）：w 从 0→4，**FID 涨 14.6 倍**（1.80→26.2）。

**→ 正常工作的 CFG，cfg 提高应明显降低多样性。**

| 证据链 | 内容 |
|---|---|
| **代码侧** | uncond 分支未训练 + `null_embed` 停在初始化（std=0.02） |
| **行为侧** | 实测 cfg 0.7 → 1.0：**VS 2.233 → 2.210，几乎不动** |

**两条完全独立的证据指向同一结论。** 这比只从代码推断可靠得多。

### 影响评估：机制错，但**数值影响很小**

| | cfg=0.7 | cfg=1.0 | 差异 |
|---|---|---|---|
| intra | 0.3169 | 0.3113 | −1.8% |
| ssim_to_gt | 0.5862 | 0.5869 | +0.1% |

原因：`null_embed` 停在初始化（std=0.02）→ `0.3·uncond + 0.7·cond ≈ cond`，插值近似 no-op。

→ **机制上该修（已修，重训零成本），数值上不值得为它返工。**

## 5. 方法学教训（本次积累）

1. **判定"多样性合格"必须先定参照系，而参照系极易搞错**
   —— 我第一次按 (书家,字) 分组，41% 的组合跨书体，测的是"楷 vs 行"。
2. **真迹差异 ≠ 模型多样性** —— 前者含采集噪声，是上界不是目标。
3. **小样本偏差极大** —— 16 对得 0.1878，180 对得 0.3169（**差 69%**）。
   这类指标必须 ≥100 对。
4. **测试脚本本身要先做 sanity check** —— DiT 的 `final_layer` 是 zero-init
   → 输出恒为 0，不打破它测出来的全是"0 和 0 的差"。
5. **`strict=True` 当护栏** —— `eval_diversity.py` 原来的 `strict=False` +
   漏字段，会**静默加载随机 `cond_fusion`**，数字看着正常但毫无意义。
6. **概念要先分清再测量** —— `intra`（多样性）与 `inter`（可控性）是独立维度，
   混在一起讲会得出错误结论（我犯过）。
